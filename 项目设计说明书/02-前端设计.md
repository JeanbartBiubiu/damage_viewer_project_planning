## 一、功能说明

前端是 **React + Arco 的 Web 控制台**，承担：

1. **combat-data 管理后台**：按资源表分页编辑（列表 GET + Admin PUT；无独立 DELETE）。
2. **版本发布**：`versions:publish`，回读 current / combat-data state。
3. **装配与计算**：`combatDataLoader` → `combatDataAssembler` → `genericEngineClient`（compile / run / release）。
4. **图片 IndexedDB 缓存**。

事实数据面仅为 `combat-data/**`；不要恢复 Bundle / wasm-catalog / hero·item·skill 专用页。

## 五、服务层要点

| 模块 | 职责 |
|------|------|
| `apiClient` | 基址解析、games/current/images/publish |
| `combatDataClient` | Public GET / Admin PUT `combat-data/**` |
| `combatDataLoader` | revision-safe 拉取；与 IndexedDB graph 缓存协作 |
| `combatDataAssembler` | graph + 实体选择 → `CompileRequest` / RunRequest |
| `genericEngineClient` | 调用桥接层通用 ABI |
| `tinygoV2Bridge` | frame 编解码；通用导出 `engine_compile` / `engine_run` / `engine_release_session` |

API 基址：显式值 → `VITE_API_BASE_URL` → `http://localhost:8080`。

## 六、Wasm 调用时序（当前）

```
loadCombatDataGraphRevisionSafe(apiBase, gameId)
  → assembleCombatScenario / assembleCompileRequest
  → genericEngineClient.compile(CompileRequest)   # engine_compile
  → genericEngineClient.run(...)                  # engine_run
  → genericEngineClient.releaseSession(...)       # engine_release_session
```

字段级编译规则见 [08](./08-适配层编译规范.md)。

## 七、本地缓存

| 缓存 | 文件 | 键 | 时机 |
|------|------|----|------|
| combat-data graph | `combatDataCache.ts` | gameId + revision | loader 命中/失效 |
| 图片 | `imageCache.ts` | `{gameId}_{uri}` | ImagesPage 同步 |

## 八、验证与发布门禁

| 命令 | 作用 |
|------|------|
| `npm run lint` / `typecheck` / `test` / `build` | 日常 |
| `npm run test:e2e:wasm-generic` | 仅 Playwright |
| `npm run smoke:wasm-generic` | lint→typecheck→test→build→e2e（fail-fast） |

Live smoke **fail-closed**：必须设置非空 `E2E_API_BASE_URL`、`E2E_GAME_ID`；缺失则非零退出，不 skip。`E2E_WEB_BASE_URL` 可选；未设则自动 `vite preview`（`127.0.0.1:4173`）。
