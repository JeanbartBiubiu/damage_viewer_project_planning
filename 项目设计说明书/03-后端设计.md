## 一、功能说明

单体 Spring Boot 服务 **data_manage** 负责：

1. **Public 只读**：`games`、`versions/current`、`images`、`/combat-data/**`（含 `/state`）。
2. **Admin 写入**：`PUT /api/admin/games/{gameId}/combat-data/**`、`images` PUT、`POST .../versions:publish`。
3. **revision**：Admin PUT 锁定 `game_data_state` 并递增 `current_revision`；行上记录 `change_revision`。
4. **发布**：冻结 `publishRevision` 到 `game_versions`，增量拷贝 `change_revision ∈ (previousPublishedRevision, publishRevision]` 的行到对应 `*_log`。**不**构建 Bundle / Wasm Catalog。

**不做**：伤害计算；用户登录注册（外部 JWT）。

## 四、对外接口（机制级）

### 4.1 约定

- 成功：`2xx` 直接 JSON，无 wrapper。
- 失败：`{ error: { code, message, details? } }`。
- Public `/api/games/**`（非 admin）无 JWT；Admin `/api/admin/**` 需 Bearer + `canEdit`。
- PUT 请求体禁止带 revision/version 元数据字段。

### 4.2 Public（节选）

```http
GET /api/games
GET /api/games/{gameId}/versions/current
GET /api/games/{gameId}/images?updatedAfter=<ISO>
GET /api/games/{gameId}/combat-data/state
GET /api/games/{gameId}/combat-data/**   # entities、providers、abilities、effect-steps、types…
```

完整路径表见 [接口与页面索引](../文档记录/详细设计/接口与页面索引.md) 与 `文档记录/详细设计/server/game_manage/接口定义.md`。

### 4.3 Admin（节选）

```http
PUT  /api/admin/games/{gameId}/combat-data/**   # 与 Public 资源树对称，仅 PUT
PUT  /api/admin/games/{gameId}/images/{uri}
POST /api/admin/games/{gameId}/versions:publish
```

发布请求 `{ versionCode, releaseDate? }`；响应含 `changeRevision` 等版本元数据。

## 五、关键子系统

### 5.1 combat-data 读写

- Public Controllers：`controller/publicapi/combatdata/*`
- Admin Controllers：`controller/adminapi/combatdata/*`
- Services：`CombatTypeService`、`EntityCombatDataService`、`ProviderCombatDataService`、`AbilityCombatDataService`、`EffectCombatDataService`
- Revision：`GameDataRevisionService`（递增）、`CombatDataPublishService`（publish / log 拷贝）

### 5.2 发布算法（机制）

```
1. 锁定 game_data_state
2. 拒绝非法 versionCode；创建 game_versions，冻结 publishRevision
3. 增量拷贝 change_revision ∈ (previousPublishedRevision, publishRevision] 的 combat-data 行到对应 *_log（按 version_id）
4. 推进 published_revision / is_current
5. 失效 current 等读缓存
```

不调用 `buildBundle`，不写全量快照表。

### 5.3 鉴权 / CORS / 缓存

- `AdminAuthFilter` 仅 `/api/admin/**`。
- CORS：`/api/**`，暴露 `ETag`。
- 缓存名侧重 games / currentVersion / images（无 bundle）。
