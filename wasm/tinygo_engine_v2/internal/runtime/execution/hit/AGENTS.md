# 命中执行约束

本包执行合格接触、候选与规则组、阻挡、主体替换及强化命中，私有持有命中索引、接触历史、冻结候选上下文和强化局部帧事实。

- 实际使用身份继续由 `action` 持有；本包只借用本职责需要的真实使用、过程视图和变更对象，不取得全局行动控制。
- 不导入父执行包、根运行包、调度器或其他执行所有者；可以借用根层组合的同一 `usage.Ledger` 及实际预留凭据，不保存第二份共同额度。
- 候选、规则组、窗口消耗、失败及完成规则在本包执行。操作、真实过程时点和盾消费通过消费方声明的有限同步能力交回原帧；本包不创建根帧、统一提交、直接排程或自行派发普通监听。
- `resolve_skill_hit` 在原帧只准备冻结事实和待派发请求，不提前执行候选或监听。跨命中、普通监听、阻挡监听及强化的固定次序由根层保留。
- 尝试期命中序号和接触登记保留原调用时点，不能统一改成帧成功后记录。
- 完整 `Context` 私有保存候选、编译计划和强化等待；共同事件只借用 `contract.SkillHitFacts` 等有限事实。阻挡复用账只保存范围和盾身份，不复制完整执行上下文。
- 规则组共用原帧和实际额度预留，逐候选清理可读操作输出；强化等待在执行位置复查实例、版本、期限和挂载，不能复用同步子调用之前的存活结论。
- 嵌套执行使用每次调用独立的绑定恢复凭据，不使用单个“当前帧”。历史冻结与只读借用期限必须明确；不公开可写集合，不新增逐事件适配对象、闭包或大快照。
