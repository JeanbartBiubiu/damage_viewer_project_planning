# 执行协调约束

继承上层运行规则。本包拥有帧、操作路由、公式上下文、命中与监听的冻结事实，以及统一提交协调。

- `Engine` 与 `Frame` 的字段保持私有；数值、行动、效果、报告状态继续由所属子包持有。
- 只借用根入口提供的同一个 `scheduler.Loop`，不再创建时钟、事件堆或独立停止账。
- 统一提交保留现有预检、发布、生命周期、唤醒、事实与报告顺序；不要把旧有部分成功边界改成整体回滚。
- 过程与效果只读查询使用视图，暂存写入使用所属包的变更对象，不为跨包调用恢复可写集合。
- 单测与实现同包；`wiring_test.go` 只为私有不变量测试组合真实入口。系统组合回归通过 `tests/runtime/` 的根会话执行。

修改执行路径按模块规则运行全量 Go、原生基准、正式 Wasm 及生产适配机制回归。
