# 概要设计 — 历史值追踪与时间窗口机制

> 创建日期：2026-03-31
> 状态：设计草案

## 1. 背景与需求

许多英雄技能的数值计算依赖 **"N 秒前的状态值"** 或 **"最近 N 秒内的累计值"**，典型代表：

| 英雄 | 技能 | 机制 | 依赖的历史数据 |
|------|------|------|---------------|
| 艾克 | R（时空断裂） | 回溯到 4 秒前的位置，回复到 4 秒前的 HP | 位置坐标历史、HP 历史快照 |
| 腕豪 | W（蓄意轰拳） | 将最近数秒内承受的伤害按比例转化为护盾/真伤 | 受到的伤害滑动窗口累计 |
| 塔姆 | 被动（百味盛宴） | 基于最大生命值百分比的持续伤害叠层 | 叠层计数 + 过期窗口 |
| 沃利贝尔 | 被动（雷霆之爪） | 连续攻击叠层，一定时间内不攻击则重置 | 攻击时间间隔窗口 |

这些机制的共同特征：**在任意时刻 $t$，需要高效查询过去 $[t - \Delta, t]$ 窗口内的状态快照或累计值。**

## 2. 现有引擎差距分析

当前 `katarina_mvp_engine` 的 `ActorRuntime` 存在以下不足：

| 现状 | 问题 |
|------|------|
| `hp_current`、`attrs` 仅保存当前值 | 无法查询"4 秒前的 HP 是多少" |
| `Vec<RuntimeLog>` 线性追加带 `t_ms` 的事件 | 无索引、不适合运行时窗口查询，仅事后分析用 |
| `Vec<EngineSamplePoint>` 追加式采样 | 同上，线性增长，O(N) 扫描 |
| 无位置坐标系统 | 艾克 R 等需要位置回溯时无从入手 |
| 无通用 buff/debuff 框架 | 每种效果硬编码（shield / stun / black_cleaver 各有独立字段） |

**结论：需要引入一个通用的、固定内存的时间窗口追踪数据结构。**

## 3. 数据结构选型

### 3.1 方案对比

| 方案 | 内存开销 | 写入 | 查询 | 适用场景 |
|------|---------|------|------|---------|
| **环形缓冲区 Ring Buffer（推荐）** | 固定 $O(W/I)$ | $O(1)$ | 快照 $O(\log N)$ / 累计 $O(K)$ | 固定窗口回溯：艾克 R、腕豪 W |
| 事件日志线性扫描 | 随模拟时长线性增长 | $O(1)$ | $O(N)$ 全量扫描 | 仅事后分析，运行时不推荐 |
| 完整快照链 | 极高（每 tick 全量拷贝） | $O(S)$ | $O(1)$ 直接索引 | 回放/调试，生产不推荐 |
| Delta 变化链 | 低 | $O(1)$ | 需从锚点逐步重放 | 撤销/重做，随机访问慢 |

### 3.2 选定方案：`TemporalRingBuffer<T>`

以 100ms 采样间隔、5 秒窗口为例，每个 actor 仅需 **51 个 slot**，WASM 环境下内存开销可忽略不计。

**核心特征：**
- 固定容量，不会随模拟时间增长
- 覆写式写入，自动淘汰超出时间窗口的旧数据
- 支持两类查询：点查快照（艾克 R）、窗口累计（腕豪 W）

## 4. 数据结构定义

### 4.1 核心 Ring Buffer

```rust
use std::fmt::Debug;

/// 固定时间窗口的环形缓冲区
/// 支持 O(1) 写入、O(log N) 快照查询、O(K) 窗口累计
#[derive(Debug, Clone)]
pub struct TemporalRingBuffer<T: Clone + Debug> {
    entries: Vec<Option<TimestampedEntry<T>>>,
    /// 下次写入位置
    write_cursor: usize,
    /// 当前有效条目数
    len: usize,
    /// 缓冲区容量
    capacity: usize,
    /// 保留的最大时间窗口 (ms)
    window_ms: u32,
}

#[derive(Debug, Clone)]
struct TimestampedEntry<T: Clone + Debug> {
    t_ms: u32,
    value: T,
}

impl<T: Clone + Debug> TemporalRingBuffer<T> {
    /// 创建缓冲区
    /// - window_ms: 保留的历史时长 (ms)
    /// - sample_interval_ms: 采样间隔 (ms)，决定容量
    pub fn new(window_ms: u32, sample_interval_ms: u32) -> Self {
        let capacity = (window_ms / sample_interval_ms).max(1) as usize + 1;
        Self {
            entries: (0..capacity).map(|_| None).collect(),
            write_cursor: 0,
            len: 0,
            capacity,
            window_ms,
        }
    }

    /// 推入一个带时间戳的值，O(1)
    pub fn push(&mut self, t_ms: u32, value: T) {
        self.entries[self.write_cursor] = Some(TimestampedEntry { t_ms, value });
        self.write_cursor = (self.write_cursor + 1) % self.capacity;
        if self.len < self.capacity {
            self.len += 1;
        }
    }

    /// 查询最接近 target_ms 且 <= target_ms 的快照
    /// 用途：艾克 R 回溯到 N 秒前的状态
    pub fn query_at(&self, target_ms: u32) -> Option<&T> {
        let mut best: Option<&TimestampedEntry<T>> = None;
        for entry in self.entries.iter().flatten() {
            if entry.t_ms <= target_ms {
                match best {
                    Some(b) if b.t_ms >= entry.t_ms => {}
                    _ => best = Some(entry),
                }
            }
        }
        best.map(|e| &e.value)
    }

    /// 累计窗口 [from_ms, to_ms] 内的值
    /// 用途：腕豪 W 累计最近 N 秒受到的伤害
    pub fn aggregate_window<F, R>(&self, from_ms: u32, to_ms: u32, init: R, mut f: F) -> R
    where
        F: FnMut(R, &T) -> R,
    {
        let mut acc = init;
        for entry in self.entries.iter().flatten() {
            if entry.t_ms >= from_ms && entry.t_ms <= to_ms {
                acc = f(acc, &entry.value);
            }
        }
        acc
    }

    /// 查询窗口 [from_ms, to_ms] 内的所有条目（按时间排序）
    pub fn query_window(&self, from_ms: u32, to_ms: u32) -> Vec<(u32, &T)> {
        let mut result: Vec<_> = self.entries.iter()
            .flatten()
            .filter(|e| e.t_ms >= from_ms && e.t_ms <= to_ms)
            .map(|e| (e.t_ms, &e.value))
            .collect();
        result.sort_by_key(|(t, _)| *t);
        result
    }

    /// 当前有效条目数
    pub fn len(&self) -> usize {
        self.len
    }

    pub fn is_empty(&self) -> bool {
        self.len == 0
    }
}
```

### 5.4 公式引擎扩展

为 `FormulaExpression` 新增两个变体，使数据配置层可以直接引用历史值：

```rust
pub enum FormulaExpression {
    // ===== 现有变体 =====
    Constant(f64),
    ActorAttr { actor: ActorId, attr_key: String },
    ActorHpCurrent(ActorId),
    ActorHpMax(ActorId),
    Add(Vec<FormulaExpression>),
    Multiply(Vec<FormulaExpression>),

    // ===== 新增变体 =====
    /// 查询 actor 在 delay_ms 毫秒前的属性值
    /// 用途：艾克 R 回溯 — ActorAttrAtPast { actor: Self, attr: "hp", delay_ms: 4000 }
    ActorAttrAtPast {
        actor: ActorId,
        attr_key: String,
        delay_ms: u32,
    },

    /// 查询 actor 在 [now - window_ms, now] 窗口内的累计受伤
    /// 用途：腕豪 W — DamageTakenInWindow { actor: Self, window_ms: 4000 }
    DamageTakenInWindow {
        actor: ActorId,
        window_ms: u32,
    },
}
```

对应的求值逻辑：

```rust
fn eval_formula(expr: &FormulaExpression, ctx: &FormulaContext) -> f64 {
    match expr {
        // ... 现有分支 ...

        FormulaExpression::ActorAttrAtPast { actor, attr_key, delay_ms } => {
            let target_ms = ctx.now_ms.saturating_sub(*delay_ms);
            let actor_rt = ctx.get_actor(*actor);
            match actor_rt.state_history.as_ref() {
                Some(history) => match attr_key.as_str() {
                    "hp" => history.query_at(target_ms)
                        .map(|s| s.hp_current).unwrap_or(actor_rt.hp_current),
                    "mana" => history.query_at(target_ms)
                        .map(|s| s.mana_current).unwrap_or(actor_rt.mana_current),
                    _ => actor_rt.attr(attr_key), // fallback 当前值
                },
                None => actor_rt.attr(attr_key), // 无历史时 fallback 当前值
            }
        }

        FormulaExpression::DamageTakenInWindow { actor, window_ms } => {
            let from = ctx.now_ms.saturating_sub(*window_ms);
            let actor_rt = ctx.get_actor(*actor);
            match actor_rt.damage_taken_window.as_ref() {
                Some(window) => window.aggregate_window(from, ctx.now_ms, 0.0, |acc, entry| {
                    acc + entry.amount
                }),
                None => 0.0,
            }
        }
    }
}
```

## 7. 内存与性能预算

| 配置 | 窗口时长 | 采样间隔 | Slot 数 | 单 Slot 大小（估算） | 总内存 |
|------|---------|---------|---------|---------------------|--------|
| 状态快照（ActorSnapshot） | 5000ms | 100ms | 51 | ~40 bytes | ~2 KB |
| 受伤记录（DamageReceivedEntry） | 4000ms | 逐事件 ~80 | 80 | ~48 bytes | ~4 KB |
| 命中记录（HitReceivedEntry） | 3000ms | 逐事件 ~60 | 60 | ~40 bytes | ~2.4 KB |

**最坏情况：每个 actor 全部启用 ≈ 8.4 KB**，WASM 线性内存中完全可接受。

## 9. 扩展性考量

- **多窗口并存**：同一 actor 可挂载多个不同 `window_ms` 的 buffer（如被动 3 秒窗口 + 大招 5 秒窗口）
- **分类累计**：`DamageReceivedEntry` 携带 `damage_type`，可按物理/魔法/真实分别累计
- **衰减权重**：`aggregate_window` 的回调中可引入时间衰减因子 $w(t) = e^{-\lambda(t_{now}-t)}$
- **与通用 Buff 系统联动**：将来 buff 框架就位后，`ActorSnapshot` 可记录 buff 列表摘要，支持更复杂的回溯（如回到没有某个 debuff 时的状态）
