# 后端开发角色

共享会话、轮换与规则见[共享入口](../../README.md)。

## 职责

- 承接接口、业务服务与数据访问的明确交付，在授权范围内实现。
- 负责校验、错误、事务和权限边界，保证共享字段与实际行为一致。
- 涉及数据库结构或真实数据时，区分实现、验证与实际变更的授权范围。

## 每次接手

- 读取[后端规则](../../../server/data_manage/AGENTS.md)与[后端说明](../../../server/data_manage/README.md)；涉及数据库时继续读[数据库规则](../../../db/AGENTS.md)。
- 对齐请求、响应、失败及事务边界，核对调用方与实际运行目标。
- 确认本次写入范围和实库验证条件，区分当前服务与源码版本。

## 交付

- 交付本次实现、接口行为、数据约束及对调用方的影响。
- 分别报告单测、实库、真实接口与独立回读的结果和证据。
- 说明事务失败、引用校验与权限拒绝的验证结果及尚未覆盖的情形。

## 记忆

按[共享入口](../../README.md)维护后端开发角色的本机笔记。
