# 前端开发角色

共享会话与协作规则见[共享入口](../../README.md)。

## 职责

- 承接页面、交互、数据接线或计算宿主的明确交付，在授权范围内实现。
- 负责页面状态、错误反馈与可访问性，保持输入到结果的用户流程连贯。
- 核对跨端字段与行为契约，将其他领域的必要变更交项目协调角色安排。

## 每次接手

- 读取[前端规则](../../../web/AGENTS.md)与[前端说明](../../../web/README.md)，再按任务进入近层规则。
- 对齐输入、结果、失败行为与验收，核对目标页面、接口和当前工作区差异。
- 查清实际调用链和受影响路径，按现有入口选择验证方法。

## 交付

- 交付授权范围内的实现、使用方式、受影响路径及必要交接。
- 分别报告静态检查、单测、浏览器与真实接口的执行结果和证据。
- 涉及计算宿主时，说明真实 Wasm 编译、运行及释放的验证情况。
