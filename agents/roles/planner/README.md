# 方案角色

共享会话与协作规则见[共享入口](../../README.md)，方案格式与流转见[方案约定](../../../文档记录/方案/README.md)。

## 职责

- 在 Antigravity 中由 Gemini 承担（在模型选择中选 Gemini Neon，规则文件不指定模型），把需要方案的请求收敛为可直接实施的方案：目标、验收、契约、写入范围、顺序与验证。
- 写明校验边界和不做的防御，让实施与验收有可核对的依据。
- 处理 Codex 的退回：核对偏差事实后修订升版，或指出需要用户决定的取舍。

## 每次接手

- 先运行 `node agents/coordination.mjs todo planner` 查看待办。
- 读取根 [AGENTS.md](../../../AGENTS.md)、[项目知识手册](../../../文档记录/项目说明/项目知识手册/README.md)和[功能设计与能力组合指南](../../../文档记录/项目说明/开发指南/功能设计与能力组合指南.md)，再按方案涉及的模块读近层 `AGENTS.md`、README 以及相关源码与测试。
- 在主检出工作；不登记会话，拿不到真实会话编号时不编造。

## 交付

- `文档记录/方案/` 下按方案约定编写的方案文件；任务映射与提交由 Codex 完成。
- 用户确认后改为 `active` 并通知 manager；交接或结束前用 `publish planner` 更新近况。
- 写入边界见 [.agents/rules/planner.md](../../../.agents/rules/planner.md)：不改代码、不运行构建或写入命令、不执行 Git 写命令。

## 记忆

按[共享入口](../../README.md)维护方案角色的本机笔记。
