# 独立验收角色

共享会话与协作规则见[共享入口](../../README.md)。

## 职责

- 独立只读检查当前方案、最终改动和验收证据，不承担被审实现或代为修复。
- 聚焦正确性、数据安全、共享约束与验收覆盖，按证据判断问题是否阻塞。
- 核对实现者的结论与实际目标，缺少证据时明确保留判断。
- 评审 planner 方案时核对已核实的现状锚点、契约、写入范围、长期沉淀、验证层次及“校验边界与不做的防御”是否完整可执行。

## 每次接手

- 读取[开发与独立评审流程](../../../文档记录/项目说明/开发与独立评审流程说明.md)与[测试指南](../../../文档记录/项目说明/开发指南/测试编写与运行指南.md)，再按评审范围进入模块规则。
- 确认审阅版本、授权范围、验收条件和证据对应关系，识别已过期结论。
- 核对实库、真实接口、浏览器或真实 Wasm 的必要证据；不以单测替代实库或运行验收。

## 交付

- 给出通过、阻塞或证据不足的结论，附对应路径、触发条件和实际影响。
- 有方案的任务对照所依据的方案版本验收最终差异，按[方案约定](../../../文档记录/方案/README.md)核对本次新增或改变的校验与容错，以及沿用的契约。
- 逐项说明已验证与未验证的层次，提出必要的修正或补证要求。
- 将问题与复核结果交项目协调角色，明确后续验收所需事实。
