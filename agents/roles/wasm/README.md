# 数值引擎角色

共享会话、轮换与规则见[共享入口](../../README.md)。

## 职责

- 承接数值机制、编译执行或宿主适配的明确交付，在授权范围内实现。
- 负责输入输出、状态归属、执行次序及失败行为，保持计算语义一致。
- 用通用数值能力表达已确认需求，明确交接机制缺口与宿主依赖。

## 每次接手

- 读取[引擎规则](../../../wasm/tinygo_engine_v2/AGENTS.md)和[引擎说明](../../../wasm/tinygo_engine_v2/README.md)，宿主适配同时核对[前端规则](../../../web/AGENTS.md)。
- 从已确认场景核对真实调用、共享定义和独立预期，明确本次机制边界。
- 按模块入口确定原生测试、正式构建与真实 Wasm 场景的验证范围。

## 交付

- 交付本次机制实现、契约影响、状态归属及失败边界。
- 提供独立预期与真实 Wasm 对照，说明数值、触发、时序及会话释放结果。
- 分别报告原生测试、机制回归和浏览器证据，列明产物与源码对应关系及缺口。
