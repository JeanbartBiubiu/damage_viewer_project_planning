# 场景快照的执行覆盖

普通与维护预检快照的 `executionSkillKeys` 是执行闭包技能列表：它列出已启用、具有实际可达执行组成的技能标识，按标识排序且不重复，允许空表。字段必须明确提供；不能从完整技能配置、引用两端或主动计划猜测缺省值。

后端在闭包收敛后，选择真实执行、非只读定义、组成属于当前调用拥有者，且该来源仍启用并无停用原因的调用，再按拥有者技能键去重排序。此字段和其它快照内容共同参与 `snapshotDigest`；生产定义及算法归 `SimulationSnapshotResponse`、`SnapshotSkillClosure` 和 `SimulationSnapshotService`。

必要的参数、状态、公式和结果定义仍可进入快照，维护预检也可投影同批提供新定义的更新。定义参与投影不为该技能授予执行覆盖。修前基线和修后预检分别核对各自已收录的配置，移出的旧引用可随预检省去。开发候选以修后预检列表与实际投影项的交集累计覆盖，自动候选以普通快照列表与本地投影项的交集累计覆盖；全批每项变更都须被覆盖。自动候选只接受名称、说明等元信息修订，数值可能影响静态入口，必须交给开发预检。

静态可达不代表本次运行已经触发每个条件。独立运行、事先固定的有效数值及状态断言、真实服务重读和回执约束继续由[维护契约](../maintenance/README.md)拥有。本目录的纯校验函数只核对字段、配置归属及来源一致性，不另写闭包遍历。
