# 分阶段命中与攻击起始状态契约

本文件是本轮新增共享字段与运行语义的唯一说明。用于妮蔻Q、W被动、R暴露的公共缺口；数值及排除范围见同目录《妮蔻数值适配范围》。实施前独立评审已接受以下边界，最终产物仍需独立检查。

## 同次施放中的分阶段命中

作者的技能实际命中事件（`SKILL_HIT`）保留 `sourceSkillKey`。显式分阶段规则新增可选 `processMoment` 对象，字段如下：

| 字段 | 约束 |
| --- | --- |
| `processKey` | 同一技能真实首次主动过程的标识。 |
| `moment` | 只允许 `{momentType: 'STEP_EXECUTION', stepKey: <真实步骤>}`；步骤执行时尝试本阶段真实命中，不把步骤完成本身视为命中。 |
| `requiresPriorStepKey` | 明确为 `null` 或同过程严格更早且有命中规则的步骤；表示本次使用需要该阶段已有提交的真实接触。 |

省略 `processMoment` 的现有单次末尾命中保持原行为；一个实际过程不得混合隐式末尾与显式阶段规则。同一步骤的全部规则合并为一个完整命中绑定，其依赖必须一致；不能逐规则制造多次接触。禁止空阶段、悬空引用、跨过程依赖、自引用、前向依赖和含糊的排序；同一技能、来源、过程和使用身份贯穿全部阶段。

宿主将依赖降低为命中绑定的可选 `requiresPriorHitBindingKey`，只可引用同一绑定中实际步骤严格更早的命中绑定。原生编译重新校验完整图，不信任宿主校验。最多64个命中绑定，可用当前使用实例内的位集合保存已提交的真实接触；每次新的使用重新清空。

前置命中被法术护盾阻挡仍属于真实接触，未命中、动作拒绝、未提交或预算失败不属于。资格来自真实提交，与是否有伤害、是否扣血、是否保留详细记录无关。依赖不满足时跳过该阶段实际命中，不增加命中序号、不发布命中事件、不消耗法盾、不造成伤害；其有限等待步骤可以按原排程完成。

每次接触使用原始使用身份与递增命中序号。法盾仍按作者范围判定：Q各段使用独立伤害实例；R早期击飞与落地伤害加眩晕分别判定，落地同次伤害和眩晕共同阻挡，禁止将两次接触合为整次技能阻挡。普通持续/周期伤害形状不能被即时命中编译器误译成立即伤害；不支持的形状明确拒绝。

显式简单步骤命中过程在最终过程快照输出 `skillHitStages`，不受详细记录预算截断；尚未执行时为明确空数组，旧隐式过程不输出。每项含 `hitBindingKey / stepKey / timeMs / released / contact / completed`。时间来自真实执行；依赖不足为释放否、接触否、完成是，未命中为释放是、接触否、完成是，被盾为三项是。沿既有分段提交，预算或错误可能发生在根接触已提交而伤害未完成之间，此时接触是、完成否，不能授予后续资格；只有完整成功且有接触才授予前置位。记录为零时事实仍完整；外来阶段事实不得恢复成运行资格。

主动固定计划和自动调度都允许1至64个明确行动占用的即时或有限延时步骤；本轮新增多步显式阶段及自动普通链至少有一段正延时，旧单即时仍合法，不增加无界调度。现有复杂步骤的准入不扩大；自动结果完整性和来源映射必须同步认识有限延时序列。

Q用250毫秒占用、750毫秒自由、750毫秒自由三个步骤，后两段都依赖首段真实接触。R用1250毫秒自由准备和600毫秒占用两个步骤。准备期发动的其它过程继续按已有排程完成；锁定只阻止新的动作，不抢占、取消其它过程或推迟R。以上属于本轮明确的数值模型。

## 普通攻击起始时的自然计数快照

作者使用现有内部状态检查 `INTERNAL_STATE_CHECK` 的 `ATTACK_START_VALUE`。本轮仅开放攻击方、同技能、技能范围整数计数器（`SKILL/COUNTER`）在真实普通攻击开始或命中监听中的读取。作者不能指定任意其它来源挂载或读取目标状态。

宿主生成 `use.provider_state_before.<编译后状态键>` 的读取。原生编译只接受同拥有者、同实际供值器挂载且位于上述监听因果图的读取，记录确切需要捕获的计数字段。普通攻击开始时，在该事件的任何监听器写入之前，按本次使用身份捕获实际计数；该次开始与对应命中均读取这份冻结值。缺少捕获、错误使用、来源或字段必须失败，不能退回当前状态或全局最近值。没有此类读取的现有来源不增加每次攻击的捕获分配。

W被动：起始快照为2时，开始动作消费为0并施加本场1000毫秒加速；对应真实命中才产生一笔额外魔伤，且不再叠一层。快照小于2的真实命中才叠一层。未命中不撤销已提交的开始消费或加速，不叠层、不补附伤。初始0至2由无默认值的场景参数声明。

来源有限总属性乘算仅开放明确单层实例，增加比例非负、减少比例为0至1；在所有平加之后的总值阶段计算，期满乘数恢复1。不能通过普通属性乘数绕过生命上限账本。手算用例同时保留基础100、稍后平加20与10%总移速，结果必须为132，不能按修正排列顺序得到130。
