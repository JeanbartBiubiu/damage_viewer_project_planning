# 自身普通盾首次受损启动既有等待

本契约只补用户已确认的墨菲特P分支：等待尚未启动时，本来源自身P盾第一次实际吸收伤害，开始一次8/7/6秒等待；已等待时纯损盾不重置，实际扣血继续重置。用户确认见本机 `outputs/skill-adaptation-20261021-malphite/P首次损盾起计确认.json`，恢复方法见[外置归档索引](../../数据参考/外置归档索引.md)。沿用原补盾、等待状态、同刻到期保护和W护甲联动；Q/W/E/R不重新实现。

## 管理字段与引用

`EVENT_VALUE_COMPARE`（事件值比较）的明细增加可选`shieldResult`（指定自身盾结果），仅与`DAMAGE_TAKEN`（受到伤害）及`SHIELD_ABSORBED`（吸收量）一起使用：

```json
{
  "eventValueKey": "SHIELD_ABSORBED",
  "shieldResult": {
    "skillKey": "malphite_p",
    "effectKey": "granite_shield",
    "resultKey": "shield"
  },
  "comparator": "GT",
  "comparisonValue": { "kind": "FIXED", "value": 0 }
}
```

三段身份必须完整、合法且属于当前技能的自身普通盾结果；示例效果、结果键以实际回读为准。盾须为单层、唯一普通盾终止生命周期，不能引用目标盾、法术盾或其它技能。复用现有普通盾结构校验及完整结果引用索引，在保存和最终事务图校验，反向删除或改变类型也要受保护。不改表结构，不迁移数据。

显式null、空对象、额外字段及在其它事件值夹带该字段均拒绝。省略时，既有管理层总吸收量定义保持；宿主仍拒绝没有显式自身盾引用的吸收量读取，不猜默认盾。管理客户端响应解析、类型、表单和回填必须保留该选择器，切换不适用事件值时清除它。

## 降低与真实事实

宿主将完整盾结果降低为`event.damage.linked_shield[完整静态盾定义引用].absorbed`（本笔指定盾吸收额），只在真实受伤监听条件中读取；比较右值沿现有数值取值。监听的匹配条件必须同时要求真实受伤及事件目标为监听拥有者。原生编译独立绑定完整盾定义与关联供值定义，校验真实拥有者、父挂载及创建闭包，不以宿主标记或字符串前缀授权。

首版只允许同拥有者该自然父定义有唯一真实挂载，所选盾的创建操作均来自该父定义且目标为自身、关联定义唯一。重复父挂载、外部父创建同盾、不完整初态及未授权公式语境明确拒绝；不扩大运行存档恢复范围。关闭来源、另一方同名技能及其它装备盾均不能充当本来源P盾。W附着在P关联盾的静态属性仍沿既有机制运输。

实际护盾结算循环保留每面盾的真实吸收行，含`shieldRef`、`definitionRef`、`lifecycleProviderRef`、`source`、`owner`、`remainingBefore`、`remainingAfter`、`absorbed`，只记录正吸收，顺序沿既有优先级和真实盾引用。全部行合计等于原总吸收；读取只合计被绑定定义和关联身份、且来源与拥有者均为本监听拥有者的行。耗尽盾移除后仍读本笔冻结事实，不能事后查活跃盾列表。

固定场景中的另一面自身初始盾沿真实来源初始化施加。对没有到期状态的普通关联盾，只接纳唯一静态自身父、真实初始化匹配、单个无条件自身盾操作、有限非负静态金额、同技能单层无期限替换及完整关联身份；不把初始化事件加入通用命中准入，也不添加空监听或虚构计时器。已有带到期状态的初始化路径保留原校验。

没有新读取的会话不采集、不增加逐伤害分配。有读取会话带明确采集完成标记；已采集而没有指定盾吸收返回0，缺事实、缺真实事件或归属不符报错。事实随实际成功伤害帧产生，沿原受伤事件只读共享，不为每个监听复制或新增逐事件映射。详细受伤证据增加`shieldAbsorptions`（逐盾吸收行）并绑定原伤害身份；汇总、零明细及重放不改变数值。

只允许真实已挂载受伤监听的条件依赖读取。展开具名公式及全部条件分支检查，主动金额、监听操作金额、全局修正、伤害发出方、聚合伤害及伪造事件不授权。运行再次核对事件和挂载身份。沿既有父伤害提交、监听子帧原子性及队列预检处理失败，不半提交状态写入或回调。

## 原规则接线与复制边界

P仍只有原`damage_restarts_wait`受伤监听。给它增加一个并列条件组，完整表达式为：

```text
实际扣血 > 0
或（本技能等待状态 == 0 且 指定自身P盾本笔吸收 > 0）
```

两组共用原`restart_wait`动作，不创建第二个监听或新计时器。同笔既损盾又扣血只执行一次。精确到期尚未提交时继续沿原状态保留规则，纯盾伤不能误进首次分支；真实扣血更新原世代，使旧回调失效。

当前复制附伤重放没有派发受伤事件。为避免新分支静默漏算，含新读取的会话在完整操作编译后拒绝`OperationKindRepeat`（当前只支持复制附伤的操作）；无新读取会话保持原语义。单独的可复制命中标记不等于发生重放，普通多段过程和驱动重复不属此禁用范围。不扩所有旧监听的派发。无装备墨菲特代表矩阵不包含这类复制操作。
