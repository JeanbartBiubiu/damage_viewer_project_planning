# 卡特琳娜最小验证数据采集清单

## 1. 目标
- 先完成一个可跑通的 WASM MVP（后端取 bundle -> 前端组装 -> run 出结果）。
- 再扩展到你定义的完整验证（6 装 + 2 天赋 + 假人防御装备）。

## 2. 分阶段范围

### 阶段 A（先跑通 MVP）
- 英雄：卡特琳娜（self）+ 假人（enemy）
- 技能：平A、R（大招）
- 装备：先选 2 件（建议：破败、纳什之牙）
- 天赋：先不做真实天赋系统，先按“伪装备”方式预留

### 阶段 B（完整验证）
- 装备扩展到 6 件：
  - 破败
  - 纳什之牙
  - 育恩塔尔荒野箭
  - 兰德里的折磨
  - 羊刀
  - 界弓
- 天赋：致命节奏、征服者（建议先按 item/rune 伪物品落库）
- 假人：10000 HP / 100 护甲 / 100 魔抗，可加布甲鞋、冰心

## 3. 必收集的“可入库”数据（按后端校验要求）

### 3.1 基础标识
- `gameId`：`lol`
- `versionCode`：例如 `mvp_katarina_001`
- `owner_categories`：至少要有 `hero`、`item`（如要符文建议再加 `rune`）

### 3.2 属性定义（attribute_definitions）
至少收集这些 `attrKey`（可后续再补）：
- `hp`
- `ad`
- `ap`
- `attack_speed`
- `armor`
- `magic_resist`
- `ability_haste`
- `physical_pen`
- `magic_pen`

每个属性至少给：
- `attrKey`
- `attrName`
- `attrType`（建议 `number`）
- `defaultValue`

### 3.3 英雄（heroes）
卡特琳娜与假人都要有：
- `heroId`
- `name`
- `baseStats`（必须）
- `statsByLevel`（可选）

建议 ID：
- `hero_katarina`
- `hero_dummy_10000hp_100ar_100mr`

### 3.4 技能（skills）
至少准备：
- 卡特平A技能（可作为统一技能事件入口）
- 卡特R技能

每个技能必须有：
- `skillId`
- `ownerType`（如 `hero`）
- `ownerId`（卡特 heroId）
- `mechanicsConfig`（必须，且 `version=1`，`triggers` 必须是数组）

### 3.5 装备（items）
每个装备建议收集：
- `itemId`
- `name`
- `statsModifier`
- `skillRefs`（如果装备有被动/主动技能）
- `recipeIds`（可先空数组）

注意：
- 如果填了 `skillRefs`，引用的技能必须已存在。

### 3.6 天赋（先按 MVP 方案）
当前引擎 run 输入没有独立 `runeIds`，建议先按“伪装备”处理：
- `item_rune_lethal_tempo`
- `item_rune_conqueror`

## 4. 关键命名与映射（先定死，避免后续返工）
请你采集时明确以下“待确认项”：
1. “大招减 CD + 攻速装备”具体是哪件（中文名 + 英文名 + 版本号）。
2. “面具”具体是哪件。
3. “加双抗弓”具体是哪件。
4. 每件装备的唯一 `itemId` 命名规则（建议全小写下划线）。

## 5. 场景矩阵（用于验证）

### 5.1 基线场景（必须）
- S0：卡特无装备无天赋，打假人（平A 10 下）
- S1：卡特无装备无天赋，打假人（完整 R）

### 5.2 装备场景
- S2~S7：逐件装备对比（每次只加 1 件）
- S8：6 装全开

### 5.3 天赋场景
- S9：6 装 + 致命节奏
- S10：6 装 + 征服者

### 5.4 假人防御变化
- S11：假人加布甲鞋
- S12：假人加冰心

## 6. 入库顺序（建议）
1. SQL：插入 `games`、`owner_categories`
2. API：创建版本 `POST /api/admin/games/{gameId}/versions`
3. API：写入 `attribute_definitions`
4. API：写入 `heroes`
5. API：写入 `skills`
6. API：写入 `items`
7. API：发布 `POST /api/admin/games/{gameId}/versions/{versionId}:publish`
8. Public API：拉 `current` + `bundle` 给前端/WASM

## 7. 数据采集时的填空模板

### 7.1 装备模板
```json
{
  "itemId": "item_xxx",
  "name": "装备名",
  "statsModifier": {},
  "skillRefs": [],
  "recipeIds": []
}
```

### 7.2 技能模板
```json
{
  "skillId": "skill_xxx",
  "ownerType": "hero",
  "ownerId": "hero_katarina",
  "skillKey": "R",
  "name": "技能名",
  "mechanicsConfig": {
    "version": 1,
    "triggers": []
  }
}
```

### 7.3 英雄模板
```json
{
  "heroId": "hero_katarina",
  "name": "卡特琳娜",
  "baseStats": {},
  "statsByLevel": {}
}
```
