# 盖伦技能录入候选

本目录供通过管理页面逐项录入。已准备 **5 个技能、38 个参数、7 个公式、13 个效果、1 个内部计数器、2 个有界过程候选、2 条触发规则**。完整字段在 [盖伦技能录入候选.json](盖伦技能录入候选.json)，每个技能的 `componentNotes`、`blockedRecipes`、`gaps` 分别说明录入前提、尚不能表达的流程和待核机制。

这是来源与录入候选，尚未通过页面保存或运行验收；不能把“参数可保存”记为“英雄技能全部完成”。仅涵盖召唤师峡谷与常规 1–18 级，竞技场、海克斯大乱斗及模式覆盖均不采用。上路任务 19–20 级另记边界。

推荐顺序：技能主体和图片 → 参数 → 公式 → 需要的状态/乘区 → 效果 → 确认前提后的过程/规则 → 关联 `champion_garen` → 页面回读关键值。图片直接在技能页面上传，`imageSource` 提供官方对应图标地址。建议键为 `garen_p/q/w/e/r`，不是已核实存在的技能键；若页面已有对象，应合并到已知对象并同步公式/规则引用，避免重复。

伤害键已按主负责人真实页面回读映射为 `physics`、`magic`、`real`；属性比例乘区映射为 `attribute_percent_bonus`。仍有 3 个明确占位项：`$减速状态键`、`$沉默状态键`、`$承受伤害比例乘区键`。它们不是合法的现有目录引用，先建/核对后替换。技能分类目录未核，候选不猜分类键。

## 容易录错的地方

- Q 整次非暴击普攻的客户端提示是“基础值 + 1.5 总攻击力”。系统已有普通攻击时，这里只录**额外基础值 + 0.5 总攻击力**，避免重复普通攻击。普攻部分可以暴击，额外部分不暴击。
- W 盾按**额外生命**计算。满层再加 10% 双抗已删除。减伤拆成物理/魔法结果，避免错误降低真实伤害。按[普通护盾契约](../../../文档记录/详细设计/项目/伤害与普通护盾交互基础详细设计.md)，护盾耗尽会结束所属效果；护盾与韧性因此拆为两个独立效果，共用 750 毫秒参数并在施放开始分别挂接，避免韧性提前消失。此为配置核对，没有执行护盾破裂场景。
- E 当前暴击倍率为 `1.3 + 0.3 × critical_strike_damage_bonus_percent`；该属性是额外暴伤百分点，额外 0.3 时 E 倍率为 1.39。不要用固定 1.3，也不要套旧的总暴击倍率 80%。
- E 已删除随英雄等级增加的每圈附加伤害、150% 野怪伤害和提前结束冷却返还。不能把 E 当作普通受控就中断的引导，也不能固定 7 圈掩盖取整/来源缺口。
- R 是普通真实伤害，仍可能被护盾吸收；不使用系统“处决”结果。触发规则依赖实际 `SKILL_HIT`，不在点击施放时立即造成伤害。
- 百分比统一 `1=100%`；所有时间参数为毫秒。普通吸血应落在游戏级规则，当前空 `vampRules` 不代表技能没有吸血。Q 额外伤害的生命偷取例外与 E 对小兵的全能吸血效率另待统一处理。

## 来源和支持边界

数值优先级：已冻结的 16.17 客户端原字段 → 同期官方补丁交叉确认 → 16.17.1 官方 Data Dragon 名称、图标、等级、冷却、说明 → 非同版本 Wiki 机制补充。Data Dragon 空变量和全零占位数组不能填成技能真实数值。CommunityDragon 是社区对客户端文件的提取，不能称为 Riot 官方接口，也不能证明它包含完整服务端技能脚本。

源文件、原始响应校验值见 [客户端技能原字段.json](客户端技能原字段.json) 和候选文件的 `sourceFiles`；完整原始响应保留在相邻英雄资料目录，本目录不再复制。相关官方依据：

## 可复现检查

在本目录运行 `node 生成候选.mjs`，只重新生成候选和原字段摘录；源响应校验值不符即停止。然后运行 `node 核对候选.mjs` 检查已冻结来源、公式引用、关键数学样例和当前前端类型。整个过程不读写业务接口/数据库，不修改其他路径。
