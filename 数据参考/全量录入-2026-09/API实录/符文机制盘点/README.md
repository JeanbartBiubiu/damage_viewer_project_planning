# 62 个符文机制盘点

已完整遍历固定版本的 62 个基石与小符文（17 基石、45 小符文），不含 7 个属性碎片。每个身份保持原来的唯一 `rune_ID`，拆分结果与原对象逐一对应；本轮只读取接口并生成候选，没有业务写入、页面操作、服务变更或 Git 提交。

最终统计：**43 项范围内、12 项混合保留、7 项范围外**。共 115 个分支：71 个范围内效果、25 个保留的成长或条件依赖、19 个范围外分支。34 项明确缺少部分数值、曲线或精确计量规则；另外 21 项已见明确数值，但触发、组合或管理能力缺口分别列出。范围分类和可完整录入程度是两个不同维度。

`逐项机器清单.json` 给出全部 62 项的分支、逐条原文依据、已确定事实、具体缺值、现行结构可录组成和剩余条件。整项范围外的 7 个是：第六感、深入守卫、寻宝猎人、海克斯科技闪现罗网、返现、守护者、爆破。守护者的自身护盾同样依赖友军守护关系，不能抽成无条件自身护盾；海克斯闪现只有位置改变及替换，没有独立伤害、治疗或属性组成。

只有欢欣基础攻速、超然明确等级急速、复苏基础强度这三个独立组成带来源初始化规则。其余有条件效果没有被补成无条件规则；不灭的两个治疗分支、气定神闲的不同资源分支也不能同时执行。现有技能查询只记录实际结果，没有固定断言技能总数。

每个候选另有 `executionQualification`，列出适用资格、必需计算输入和不得默认的条件。依现行技能参数与公式契约，生命/法力/能量的 `TOTAL` 是包含当前加成的最大值，`MISSING = max(TOTAL - CURRENT, 0)`；凯旋及不灭均读取持有者 `SOURCE`，不读取敌方最大生命。核对时显式提供当前值，不以缺省满血或空资源替代真实输入。公式输出是配置回复额：例如凯旋在最大生命 2000、当前生命 2000 时公式仍为 50，这不表示实际能增加 50 当前生命；实际恢复量需另经战斗结算。

凯旋的参与击杀目标资格、助攻及治疗时点尚未由本批补齐，不能把任何 `KILL` 当作合格事件。法力流的门槛是本符文累计额外法力 250，不是角色总法力达到 250；气定神闲没有默认角色同时拥有法力和能量。传奇层数、药剂消费、黑暗收割灵魂、近远程类型及控制结束时点均未设默认。

## 三类容易误删或误配的分支

- **三重补药分别处理。** 原力合剂和技能合剂都影响单挑。官方装备 2152 明确 25 适应之力持续 60 秒，2150 明确提供 1 技能点、不会提升角色等级、不能投入已满级技能；技能点不能当作经验排除。只有 2151 对小兵的伤害和金币分支范围外。相关装备主体已经存在，后续不能重复创建或把持有当成已消耗。
- **冰川与艾黎不能整项排除。** 冰川减速作用于敌人，持有者能够受益；只有文字明确“不包括你自己”的队友减伤排除。艾黎保留对敌伤害以及返回前不可再次派出的约束，仅排除友军护盾；不能凭名称“召唤”跳过，也不能用任意固定冷却代替返回等待。
- **成长依赖保留。** 传说系列及过度生长的小兵、野怪进度会改变英雄属性，属于需保留的成长输入，不因为对象不是英雄而丢失。严格单挑可以不模拟小兵战斗，但已有层数、充能、物品消耗和获得条件必须有明确来源。

范围外 7 项另有 `范围外跨技能依赖.json`：逐项保留排除依据、其他符文的原文关联和证据局限。寻宝金币排除不会删除终极/无情猎人仍需的独特英雄参与击杀事实；海克斯闪现的闪烁类别与猛然冲击、灵光披风的具体触发归属仍需核对，不能当作已确认或直接忽略；守护者排除不等于删除其他合法新护盾及护盾猛击。对塔伤害排除也不据此清空其他符文已确认的战前攻击充能。另发 7 个 GET，当前这 7 项均无技能挂载；这只能证明当前管理数据，不证明客户端玩法不存在间接依赖。

## 录入体验与核对

1. 要同时读长说明和提示文本：强攻的客户端提示额外给出 6 秒三击冷却；吸收生命力虽由客户端补出 1–23 端点，仍不足以填写完整等级表；生命源泉两份资料都没有完整治疗数值。
2. 百分数必须先区分属性单位和结算基数。比例类属性固定增加 0.03 与“把当前总属性乘 1.03”不同；冰川的治疗护盾强度、法强和额外攻击力系数分别换算，不能把 90% 每 100% 误当 90 倍。
3. 状态名、事件名和结果类型可以选择，不代表组合正确。坚定的 2 秒从控制结束起算；艾黎需要返回事件；冥火“每秒伤害”不能直接推定每秒恰好一跳。缺口已逐项保留。
4. 独立组成可以先保存，完整度必须单独记账。没有默认满层、默认返回、默认自适应类型或默认伤害包暴击/吸血设置；参数存在和技能启用也不意味着符文机制已完整。

`独立校验结果.json` 已验证 62 个唯一身份、115 条分支原文依据、特殊混合范围、12 项候选资格、7 项范围外依赖依据及 11 个直接求值的公式算例，并核对超然等级断点。所有输出都在本目录；之前批次、共享进度、标准流程和应用代码未修改。

复现顺序为 `准备来源.mjs`、`目录只读.mjs`、`逐项拆分.mjs`、`下一批候选.mjs`、`范围外依赖只读.mjs`、`范围外跨技能依据.mjs`、`独立校验.mjs`，使用现有 Node.js 24。两个只读工具合计发出 14 个 GET，其余只读本地输入并生成本目录文件；所有工具拒绝额外参数，没有业务写入入口。没有下载新的玩法数据包，后续精确资料补证由选定批次按缺项处理。
