# 装备效果候选代表图 API 实录体验报告

范围为装备效果候选清单 134 件；原 47 件纯属性装备范围未从旧清单重复处理。图片来自官方 16.17.1 Data Dragon 原图，未重造、未更新浏览器缓存。

## 结果

134 件源图均成功下载并校验为 64×64 PNG，大小均不超过 262144 字节。134 件代表图关系最终独立 GET 核对全部 linked，未发现未关联、禁用或失败项。

其中 2 件创建了稳定键图片（duolanjie 对应 1056、item_3057）；131 件因系统中已有同名图片记录而按 409 后 GET 消歧，校验官方源图 hash、字节数、尺寸和启用状态后复用原图片键并建立关系；item_1043 已存在代表图关系，保留并跳过。

因图片名称唯一约束，复用同名图片的关系键多数为旧键 item_<id>，不是本轮稳定键 entry_16171_<equipmentKey>；证据逐项记录了 stable image GET 404、409 消歧、复用键和最终关系回读。未删除、覆盖或清空已有图片。

## 最终关系核对

`代表图关系最终核对.json` 记录 134 件独立 GET：linked 134、unlinked 0、disabled 0、failed 0。

## 证据

每件对象一个 JSON，记录官方 URL、源图 hash、字节数、尺寸、图片创建或复用、代表图 PUT 及独立 GET。脚本为 `record.mjs`，关系最终核对脚本为 `relation-audit.mjs`。效果、技能、装备数值和浏览器缓存均未修改。
