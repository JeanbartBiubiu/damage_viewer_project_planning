使用 Node.js 24，从本目录执行：

```text
node record-skills.mjs --limit=1
node record-skills.mjs --apply
node record-skills.mjs --relations-only --apply
```

不带 `--apply` 只读取和生成计划；写入固定使用本地 8080 的 `lol`。先全批预检，再按稳定键查重，每次保存后独立读取。已有 20 项已编写技能保留基本资料，其他项严格核对名称、说明、等级、状态、分类和排序。技能分类输入中的空白表示不选分类，不自动建立新的分类。
