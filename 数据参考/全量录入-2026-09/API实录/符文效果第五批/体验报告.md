# 第五批候选配置体验

本轮确定来源可以继续形成参数和公式，不需要为尚未证明的等级曲线、战斗事件或自适应选择填零。162 个内容请求及 12 个图片复用请求均只是候选，尚未执行。

最明显的来源问题是同对象的不同展示路径不一致。致命节奏的远程攻速及伤害、风暴聚集的攻击力都存在实际差异，不能用“计算树肯定优先”或“长说明肯定优先”静默替代。确定近战/法强分支保留，冲突分支使用无默认输入并保留两份原值。

本次还出现一个执行者自身的配置错误：看到 `attack_speed` 的每秒次数单位后，我先认定比例效果不可保存并撤除。主负责人指出同一目录已有 `bonus_attack_speed_percent`；单独 GET确认其说明“以1表示100%”后，最终把致命节奏近战效果改绑此属性。正确经验是先搜索相同业务词的全部目录，再核单位和修正区；这不是系统缺少能力，也不构成已冻结英雄批次存在错误的证据。初稿和中间态全部保留，未发生业务写入。

另外几项容易出错的操作已经体现在独立算例中：比例点需转为比例，公理秘术返还当前剩余冷却而非总冷却，征服者取实际伤害而非理论基础伤害，冥火保存每秒量而不是单跳或完整持续总量。技能属于群体分类仍可伤害当前单一目标；小兵触发的自身恢复也可能影响战前状态，不能按目标关键词整项删除。

本轮无需新增系统能力即可保存 31 个确定数学关系和两个独立属性组成。真实资格、取样时点、周期首跳、重复触发与属性选择尚未接线；存在可保存结构不能替代这些事实。最终检查为 826 项本地检查、36 个独立算例和 80 次只读请求，未进行浏览器或战斗运行验收。
