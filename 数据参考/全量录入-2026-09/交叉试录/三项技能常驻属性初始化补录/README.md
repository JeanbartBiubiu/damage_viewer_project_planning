# 三项技能常驻属性初始化补录

本目录保存克格莫Q、奥拉夫R和亚恒R三项常驻属性初始化规则的冻结、纯GET准备、独立批准、一次受保护写入、即时回读、独立回读、页面目标、真实浏览器验收和证据清单。

执行顺序固定为：`freeze`、`prepare`、`review`、`write`、`readback`、`targets`、真实浏览器验收、`manifest`。除 `freeze`、`targets` 和 `manifest` 外，接口模式都要求进程内非空 `DAMAGE_ENTRY_TOKEN`；令牌不保存、不输出。已经生成的证据文件拒绝覆盖，写入模式只允许冻结的三个POST。

页面只执行查询、查看、编辑查看和取消，不点击保存、删除、新增或停用。管理保存、Wasm组装、宿主初始化事件和真实战斗分别记账，不能互相替代。
