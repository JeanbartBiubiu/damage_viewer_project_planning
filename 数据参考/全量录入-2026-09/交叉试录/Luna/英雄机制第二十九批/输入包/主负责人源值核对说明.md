# 第二十九批来源核对：奥恩、慎

固定本地客户端16.17与官方16.17.1。10槽当前99次GET、11项既有公共参数，无非公共组成。根绑定和压缩前后散列已校验；复用已有主体、图片与关系。仅本轮1V1范围，不开展战斗运行验收。

## 数组与范围

客户端 DataValues 和 cooldownTime 的技能等级1从索引1开始；mana/manaValues 的消耗数组从索引0开始，并用官方五项cost数组交叉核对，不能统一切同一个起点。奥恩W法力45/50/55/60/65，E法力35/40/45/50/55；慎Q能量140/130/120/110/100。已有11项均正确，保持不变。能量不能写成法力；属性目录无能量时保留能量消耗和回复参数，记录资源接线缺口。

奥恩Q柱与R岩浆元素、慎Q魂刃是技能载体，不按自主召唤物排除。奥恩商店与铸造经济跳过，但升级杰作给自己的属性增幅、自己装备已经得到的额外属性仍与1V1相关；战前已有升级数量不能因需要队友历史而一并排除。慎W可保护自己，保留自身格挡。慎R只能选另一友方英雄，护盾和传送在本轮范围外；当前无既有组成，无需新录R。P“使用技能触发自身护盾”的通用条件仍保留，不为R虚构一个可独自在1V1施放的过程。

## 奥恩

P必须展开当前GameModeInteger=1的 spell_ornnp_tooltip_1 与 spell_ornnp_tooltipextended_1。实际正文明确生命、护甲、魔抗的加成属性提高10%，每完成一件杰作额外提高4%；摘要遗漏生命，不能按摘要少录。保留升级数量为无默认非负整数输入及10%+4%×数量的增幅公式；资料没有给当前模式允许的全部数量上限，不自行设为0、1或5。三个自身收益的应用前加成属性基准与反馈排除阶段需明确输入，不能拿已包含自身增益的最终值循环放大。13级可升级自身装备和之后升级队友的经济操作不录；升级后的自身属性收益接线单独待处理。未被正文使用的匿名90到10曲线不录。

Q伤害20/45/70/95/120 + 1.1总攻击力，物理；减速40%持续2000毫秒；柱持续4000毫秒供E交互保留。施法250与300毫秒冲突，不任选固定值。命中英雄短暂停滞、柱形成延迟和碰撞作为事件待接。

W共5次火焰，持续750毫秒；每次下限16/26/36/46/56，目标最大生命比例2.4/2.6/2.8/3/3.2%；当前正文的总比例12/13/14/15/16%，总下限80/130/180/230/280。对英雄有伤害下限，不能仅录百分比。可保存单次MAX(下限,目标最大生命×比例)以及五次总量的算术参照；实际每次取生命的阶段、首末时点继续接线，不假定平均间隔。BaseDamageTooltip100..300未被当前正文使用，不能覆盖真实总下限。野怪上限260..500排除。最后一道火焰施加易碎3000毫秒；下一次定身持续时间增加30%，并造成目标最大生命值9%到17%的等级相关额外魔法伤害；等级求值器未证，比例无默认输入，端点保留。自身普攻可触发击退与同一额外伤害，不能再把“额外伤害”重复计算两次。不可阻挡保留事件语义；原始自减速35%没有当前正文消费，只记来源待核，不固定挂增减益。施法250毫秒明确。

E伤害80/125/170/215/260 + 护甲项0.4 + 魔抗项0.4，物理。两个实际节点分别mStat1/formula2和mStat6/formula2；不能仅按ArmorRatio名称断定基础或最终口径。已有同构建bonusMR窄证可核对使用，护甲项应补查明确“额外护甲”映射证据，否则保留基准无默认输入。撞地形击飞1250毫秒。正文明确冲击波只给未被冲锋伤害的敌人造成同样伤害，因此同一敌人最多吃一次E伤害；击飞仍可作用已被冲锋命中的唯一敌人。Q柱可供碰撞，地形交互保留。施法250与350毫秒冲突。

R每程125/175/225 + 0.2法强魔法伤害，来回两次各自可击中唯一敌人；每程易碎3000毫秒。首程减速40/50/60%，客户端RSlowDuration为2000毫秒，但官方英文把正文减速也写进3000毫秒语句，中文没有明确减速时长，因此分开保留客户端值与文本冲突，不能声称两份来源一致。第二程第一英雄击飞1000毫秒；后续英雄500毫秒是第三目标分配，排除。本轮唯一敌人仍保留两程与两次易碎。施法250与500毫秒冲突。元素并非自主召唤。

## 慎

P当前ShieldValue默认明确指向{58a09e24}：等级基础护盾47到120 + 0.13额外生命，持续2500毫秒。另一个47到101 + 0.07额外生命分支没有当前ShieldValue消费，不能混用。已命名条件分支把完整默认护盾乘1.3，条件是指定buff；保留条件端点及buff键原件，不能假定默认已完成慎劫任务，也不根据任务名称虚构触发事件。基础冷却11000毫秒。ShieldCooldownReduction初始4秒、每级0.235秒且19级断点改0.125，显示精度1仅显示；实际等级求值与毫秒归整待核，保留无默认输入，不按显示精度造十毫秒或百毫秒数组。对唯一敌人的技能成功作用可缩短自身P冷却，队友收益分开排除。

Q强化普攻3次，窗口8000毫秒。基础附加伤害BaseFlatDamage是当前正文消费的tooltipOnly节点：等级1为10，4/7/10/13/16级各额外6；保留该阶梯来源与实际等级伤害输入，不用10+6×每一级。普通附加魔法伤害=实际等级固定伤害 + 目标最大生命×0.01×(2/2.5/3/3.5/4 + 0.015法强)；穿过敌方英雄后的强化比例=0.01×(5/5.5/6/6.5/7 + 0.02法强)，根0.01乘完整比例表达式。两种都是普攻额外伤害，不包含普通攻击物理伤害。穿过英雄后的这几次攻击获得50%攻速，属于次数消耗条件，不能把旧SteroidDuration=75当作75秒固定增益；8秒也是攻击窗口而非永远持续完整8秒。逃离慎方向时减速25/30/35/40/45%，持续2000毫秒，方向资格待接。兵野专用加伤/封顶和建筑伤害排除。没有明确施法时间，不补0。

W自身防御区域持续1750毫秒，区域无可保护英雄时最多等待2000毫秒；实际开启时机与普攻格挡需事件接线，不写成1750毫秒无敌或全伤害减免。仅作用队友部分跳过，自身保留。能量40，施法来源缺失不补0。

E伤害60/85/110/135/160 + 0.11额外生命，物理；对唯一英雄嘲讽1500毫秒。自身Q或E造成伤害可回复能量：当前等级节点1级30、4级增加10、12级增加10；保留具体断点与无默认当前等级回复值，资源目录未支持时不改写法力。能量150。兵野嘲讽的独立目标分配排除。没有明确施法时间，不补0。

R如上属于纯友方护盾与传送，本轮跳过，记录完整依据，不能算作系统无法录入。

## 独立核算重点

奥恩W每次伤害下限与总5次、E单敌只一次、R两程各一次及减速时长冲突；奥恩P按应用前基准增益，已升级数量必须给出。慎Q两个比例的根0.01、法强、技能等级起点、附加伤害身份；P完整护盾×1.3条件端点但不默认条件成立；能量cost与冷却数组分别取起点。所有未知输入缺失时拒绝求值，不补零。效应和事件接线待项与可存参数公式分别记录。
