## 使用入口

- `候选现况与哈希.json`：恢复开始时的原始文件范围、散列和计数。
- `最终候选.json`：供主负责人审查的派生修正版；原始候选散列写入其 `meta`，来源待核字段仍保留原始映射。
- `修正独立核对.json`：每项修正的原文、根值、旧值、反例、处置和失败情况。
- `最终独立来源与公式算例摘要.json`：最终公式集合的保留算例、缺输入检查和修正核对绑定。
- `最终写前计划.json`：最终版逐条新增请求体，以及 28 个完整复用对象和字段差异。
- `关联与图片保护快照.json`：角色主体、关联列表和代表图的实际只读结果。
- `体验与缺口.md`：本轮只读体验、保留范围和未接线边界。
- `最终交付清单.json`：最终文件散列和验收摘要。
- `冻结候选锁.json`：最终候选、请求计划和证据锁定信息；锁定不授权业务 POST、PUT 或 DELETE。

最终候选只表达可独立核对的数值和关系组成，不代表页面、数据库、战斗运行或 Wasm（浏览器运行模块）已经完成。缺少输入时不填默认 0，也不把效果定义当作已经触发。
