# 英雄机制第十二批

本目录保存图奇、卢锡安、希维尔、崔丝塔娜四名英雄的二十个技能槽候选、来源冻结、只读现值和独立核算结果。本批为第三批四名既有英雄的只读复核，不计作新录入。没有调用业务写接口，也没有修改应用代码或其他批次。

## 固定来源

客户端资料固定为 16.17.8104348，官方资料固定为 16.17.1。根绑定沿规划树 `数据参考/全量录入-2026-09/技能公共参数实录/技能来源索引.json` 的角色根和 `mCharacterPassiveSpell / spells` 路径逐槽核对。完整根对象、计算树、官方技能和来源哈希见 `根绑定与数值证据.json`；文本键见 `补充文本证据.json`。

## 当前只读现值

`当前20技能只读核对.mjs` 只使用 `GET http://127.0.0.1:8080/api/admin/games/lol`，凭据由任务环境注入，文件不保存凭据。执行得到 354 个请求全部为 200：20 个技能、120 个六类组成列表和 210 个组成详情，重复键 0，失败 0。原始快照为 `写前现值.json`，快照摘要为 `.agents/artifacts/hero12-20260909/当前组成摘要.json`，摘要哈希为 `377dc7b8bdbc5049e063afab8fa8cd3c203b7605e7d6b686bbabb95b3c6569b5`。

四名英雄的现值都能完整读取六类组成，但来源和时序仍有待补，不能标为完整机制。候选生成器因此保护现有 210 个组成：候选中语义字段与现值相同的 190 个逐项记为复用（名称、说明和排序不作为同值判断；现值对象完整保护）；另外 20 个现值组成属于伤害、治疗或其命中规则，以及希维尔 E 的零法力参数，候选不重复提出，完整清单在候选生成摘要中。

## 候选和核算

`候选原始.json` 是来源计算得到的原始候选，共 126 个参数、24 个公式、27 个效果、12 个非空过程和 1 条触发规则。为遵守结果资格边界，新的 `DAMAGE` 和 `DIRECT_HEAL` 均不生成；数值公式仍保留。`完整候选.json` 是按当前 GET 逐项保护后的候选，待写组成数为 0；已有组成不覆盖，异值若出现只记录差异。

`完整独立核算.mjs` 重新核对四份来源哈希、根绑定、数据字段索引和单位换算，检查所有表达式只含 `PARAMETER / ATTRIBUTE / OPERATION` 节点，并以多等级输入执行 180 次公式求值和 21 个独立算例。结果 `完整独立核算.json` 通过 1256 项检查，错误 0。

范围外或尚未接线的内容只在候选的 `pending`、`excluded` 和审查说明中记录：纯空间和多目标路径、小兵野怪或防御塔专用支路、第三者友军、伪装和毒层时序、强化攻击消费、希维尔被动衰减，以及崔丝塔娜炸弹的来源层数和击退后爆炸顺序。未知字段不补 0，不把持续总量当作每跳，不把冷却比例当作毫秒。
