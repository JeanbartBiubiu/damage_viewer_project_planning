# 第二十四批英雄机制候选

本目录保存努努、瑟庄妮、赛恩、沃利贝尔四名英雄各 P/Q/W/E/R 共 2 个技能位的候选和来源证据，固定客户端 16.1、官方资料 16.1.1。当前阶段只做候选预检，没有业务写入。

## 当前结果

- 写入前六类组成逐次只读核对：2 个技能主体、12 个组成列表及详情，共 13 个请求，全部返回 2；已有 29 项公共参数，公式、效果、过程、内部状态和触发规则均无既有项，重复项为 。
- 候选组成：229 项参数、38 条公式、19 个效果；过程、内部状态、触发规则均为 。复用公共参数 29 项，拟新增参数 2 项。没有即时伤害、直接治疗或自动触发效果。
- 独立数学核对：38 条公式各取两组不同输入，共 6 组；8 项缺失输入拒绝检查、1 项运行输入均无默认值，并检查沃利贝尔/5/超5层边界和努努低生命1.5倍回复边界，结果通过。
- 2 个根技能同时检查 `spellCastTime` 与 `mCastTime`。努努 Q、R 的两字段数值冲突，候选保留来源待核，不选字段、不补零；未发现负时长值。

## 文件入口

- `当前2技能只读核对.mjs`：六类组成去重，只读运行。
- `冻结来源.mjs`、`冻结文本.mjs`、`提取原始技能值.mjs`：固定来源和原始技能对象。
- `英雄组成.mjs`、`生成候选.mjs`：生成完整候选和计划，生成结果写入 `完整候选.json`、`候选版本.json`。
- `独立数学核对.mjs`：从候选、根计算树和独立数值展开重新取值并核算，结果写入 `独立数学核对.json`。
- `范围与体验报告.md`：范围边界、来源、单位、公式缺口和体验记录。
- `来源冻结/`：客户端、官方资料绑定和原始对象、展开数值。

运行时使用项目指定的 Node.js 路径，先运行生成候选，再运行独立数学核对；两个脚本均不调用业务写接口。

## 范围边界

保留自身强化、同一目标的多段伤害、唯一敌人条件、死亡后继续攻击和明确的前置成长；努努周围其他敌人/附近友军传播、独立召唤物、纯小兵野怪、纯建筑、纯视野和未绑定的触发过程只留来源证据或逐支路排除。等级曲线、命中时点、目标生命值、来源额外护甲、缺失生命值、标记再施放、攻击速度层数和冲锋距离等运行输入不补默认值。

- 写入准备前已复核沃利贝尔被动层数：attack_speed_max_stacks=5 来自中文正文，BounceCounterMax 只作为额外闪电目标来源证据；修订前候选原件保留在历史版本目录。
