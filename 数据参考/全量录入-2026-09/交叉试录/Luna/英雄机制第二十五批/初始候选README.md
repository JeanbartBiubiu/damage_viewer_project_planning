# 第二十五批候选交付

本目录保存蒙多医生、泰达米尔共10个技能槽的静态候选材料。来源固定为客户端16.17、官方资料16.17.1，构建号为 `16.17.8104348+branch.releases-16-17.content.release`。候选沿当前角色根绑定正文和计算树整理，保留原始来源对象、当前正文、等级值和计算树；不调用业务接口，也不表示已经入库。

候选包含76个新增参数、23个新增公式和10个新增效果，共109项有序新增意图。已有7个公共冷却参数只作复用和保护，未放进请求体；已有10个技能主体和60组组成列表只读保护。候选不新增主体、技能分类、角色关系、图片或公共参数，不创建伤害结果、直接治疗结果、瞬时结果、过程、内部状态和触发规则。

所有公式树的运算节点都恰好有两个输入。严格数学脚本从候选实际表达式独立求值，并用独立源值摘要计算期望值：23个公式各有两组不同等级、属性或运行输入，另有23组缺值拒绝和13项阶段、封顶、边界检查；44个运算节点、时间参数、次数和怒气整数约束均通过。首次浮点噪声失败原件没有覆盖，最终报告使用源值归一化后通过，原始浮点值仍在源值检查中保留。

关键边界已经写入候选说明和数学报告：蒙多医生Q的最低魔法伤害使用最终 `MAX`，W首750毫秒与后续灰色生命储存分开，W重施放使用当前主对象的 `基础值+0.07×额外生命`；蒙多医生R两项治疗使用施放前生命基数和附近敌方英雄外供数量。泰达米尔W把原始负值转换为正的降低幅度并使用“降低”操作，Q使用实际消耗怒气输入，P不把怒气伪装成法力，也不默认满怒。

仍待运行接线或语义补证的项目已列在每个技能的 `pending` 中，包括定身抵抗、命中事件、灰色生命属性、治疗和伤害结果、怒气资源、泰达米尔R生命下限与死亡免疫等。未知等级曲线、实际运行输入、背对目标条件和多目标或兵野专用分支没有猜测或自动补零；几何和显示数据仅保留在来源与排除说明中。

文件用途如下：

- `完整候选.json`：候选参数、公式、效果、来源绑定和既有对象保护。
- `写前请求计划.json`：109项按技能、参数、公式、效果排序的新增意图；仅供审查，不是已执行记录。
- `独立源值与算例.json`：当前原始正文、计算树、DataValues、源值系列和负值转换证据。
- `严格数学.json`：实际候选表达式的独立求值、缺值拒绝、边界和结构检查。
- `候选版本.json`、`冻结候选锁.json`、`最终哈希汇总.json`：版本、散列、计数和零业务写入状态。
- `审计归档/`：Cursor只读复核及主负责人执行审计的字节不变副本；`审计归档哈希.json`记录源副本与归档副本的代码散列核对。

本批目前处于“候选交付待主负责人审查”阶段。没有真实数据库、页面、战斗运行或浏览器验收证据；后续若要入库，应由主负责人按独立复核后的授权流程另行执行。
