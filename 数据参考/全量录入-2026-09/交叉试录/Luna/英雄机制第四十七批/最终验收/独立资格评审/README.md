# 第四十七批资格评审

评审版本：`hero47-qualification-review-v1`。固定范围是客户端 16.17、官方资料 16.17.1；只核对伊莉丝人类 W、奈德丽人类 E，以及补充核对第四十五批提莫 W。没有修改第47批候选、根输入或第45批候选。

结论如下：

1. **伊莉丝人类 W（自爆蜘蛛）**按“一次施放、一次爆炸”的本体技能伤害载体处理。玩家选择方向/位置后，蜘蛛在接近敌人或 3 秒时爆炸；它没有在冻结根对象中呈现可独立管理的生命、攻击力、攻击周期或持续攻击链。因此本批不建立独立召唤物生命管理或持续攻击实体。它施放后的自主移动和爆炸时点仍属于待运行接线；“没有独立生命”是基于静态对象结构的有界结论，不是假装已有运行验证。
2. **伊莉丝 R 的普通小蜘蛛**与上项不同。`EliseRAbility` 明确有手动管理生命周期的标记，并有 `EliseRSpider` 子对象；该子对象包含小蜘蛛数量、护甲、魔抗和伤害树，官方 R 文本也明确写有召唤休眠小蜘蛛并攻击敌人。该证据支持把 R 普通小蜘蛛作为独立单位链另行处理；本评审不改变第47批已规定的跳过范围。
3. **奈德丽人类 E（野性奔腾）**的技能事实允许奈德丽自己或一个被选中的友方英雄；本轮 1V1 录入仅保留自身受益，第三方友方按范围排除，没有证据支持同时分配给多个友方。`mAffectsTypeFlags=1029` 和 `{ea595ca6}` 只作为原始字段记录，未把位掩码或哈希枚举解释成目标语义。
4. **第四十五批提莫 W（小莫快跑）**主动移速是被动移速的翻倍态，替代被动增量，不能把 0.12 与 0.24 相加成 0.36。冻结客户端每个等级的主动值都正好是被动值两倍；可靠技能资料明确写为主动“双倍”被动移速，并说明主动期间被动不会被移除。此项只作资格与叠加说明，未修改第45批候选。

主要来源、原文定位和是否推断见同目录的 `资格审查.json` 与 `来源摘录.md`。本评审没有调用业务接口、数据库或浏览器；按仓库规则做过一次只读工作树状态核对，没有任何 Git 写入。
