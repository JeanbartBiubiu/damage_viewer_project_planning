# 第二十批英雄机制候选修订一

本目录文件是基于冻结原候选的修订一。原《完整候选.json》、原《写前请求意图.json》、原保护快照、原来源哈希和原《独立数学核算.json》均为历史证据，保持原字节；当前设计以《修订一-完整候选.json》、 《修订一-修订差异.json》和《修订一-独立数学核算.json》为准。

本批范围为Nasus、Chogath、Galio、Rammus各五槽的单一英雄目标机制。科加斯P击杀回复和R盛宴历史层数前置分开记录；R的RMinionMaxStacks=6仅保留为来源约束，不强迫当前层数上限。Galio R的友方选中施放资格仍待补证。未知的等级曲线保留为无默认运行时输入，不能由起止值自行展开。

修订一只生成候选、请求意图和只读数学核算结果，未调用业务写接口；后续写入必须以主负责人复核后的修订一计划为准。
