# 第四十九批候选（修订一）

本目录保存纳尔、克烈、奎因、雷克塞20个技能槽的修订候选、请求计划、来源值与计算树、范围清单、体验报告和独立数学核算。来源固定客户端16.17、官方16.17.1及根负责人当前绑定；Cursor来源复核已READY。

修订一修正纳尔W/R移速档、克烈R百分比公式和Gnar/Quinn飞弹字段，排除奎因P纯显形参数，分离奎因R受伤移除3秒与R冷却，并清空雷克塞W已保护冷却的待接项。候选规模为新增148个参数、30个公式、12个效果，新增请求190项，公共参数只读复用14项，计划总量204项。

独立数学直接读取根输入的原始 `DataValues` 与 `mSpellCalculations`，30公式/60场景全部匹配，10个缺运行输入场景全部拒绝；纳尔移速5项、克烈R三等级12项、飞弹速度3项均通过。检查覆盖完整等级数组、有限数值、整数参数和整数值分开计数、整数毫秒、二元运算、类型引用、属性字典、非空字典键、比例属性 `attribute_flat_add` 平加区和效果最终倍率。

未知曲线、资格、阶段、护盾寿命和运行属性继续使用无默认实际输入。此目录只形成静态候选，不调用业务接口、数据库、浏览器或Git；等待主负责人保存和页面验收。
