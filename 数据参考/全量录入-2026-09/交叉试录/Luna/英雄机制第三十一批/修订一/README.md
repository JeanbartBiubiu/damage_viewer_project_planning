# 第三十一批候选修订一

本目录是迦娜、璐璐、娜美、莫甘娜20个技能槽的修订候选材料。来源固定客户端16.17、官方资料16.17.1和当前绑定正文；输入阶段完成201条只读GET，业务写入为0，来源复核结论为READY。生成器没有调用业务接口。

修订一保留旧候选、旧请求和旧数学文件于同级“修订前”目录；修订差异以新文件为准。修订后的请求包含120项参数、35项公式和23项效果，共178项；29项公共参数只复用，不更新或重建。20个主体、120个组成列表、20张代表图、4个角色及关系和四类公共字典均属于保护对象。

本次修订把所有涉及等级数组的数值按客户端索引1至最高等级重新核对：迦娜Q、W、E、R以及璐璐E、R的首级值不再读取索引0占位。迦娜顺风而行和和风守护各自使用无默认的 `actual_bonus_move_speed` 额外移动速度点数运行输入；W在主动伤害中把P的0.3倍换算加入一次。迦娜E的攻击力公式保留，但攻击力只在护盾存在期间有效，本轮没有生成独立的固定5秒攻击力效果，护盾本身使用4秒参数且没有虚构衰减曲线。

所有公式节点严格使用两个操作数；毫秒参数和整数计数保持整数；角色等级插值、目标资格、触发时序和缺失生命曲线没有默认值。没有创建伤害结果、直接治疗、控制结果、瞬时求值或周期过程。娜美W在唯一敌人一对一范围最多涉及自身和一个敌人，不能把三跳总量当作必然；莫甘娜E把普通魔法护盾和控制免疫分开表达。

独立数学核算直接解析修订候选表达式，并独立读取冻结客户端数据和计算树期望：35个公式各跑低端与高端两组，共70个算例；37项缺值拒绝、70项整数检查和24项范围检查通过。`candidateMathReady`为真，`businessMathReady`为假；候选仍是静态设计证据，不代表业务入库、页面验收或战斗运行。

文件入口：完整候选.json、请求计划.json、来源值摘要.json、来源与范围.json、独立数学核算.mjs、独立数学核算.json、修订差异.json、体验报告.md。
