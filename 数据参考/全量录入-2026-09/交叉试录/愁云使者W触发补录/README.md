# 愁云使者 W 触发补录

本目录保存薇古丝 `vex_w/on_used` 的主动自身效果只读准备证据。准备阶段只读取固定来源和本地管理接口，不发送业务写入请求。

本批只准备一条无条件规则：收到 `SKILL_USED` 且 `useKind: ACTIVE` 后，在 `CURRENT_TARGET` 上执行已有的 `self_shield`。护盾效果的结果 `target` 是 `SOURCE`，持续时间引用 `shield_duration_ms`。

范围伤害、冲击波命中、暮气消费、法力消耗、施法时间、范围和冷却不在本条规则中；已有伤害公式和资源参数仍由保护快照完整记录。

文件用途：

- `01-来源方案.md`：固定来源、接线语义、排除项和停止条件。
- `02-冻结请求.json`：实时 GET 后生成的唯一候选规则请求。
- `03-来源快照.json`：来源文件散列、官方与客户端摘录、候选组成和来源检查。
- `04-写入前现值.json`：主体、关系、代表图、六类组成、目录和全量旧规则详情保护快照。
- `05-只读准备报告.json`：GET 计数、基线、护盾核对和 READY/REVISE 结论。
- `准备只读.mjs`：只读准备脚本；令牌在进程内生成，不保存也不输出。

运行：

```powershell
node '.\数据参考\全量录入-2026-09\交叉试录\愁云使者W触发补录\准备只读.mjs'
```

脚本只发送 GET。只有独立评审通过 `02-冻结请求.json` 后，才可由主负责人决定是否执行其中唯一的 POST；本目录证据不证明战斗运行时、Wasm 或浏览器接线。
