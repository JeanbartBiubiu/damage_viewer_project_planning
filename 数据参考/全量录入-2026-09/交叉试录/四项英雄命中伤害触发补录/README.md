# 四项英雄命中伤害触发补录

本目录保存阿兹尔 R、阿兹尔 E、约里克 E 和佛耶戈 W 四条实际英雄命中伤害规则的冻结请求、写前基线、受保护写入、独立回读与真实页面证据。

执行顺序：

1. 为当前进程设置任意随机非空 `DAMAGE_ENTRY_TOKEN`，运行 `准备合并只读.mjs`。
2. 从冻结请求读取 `batchSha256`，同时设置 `DAMAGE_ALLOW_WRITE=YES` 和 `DAMAGE_APPROVED_BATCH_SHA256`，仅运行一次 `受保护写入.mjs`。
3. 使用新的随机非空令牌运行 `独立GET回读.mjs`。
4. 确认前后端分别监听 5173 和 8080 后运行 `只读页面验收.mjs`。

四个脚本共同读取 `批次配置.mjs`。令牌只存在于进程环境中，证据不记录令牌值。管理保存、Wasm 组装、宿主事件生产和战斗验证分别记账。

本批已完成。写前一次共享基线使用 1302 次 GET，确认 1062 个技能、126 条旧规则和 24 条初始化规则；受保护写入使用 4 次 POST，四次均返回 201 并即时回读；独立回读使用 1306 次 GET，确认旧规则及四个目标的非规则组成未变，最终为 130 条规则。真实 Chromium 使用 267 次 GET、16 张截图，四张列表代表图均为 64×64，四项公式、效果结果和规则详情可见，业务写入及四类页面诊断均为零。

这些结果不表示 Wasm 已组装触发规则，也不表示宿主已经生产四种实际命中事件或完成真实战斗验证。
