# 十项英雄主动触发评审与六项补录

本目录记录十项英雄主动触发候选的交叉评审。六项通过并进入受保护写入：布里茨 W、德莱文 W、盖伦 Q、克格莫 W、孙悟空 E、蒙多医生 R。艾希 Q、提莫 W、沃利贝尔 E、兰博 W 因施放资格、效果互斥、延时站位或动态输入不足而暂缓。

`准备候选只读.mjs`、`准备合并只读.mjs`、`Cursor终审只读检查.mjs`、`独立GET回读.mjs` 和 `只读页面验收.mjs` 只发送 GET。`受保护写入.mjs` 只允许完整散列批准后的六次 POST，并拒绝已有写入报告时重放。

令牌从环境变量读取，只要求非空，不写入产物。页面验收使用真实浏览器和真实服务；战斗运行不在本批范围。
