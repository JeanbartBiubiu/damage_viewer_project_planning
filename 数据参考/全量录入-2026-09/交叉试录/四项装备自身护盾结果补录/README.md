## 本批发现的系统问题

- `SelfAoe` 是空间原点信息，不能自动推导目标资格；范围技能必须单独核对目标枚举。
- 结果组成可以先于触发接线稳定保存，但技能说明必须把“结果已组成”和“触发、冷却、运行时供值待接线”分开。
- 管理表格图片采用浏览器缓存优先。全新浏览器环境需要先从真实图片接口同步缓存，才能证明首列实际图片；“未缓存”不能误判成代表图关系丢失。
- 查看结果弹窗会异步加载伤害类型目录。页面验收必须等待标签真正回显，不能只等待接口响应头。

上述问题不要求新增表或兼容层，当前数据契约可以承载本批结果。
