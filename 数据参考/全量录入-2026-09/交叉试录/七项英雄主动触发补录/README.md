# 七项英雄主动触发补录

本目录评审七项英雄主动使用候选。写入集合为诺提勒斯 W、厄运小姐 W、亚托克斯 R、凯南 R、希维尔 W 和雷克顿 R；安蓓萨 W 因角色等级动态输入没有合法绑定而暂缓。

`准备候选只读.mjs` 为各候选生成标准上游证据。`准备合并只读.mjs` 只读取固定资料、上游证据和管理接口，生成统一来源快照、冻结请求及共享写前现值。`Cursor终审只读检查.mjs` 供 Cursor 本地代理执行静态终审。只有终审报告满足固定模型、完成终态、无截断、零范围外变化和零写入后，`受保护写入.mjs` 才允许一次执行。写后运行 `独立GET回读.mjs`，再运行 `只读页面验收.mjs`。

本批只证明管理作者数据、接口回读和真实管理页面。宿主事件生产、TinyGo 和 Wasm 运行另行验收。
