# 艾希 R 触发补录

本目录保存艾希 `ashe_r` 与现有一次命中伤害接线的只读准备证据。准备阶段只读取固定来源和本地管理接口，不发送业务写入请求，也不运行浏览器写入。

本批只准备一条规则：`ashe_r/actual_hit`。事件为 `SKILL_HIT`，来源技能为 `ashe_r`，命中对象类别限定为 `CHAMPION`，动作在 `CURRENT_TARGET` 上执行已有的 `hit_damage`。

艾希 R 当前已有 `hit_damage` 与 `mana_cost` 两个效果，以及命中公式和眩晕时间上下界参数。一次命中规则只接入可由实际命中证明的 `hit_damage`。眩晕、距离换算、减速、附近目标伤害、弹道、视野、法力消耗和冷却不在本条规则中：当前没有完整的控制结果、距离输入或附近目标选择模型，施放资源与冷却也应由施法过程处理。

文件用途：

- `01-来源方案.md`：固定来源、1V1范围、现有组成和停止条件。
- `02-冻结请求.json`：主负责人独立评审后唯一允许执行的规则 POST 请求。
- `03-来源快照.json`：来源文件散列、原始资料摘录和候选组成。
- `04-写入前现值.json`：主体、关系、代表图、五类组件、候选 404 和全局规则保护快照。
- `05-只读准备报告.json`：READY/REVISE、GET计数、全局基线和准确接线边界。
- `准备只读.mjs`：只读检查脚本，只发送 GET，并且只在本目录落盘证据。

运行前设置非空的临时 `DAMAGE_ENTRY_TOKEN`。脚本不会保存或输出令牌；示例：

    $env:DAMAGE_ENTRY_TOKEN=(New-Guid).Guid
    node "数据参考/全量录入-2026-09/交叉试录/艾希R触发补录/准备只读.mjs"

脚本成功后仍需由主负责人独立评审冻结请求。写入器只能按冻结文件执行一次 POST，并在写入后立即 GET 回读；本目录准备证据不证明战斗运行、Wasm 或实际距离控制。
