# 救主灵刃伤前触发补录证据

本目录记录炽天使之拥“救主灵刃”从固定来源核对、冻结请求、Cursor 独立评审、受保护写入、Luna Max 独立回读到真实管理页验收的完整证据。

最终结果：`item_3040_passive` 已删除没有来源解释的护盾运行时输入，护盾值改为来源最大法力值的 18%，并新增来源最大生命值 30% 的阈值公式。新规则在待处理伤害阶段检查“受伤前生命不低于阈值”且“预计受伤后生命严格低于阈值”，随后对当前目标施加 3 秒普通全伤害护盾；同一当前目标冷却 90 秒。既有“敬畏”参数和公式、装备关系、代表图片及护盾结果形状均保持不变。

验证结果：写入前完成 18 次纯 GET，并确认新增公式与规则不存在；Cursor 以 `grok-4.6`、高推理、非快速模式给出第 1 版方案 `READY`，85 个工具调用全部完成、无截断、运行期间零文件变化和零接口写入。受保护脚本固定四份输入散列，重新核对 18 项现值后执行 7 次冻结写入，每次即时回读，最后再次完成 18 次 GET。Luna Max 另以 20 次纯 GET 独立回读，所有断言通过，并确认“敬畏”公式与写前证据结构相等。真实页面以 166 次 GET 核对技能主表左侧 64×64 代表图、5 个固定参数、0 个运行时参数、3 个公式、护盾效果和伤前触发规则；业务写入、控制台错误、页面错误、失败请求和错误响应均为 0。

公式算例确认：最大法力值 1000 时护盾为 180；最大生命值 2000 时阈值为 600。生命值从 650 降至 500 时满足触发，原本已低于阈值或预计伤后生命恰好等于阈值时不满足触发。
