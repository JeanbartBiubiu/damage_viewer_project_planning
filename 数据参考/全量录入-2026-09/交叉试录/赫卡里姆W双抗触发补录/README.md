# 赫卡里姆 W 双抗触发补录

本目录处理 `hecarim_w/on_used`：赫卡里姆主动使用恐惧之灵时，依次执行已保存的自身护甲与魔法抗性效果。

本批不接入持续伤害、伤害治疗、友军治疗、兵野治疗上限、法力消耗、冷却、施法时间、周期节拍或附近目标。接口保存、页面可见、Wasm 组装、宿主事件和真实战斗分别记账。

执行顺序：

1. 使用临时生成的非空 `DAMAGE_ENTRY_TOKEN` 运行 `node 批次执行.mjs prepare`，保存一次全量规则基线和目标现值。
2. 主负责人复核 `02-冻结请求.json`、来源散列与写前报告。
3. 将冻结文件中的 `batchSha256` 作为 `DAMAGE_APPROVED_BATCH_SHA256`，并显式设置 `DAMAGE_ALLOW_WRITE=YES`，只运行一次 `node 批次执行.mjs write`。
4. 由新的 Luna Max 或独立检查器运行 `node 独立GET回读.mjs`。
5. 前后端服务可用时运行 `node 只读页面验收.mjs`；页面目标从同一批次配置生成。

脚本不会把令牌值写入文件或输出。任何写入超时、断线或非预期响应都先读取 `hecarim_w/on_used` 的稳定键，禁止盲目重放。
