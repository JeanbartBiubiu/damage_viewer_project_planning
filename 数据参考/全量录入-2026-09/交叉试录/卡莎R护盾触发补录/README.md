# 卡莎 R 护盾触发补录

本目录保存卡莎“猎手本能”主动使用后接入自身护盾的只读准备材料。目标规则是 `kaisa_r/on_used`：接收已由宿主确认合法的主动使用事件，在 `CURRENT_TARGET` 上执行已有的 `self_shield`；该效果的结果目标为 `SOURCE`，因此结果落在卡莎自身。

本批只表达主动使用到已有护盾效果的接线，不表达电浆资格、附近判定、跃迁或空间范围。脚本只读取固定本地来源并发送管理接口 GET，不创建、修改或删除业务数据。

文件说明：

- `01-来源方案.md`：固定来源、接线语义、排除范围和停止条件。
- `02-冻结请求.json`：脚本按实时现值生成的唯一规则请求，供独立评审；状态不是 `READY_FOR_INDEPENDENT_REVIEW` 时不得写入。
- `03-来源快照.json`：候选、官方中文/英文资料、客户端资料的固定散列和关键字段摘录。
- `04-写入前现值.json`：角色、关系、图片、六类技能组成、目录和全局旧规则的纯 GET 保护快照。
- `05-只读准备报告.json`：GET 计数、基线、语义检查、体验与不足以及 READY/REVISE 结论。
- `准备只读.mjs`：要求非空临时 `DAMAGE_ENTRY_TOKEN` 的 GET-only 脚本；令牌只在进程内使用，不写入文件或输出。

运行前确认本地后端已启动，在当前 PowerShell 会话生成任意非空令牌：

```powershell
$env:DAMAGE_ENTRY_TOKEN = (New-Guid).Guid
node ".\\数据参考\\全量录入-2026-09\\交叉试录\\卡莎R护盾触发补录\\准备只读.mjs"
Remove-Item Env:DAMAGE_ENTRY_TOKEN
```

脚本结束后先查看 `05-只读准备报告.json` 和 `02-冻结请求.json`，再由独立评审决定后续动作。静态来源、管理接口 GET 和本脚本检查不能证明战斗运行时已经产生合法使用事件。
