# 艾翁 Q 触发补录

本目录保存艾翁 `ivern_q` 与已有命中伤害接线的只读准备证据。准备阶段只读取固定来源和本地管理接口，不发送业务写入请求，也不运行浏览器写入。

本批只准备一条规则：`ivern_q/actual_hit`。事件为 `SKILL_HIT`，来源技能为 `ivern_q`，命中对象类别限定为 `CHAMPION`，动作在 `CURRENT_TARGET` 上执行已有的 `damage`。

艾翁 Q 的已有伤害公式为基础伤害加来源总法强，已有 `damage` 与 `mana_cost` 两个效果。本条规则只消费宿主确认的一次实际英雄命中；禁锢、再次施放突进、友军突进和非史诗级野怪分支不在本条规则中。

文件用途：

- `01-来源方案.md`：固定来源、严格 1V1 范围、现有组成和停止条件。
- `02-冻结请求.json`：主负责人独立评审后唯一允许执行的规则 POST 请求。
- `03-来源快照.json`：来源文件散列、原始资料摘录和候选组成。
- `04-写入前现值.json`：主体、关系、代表图、组件、候选 404 和全局规则保护快照。
- `05-只读准备报告.json`：READY/REVISE、GET 计数、全局基线和准确接线边界。
- `准备只读.mjs`：只读检查脚本，只发送 GET，并且只在本目录落盘证据。

运行前设置非空的临时 `DAMAGE_ENTRY_TOKEN`。脚本不会保存或输出令牌；示例：

    $env:DAMAGE_ENTRY_TOKEN=(New-Guid).Guid
    node "数据参考/全量录入-2026-09/交叉试录/艾翁Q触发补录/准备只读.mjs"

全局保护基线为 1062 个技能、104 条触发规则和 24 个 `SOURCE_INITIALIZED`。脚本任一基线或目标核对失败即停止，不产生业务写入。准备证据只证明作者数据、接口回读和冻结请求具备保存条件，不证明战斗运行时、Wasm 或禁锢与再次施放时序已经执行。
