# 艾翁 Q 触发补录来源方案

## 目标

为已经录入的 `ivern_q` 接入一次实际命中规则：

- 规则键：`actual_hit`。
- 事件：`SKILL_HIT`，事件来源技能键 `ivern_q`。
- 条件：`TARGET_CATEGORY_CHECK`，类别只有 `CHAMPION`。
- 动作：在 `CURRENT_TARGET` 上执行已有 `damage`。
- 触发限制：`perTargetCooldown` 与 `maxTriggersPerProcess` 均为 `null`。

这是严格 1V1 范围下可证明的最小接线。事件只消费宿主确认的实际英雄命中，不用施放过程代替命中，也不把禁锢或再次施放突进混入一次伤害。

## 固定来源

版本固定为客户端 16.17、官方静态资料 16.17.1。只读脚本会重新计算下列文件散列并写入 `03-来源快照.json`：

1. `交叉试录/Luna/英雄机制第四十八批/修订一/完整候选.json`：本批艾翁 Q 的冻结候选、当前根绑定正文、公式和效果。
2. 同批最终验收固定输入中的 `参考资料/客户端原文/Ivern.json.gz`：`Characters/Ivern/Spells/IvernQAbility/IvernQ` 客户端主对象。
3. 同批最终验收固定输入中的 `参考资料/官方中文/Ivern.json`、`官方英文/Ivern.json`：官方 16.17.1 技能说明。
4. 同批最终验收固定输入中的 `来源绑定与当前文本.json`：根绑定和当前文本索引，只作为来源证据。

固定资料确认 `BaseDamage`、`APRatio`、`RootDuration`、弹道和再次施放字段；官方说明确认命中第一个敌人造成魔法伤害并禁锢，友军可以突进到被禁锢目标附近。当前作者效果只提供一次目标伤害和法力消耗，命中规则只执行目标伤害。

## 当前组成核对

实时 `GET` 必须确认：

- `ivern_q` 主体、艾翁主体、角色技能关系和双方代表图片均为 200；
- 参数、公式、效果、过程、内部状态和触发规则列表及详情均可读；
- 效果键只有 `damage`、`mana_cost`，其中 `damage` 只有一个 `DAMAGE` 结果，目标为 `TARGET`，伤害类型为 `magic`，公式为 `magic_damage`；
- `magic_damage` 公式读取 `base_damage`、`ap_ratio` 和来源 `ability_power` 的 `TOTAL` 值；
- 候选详情 `/skills/ivern_q/trigger-rules/actual_hit` 返回 404，目标规则列表当前为空；
- 全局 1062 个技能、104 条触发规则及全部旧规则详情保持一致，两轮规则键集合一致，`SOURCE_INITIALIZED` 仍为 24。

## 严格 1V1 边界与停止条件

本批不录入：禁锢、再次施放突进、友军突进、非史诗级野怪冷却缩减、法力消耗、冷却以及其他目标分支。若实时效果缺失、公式属性口径改变、规则列表已有同键内容、候选详情不是 404、全局旧规则详情不完整或两轮键集合不稳定，状态为 `REVISE`，不产生任何 POST。

静态来源、接口 GET 和本准备脚本只能证明作者数据及接线请求具备保存条件，不能证明 TinyGo 或战斗运行时真的发出命中事件，也不能把禁锢与再次施放时序提前宣称为运行时证据。
