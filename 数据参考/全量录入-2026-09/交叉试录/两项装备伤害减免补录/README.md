# 两项装备伤害减免补录证据

本目录记录铁板靴“镀板”和兰顿之兆“复原力”从固定来源核对、冻结方案、独立评审、受保护写入、独立回读到真实管理页验收的证据。

最终结果：新增两个伤害修正乘区、两个持续效果、两个伤害修正结果和两条来源对象初始化规则。铁板靴仅过滤普通攻击并降低受到的伤害 10%；兰顿之兆仅过滤暴击并降低受到的伤害 30%。两者各自使用独立乘区，普通攻击暴击同时命中时按乘区相乘，不把两个来源直接相加。

验证结果：写入前完成 26 次纯 GET，执行前再次核对固定来源、冻结请求、写前现值及 Cursor `READY` 评审哈希；实际执行 6 次 POST，每次均返回 201 并即时回读，最后完成 22 次保护性 GET。Luna Max 另以 26 次纯 GET 独立回读全部新增对象和原有受保护对象。真实页面先同步 3279 张本地缓存图片，再以 237 次 GET 核对 6 个乘区、两条技能左侧 64×64 代表图、效果、结果和初始化规则；业务写入、控制台错误、页面错误、失败请求和错误响应均为 0。筛选和离页导致的缩略图 GET 主动取消按前端既定行为单列。

录入体验发现两项流程注意点：同一路由连续验收时应先重置本地筛选；结果详情的乘区目录和规则详情均为异步加载，应等待稳定标识或目录完成后判断，不能读取初始草稿得出结论。

本证据证明当前管理实库数据、关系保留及真实管理页展示，不证明普通攻击、暴击上下文、伤害乘区合并或 Wasm 战斗运行已经接线。
