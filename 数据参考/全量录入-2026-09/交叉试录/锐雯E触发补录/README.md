# 锐雯 E 触发补录

本目录保存锐雯“勇往直前”主动使用触发规则的只读准备材料。目标为 `riven_e/on_used`：接收主动使用，在当前目标上执行已有 `shield`；没有显式目标时当前目标回落来源对象，而护盾结果目标为 `SOURCE`，所以护盾属于锐雯自身。

本项不接线冲刺、施放资格、中断或冷却。脚本只发送 GET；不会创建、修改或删除业务数据。

文件说明：

- `01-来源方案.md`：来源、精确语义、边界和保护门槛。
- `02-冻结请求.json`：实时读取后生成的冻结请求；只有状态为 `READY_FOR_INDEPENDENT_REVIEW` 才有一条候选 POST。
- `03-来源快照.json`：固定版本来源文件散列和关键原始字段摘录。
- `04-写入前现值.json`：角色、技能、关系、图片、六类组成、目录和全局旧规则详情的实时保护快照。
- `05-只读准备报告.json`：GET 统计、语义核对和 READY/REVISE 结论。
- `准备只读.mjs`：要求非空 `DAMAGE_ENTRY_TOKEN` 的 GET-only 只读脚本，不把令牌写入文件或输出。

运行前确认本地后端已启动，在当前 PowerShell 会话设置任意非空令牌即可：

```powershell
$env:DAMAGE_ENTRY_TOKEN = '<本地非空令牌>'
node '.\数据参考\全量录入-2026-09\交叉试录\锐雯E触发补录\准备只读.mjs'
Remove-Item Env:DAMAGE_ENTRY_TOKEN
```

脚本结束后先查看 `05-只读准备报告.json` 的结论，再由独立评审决定后续写入。静态来源、接口 GET 和脚本检查不能证明战斗运行时已经产生该事件。
