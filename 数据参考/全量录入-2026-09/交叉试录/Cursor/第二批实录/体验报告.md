## 自动化脚本问题

本批未出现定位超时或套层对话框导致的保存失败。顶部「应用」使用 `page.getByRole('button', { name: '应用', exact: true })`，占位 Token 一次点按后会话可用。属性子弹窗内的「应用」仍限定在属性编辑对话框内，未与顶部按钮冲突。
