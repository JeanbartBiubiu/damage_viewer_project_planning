# 第三十批来源核对：亚索、永恩

本地客户端16.17、官方16.17.1，根绑定与来源散列已核对；96次当前GET、8项公共冷却参数，无其他组成。复用当前主体、关系、图片和公共参数。P/Q/W/E/R十槽均有1V1相关部分。永恩E是同一角色的自身技能机制，不按完整技能替换变形或独立自主召唤排除。

## 亚索

P当前正文暴击几率“提升100%”，是翻倍而非只加1个百分点。先处理其他暴击几率修正，再应用自身提升，超过100%的部分每1个百分点转0.5额外攻击力（YasuoCritToAD=50，正文×.01）。可保存以应用前实际暴击几率为无默认输入的增幅/封顶/超额换算；不要把已经含自身加成的最终暴击值再乘2。CritDamageMod=.95是暴击伤害降低参数，但CurrentCritDamage取mStat9，实际暴击伤害属性值和应用前后阶段需核对，不固定默认1.75或把95%当暴击总倍率。盾值125到600带mScaleByStatProgressionMultiplier=true，不能线性生成18级数组，留无默认实际等级护盾值。移动累积剑意、受英雄伤害时满槽触发护盾及持续多久尚待接线，不虚构固定持续时间。匿名55起带7/13/19/25断点计算没有当前正文消费，不录。P字段spellCastTime=.25只作为来源，不建立被动主动施法过程。

Q普通物理伤害20/45/70/95/120 + 1.05总攻击力。暴击树TotalDamageCrit是基础伤害 + 总攻击力×(1.05×当前实际暴击伤害倍率)，暴击倍率只乘攻击力项，不能乘整个含基础伤害的和，也不再额外加一笔普攻伤害。当前树mStat9具体选择器缺窄证时提供正确阶段实际倍率，无默认。首个命中目标获得攻击特效，唯一敌人仍保留该资格；不能把所有目标都加一次on-hit。2层后下一次风击、层数窗口6000毫秒、击飞1000毫秒，E中Q环形同一伤害不按多目标排除。基础冷却4000毫秒已存；当前正文明确攻击速度同时缩短冷却和施法时间，根spellCastTime125毫秒不能冒充所有攻速下的固定最终施法时间。实际冷却/施法无默认输入或保留待接算法，来源字段与最终值分开。

W飞行道具阻挡持续4000毫秒，本轮可阻挡唯一敌人攻击，保留。不是全伤害免疫或普通护盾；塔弹与光束不能阻挡。根spellCastTime0与mCastTime13毫秒冲突。几何尺寸本轮不需要全部录入，但飞行道具类型、碰撞与资格待接，不能记成无关技能。

E基础魔法伤害70/85/100/115/130 + 0.2额外攻击力 + 0.6法强。BonusDamagePerStack根乘数.25作用完整TotalDamage，当前正文额外伤害不是仅基础伤害25%；后续伤害=完整基数×(1+MIN(实际已有层数,4)×.25)，已有层数为非负整数、无默认，战前叠层保留但不自动满4。层数窗口5000毫秒；同一目标锁定冷却10000/9000/8000/7000/6000毫秒，与公共技能冷却500/400/300/200/100毫秒分开。根mDoesNotConsumeCooldown=true意味着公共字段保存不代表真实起算过程。E中Q联动、每目标锁及新层与本次伤害先后待接；施法字段250毫秒明确。

R物理伤害200/350/500 + 1.5额外攻击力；目标必须已浮空，将唯一敌人浮空维持至多1000毫秒，自身获得满剑意、清空Q层数均保留。随后15000毫秒内暴击无视60%额外护甲，限定暴击和额外护甲，不能保存为对所有伤害生效的普通总护甲穿透。施法250毫秒。额外敌方目标分配排除，但唯一敌人伤害与控制不排除。

## 永恩

P暴击提升/超额转换与亚索本批相同：提升100%，每超额1个百分点0.5额外攻击力，当前减伤参数.95与实际最终暴击倍率分开。每第二次攻击把50%攻击伤害分为魔法伤害，另外50%仍为物理；不是在原完整物理普攻上额外附送50%魔法伤害。可保存对正确实际普攻基数的拆分公式；暴击、攻击特效和其他伤害哪些进入拆分需要独立资格，不能把所有on-hit自动对半分。攻击交替状态保留，不能当两个角色或召唤。P来源250毫秒不证明被动需要主动施法。

Q普通物理伤害25/50/75/100/125 + 1.1总攻击力；暴击同样仅攻击力项×实际暴击伤害倍率，固定基础值不乘。2层后第三次带位移与击飞750毫秒，层数窗口6000毫秒；不是同一目标“戳刺+第三次旋风”在同次重复两笔伤害。基础冷却4000毫秒已存，根两个施法字段同为350毫秒，但正文明确攻速缩短，故保留基础字段与实际时长分别。数据字段QAttackSpeedCDPercent=.6、QAttackSpeedCDMax=.66667、QAttackSpeedCastReductionPercent=.41667、QAttackSpeedCastReductionMax=.5仅证系数与端点；缺执行求值关系时不凭名称造完整攻速公式。当前mCooldownNotAffectedByCDR=true，不能让普通技能急速公式覆盖其冷却。

W正文每种伤害为0.5×(基础10/20/30/40/50 + 目标最大生命×8/9/10/11/12%)，分别物理与魔法。两种合计一个完整基数，不是两种各算完整基数。名为WDamage的计算树包含总AD但没有当前正文消费，不能把它混入当前伤害。护盾WShield=实际等级基础40到90 + .65额外攻击力；首个英雄使完整护盾额外提升100%，本轮唯一敌人命中为2×整盾，不能只加基础值或只加100%一小段。额外英雄每人50%是额外目标分配排除。护盾1500毫秒，施放没命中不能默认有盾。BaseShield10..50是未消费字段，不能代替实际WShield等级基础。小兵最低伤害、野怪上限排除。基础冷却14000毫秒已存，基础施法500毫秒；攻速系数.6、冷却减幅上限.57142、施法系数.41667/上限.5保留来源，实际关系和首末时序待接，不能照抄Q的冷却上限。

E灵体窗口5000毫秒，移速10%逐渐到30%，不能保存完整5秒固定30%增益。返回时再次造成期间对英雄伤害的25/27.5/30/32.5/35%；用来源正确范围的实际已造成伤害作为无默认基数，不能用本批抗性前伤害算术总和、包括所有来源的总血量变化或缺失生命替代。伤害类型正文未明，现阶段公式名为返回追加伤害量，不凭印象强行标真实伤害或物理伤害。匿名DeathmarkBase+.25总AD树无当前正文消费，不加入；MissingHealthPercent虽恰好同数组也不是当前伤害基准。重施锁定500毫秒，硬控期间无法返回；自动到期和被控延迟返回待接。没有明确施法时长不补零，位移本体不是第三方实体。

R总Damage=200/400/600 + .8额外攻击力；TooltipDamage为完整Damage×.5，当前正文同时消费为物理和魔法各半。每种为100/200/300 + .4额外AD，不能两种各完整基数。唯一敌人也可被拉向并击飞；RKnockupDuration750毫秒为明确原始字段但正文没有持续数值，按来源参数与资格待接分开记，不自动造控制执行。根spellCastTime125与mCastTime750毫秒冲突。未命中时最大距离闪烁是几何分支，不影响当前伤害公式。

## 验算重点

两人的Q普通与暴击公式用不同AD/暴击倍率样本，确保固定基础值不乘暴击倍率；E亚索25%每层作用整式且封顶4；永恩W/R分别物理魔法各半不翻倍；W首英雄完整盾2倍；E实际伤害存量无默认且不加未消费AD树。输入缺失、层数小数/负数应拒绝；不以统一使用外供代替已有确定来源和系统能力。
