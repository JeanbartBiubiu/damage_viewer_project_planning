# 第三十批候选交付

本目录保存亚索、永恩十个技能槽的候选组成，来源固定为客户端16.17、官方16.17.1和构建 `16.17.8104348+branch.releases-16-17.content.release`。候选沿根绑定的当前中文正文和客户端计算树整理，输入包是主负责人提供的只读副本，原包未修改。

本批只准备新增组成：64 个参数、20 个二元公式、2 个自身护盾效果，共 86 个预期新增请求。8 个已有公共冷却参数只在计划中标为复用，不放入新增请求。当前快照包含 10 个技能主体、60 个六类组成列表、2 个角色、2 组角色关系、10 张代表图和属性/分类/乘区/伤害类型字典，均由 `当前10槽保护快照.json` 整体保护。

亚索部分保留暴击几率翻倍、超额暴击换额外攻击力、Q暴击只放大攻击力项、E完整基数叠层、W飞行道具阻挡4秒以及R单一浮空敌人伤害。永恩部分保留第二次攻击的物理/魔法拆分、Q暴击只放大攻击力项、W两类半基数伤害与首个敌方英雄完整护盾翻倍、E对英雄攻击与技能实际伤害的返回比例和R两类半基数伤害。

等级中间曲线、实际暴击倍率选择器、攻击速度缩短完整公式、施法字段冲突、命中/状态/触发时序、额外目标分配和几何过程均保留为待接或范围外。运行输入没有默认值；比例按 1 表示 100%，毫秒和次数使用整数。候选不创建伤害结果、直接治疗、瞬时求值、周期过程或自动触发。

执行顺序：先运行 `生成候选.mjs`，再运行 `独立源值数学.mjs`，最后运行 `收口冻结.mjs`。三个脚本只读取输入包和候选文件，不调用业务接口。最终散列、精确请求顺序、保护范围和独立算例见对应 JSON 文件。
