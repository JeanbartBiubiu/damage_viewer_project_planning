# 第三十批候选体验记录

## 可审查内容

- 亚索Q和永恩Q分别展示普通式与暴击式，固定基础值不会被暴击倍率重复放大。
- 亚索E支持已有层数 0 至 4 的完整基数计算，超过上限、负数和小数在独立数学中拒绝。
- 永恩W将物理与魔法分量各取一半，首个敌方英雄护盾按完整护盾整体翻倍；永恩R也将两类伤害各取一半。
- 永恩E的输入名称和说明限定为灵体期间对英雄造成的攻击与技能实际伤害，避免误用所有来源伤害或缺失生命。
- 亚索自身护盾和永恩W自身护盾采用成熟的普通护盾结构，只保存数值与生命周期，触发和命中事件仍待接线。

## 当前缺口

候选阶段没有真实页面、实时数据库、运行时战斗或浏览器证据。亚索W飞行道具资格、两人的暴击实际倍率阶段、Q/E攻击速度求值、Yasuo R浮空条件、Yone W命中与额外英雄分配、Yone E返回时序和Yone R控制事件需要后续运行层接线。Yasuo W 的 0 与约13毫秒、Yone R 的125与750毫秒来源冲突没有擅自裁决。

独立数学从输入包重新读取客户端原始值，并对每个最终公式使用两组不同等级、属性和运行输入，另做缺输入、二元节点、整数毫秒、比例、层数封顶和物理/魔法分拆检查。它是候选静态证据，不代表业务入库或页面验收。

本批业务接口写入为 0，真实写入授权不在本任务范围内。
