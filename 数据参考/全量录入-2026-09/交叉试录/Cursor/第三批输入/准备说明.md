# Cursor 第三批准备说明

已整理 40 名角色的基础属性输入计划，候选属性共 376 项、18级值共 6768 个。来源固定为规划树等级属性候选和官方中文资料；当前仅完成本地静态整理，尚未进行页面保存、回读或任何业务写入。

每名稳定标识为 champion_ 加源 ID 小写；属性由候选文件的 levelValues 逐项复制，全部相同才标记 fixed，其余标记 levels。缺失属性保留 missingAttributes，不补零、不推断；没有法力的角色不转换为 mana。技能、图片、被动、形态和特殊机制均待录。

执行前仍需在页面按 duplicateQueries 查重；执行后逐名核对实际属性配置数量与 expectedAttributeCount。
