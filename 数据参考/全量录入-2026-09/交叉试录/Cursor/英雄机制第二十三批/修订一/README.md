# 第二十三批修订一

本目录是阿木木与扎克十个技能槽的当前静态候选。上级目录中的《完整候选.json》及配套文件是连接中断后留下的初稿历史证据，已保留原字节；当前设计以本目录的修订差异和最终候选为准。

本修订只生成候选、公式、资源变化请求意图和独立核算，未调用业务接口，业务写入数为0。9个公共参数复用，10个技能槽共90个参数、22棵公式、6个资源变化效果和109条缺项请求意图。扎克Q/W/E的生命值消耗采用同类第七批已实录的资源变化载荷形状，但本批仍未业务保存。

阿木木E使用固定物理减免点数并在本次承受物理伤害上应用50%上限；扎克P复活冷却、Q不同目标距离范围、阿木木W匿名树修饰和扎克E表现预警均只在来源证据中保留。所有公式运算严格为二元树，未知运行输入没有默认值。
