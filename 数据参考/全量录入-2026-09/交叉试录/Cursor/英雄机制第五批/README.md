## 复核入口

- 录入.mjs默认完整只读；显式增加--apply只创建缺项。每次都验证完整20技能、全部现有组成详情及目录；异值或候选变化停止，不执行覆盖或删除。
- 每项POST前再次GET同键。无论POST成功、报错或超时，都独立GET确认；错误后未确认同值便停止该技能后续依赖，其他技能继续。
- 独立回读.mjs始终重新读取全部主体、列表和详情；对实际保存表达式执行独立预期，不使用候选替代缺失记录。
- 写前现值.json为最初历史快照，保持不变。执行记录目录按次保留候选快照、完整写前GET、执行结果和JSONL流水；写入流水.jsonl为追加记录。
- 生成候选.mjs与生成候选.mjs --full只重新生成候选，不能据此证明后续数据库状态。当前已保存集合以完整候选.json及最终独立回读证据.json共同核对。
