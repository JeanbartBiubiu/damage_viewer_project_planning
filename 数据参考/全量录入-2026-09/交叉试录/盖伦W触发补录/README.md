# 盖伦 W 触发补录

本目录保存盖伦 `garen_w/on_used` 的主动自身效果只读准备证据。准备阶段只读取固定来源和本地管理接口，不发送业务写入请求。

本批只准备一条无条件规则：收到 `SKILL_USED` 且 `useKind: ACTIVE` 后，在 `CURRENT_TARGET` 上依次执行已有的 `upfront_shield` 和 `upfront_tenacity`。两个效果的结果 `target` 都是 `SOURCE`，持续时间都引用 `upfront_duration_ms`，当前来源值为 0.75 秒（750 毫秒）。

永久双抗、主动减伤、冷却、击杀叠层和防御过程不在本条规则中。脚本会核对两个已有效果，避免只接入护盾而漏掉韧性。

文件用途：

- `01-来源方案.md`：固定来源、接线语义、排除项和停止条件。
- `02-冻结请求.json`：实时 GET 后生成的唯一候选规则请求。
- `03-来源快照.json`：来源文件散列、官方与客户端摘录、候选组成和来源检查。
- `04-写入前现值.json`：主体、关系、代表图、六类组成、目录和全量旧规则详情保护快照。
- `05-只读准备报告.json`：GET 计数、基线、两个效果核对和 READY/REVISE 结论。
- `准备只读.mjs`：只读准备脚本；令牌在进程内生成，不保存也不输出。

运行：

```powershell
node '.\数据参考\全量录入-2026-09\交叉试录\盖伦W触发补录\准备只读.mjs'
```

脚本只发送 GET。只有独立评审通过 `02-冻结请求.json` 后，才可由主负责人决定是否执行其中唯一的 POST；本目录证据不证明战斗运行时、Wasm 或浏览器接线。
