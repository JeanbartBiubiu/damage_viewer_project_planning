# 暗夜猎手 `vayne_r` 触发补录

本目录保存 `vayne_r/on_used` 的录入前材料。固定资料为客户端 16.17 与官方中文资料 16.17.1；实时组成、候选唯一性和全局规则基线均由脚本通过管理接口纯 GET 核对。

候选动作是启动已有的 `cast` 过程。实库过程为 `ACTIVE`，在过程开始绑定 `mana_cost` 并启动 `cooldown_ms`，随后在步骤完成时绑定 `bonus_attack_damage`。因此只启动一次过程，不直接再次执行攻击力效果，避免重复扣法力、计冷却或施加自益效果。

本批不把薇恩 R 的其他相关组成误写成已排除：被动移速替换、Q 冷却变化、隐身和击杀延长均在材料中列为相关但暂缓，后续需按一对一计算边界单独核对。

文件说明：

- `01-来源方案.md`：固定来源、动作范围、字段核验、排除项和暂缓项。
- `02-冻结请求.json`：精确拟议请求及请求散列；仅供独立评审，脚本不发送。
- `03-来源快照.json`：归档候选、客户端、官方资料和来源文件散列。
- `04-写入前现值.json`：目标技能组成、过程绑定、候选 404 和全局旧规则两轮读取。
- `05-只读准备报告.json`：GET 计数、基线、语义检查和建议状态。
- `06-体验报告.md`：录入页面所需信息与未覆盖行为边界。
- `准备只读.mjs`：只调用 GET；运行时令牌在进程内生成，不写入或输出。

运行：

```powershell
node ".\准备只读.mjs"
```
