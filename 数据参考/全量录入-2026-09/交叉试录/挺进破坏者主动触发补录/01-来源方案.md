# 挺进破坏者主动命中触发补录来源方案

## 目标

本批只为已有的 item_6631_active（挺进破坏者·破阵冲击波）接入一条主动命中规则：

- 规则键：actual_hit
- 事件：SKILL_HIT
- 事件来源技能：item_6631_active
- 条件：TARGET_CATEGORY_CHECK，类别只有 CHAMPION
- 动作：在 CURRENT_TARGET 上执行已有的 active_hit
- perTargetCooldown 和 maxTriggersPerProcess 都保持 null

SKILL_HIT 请求只保留当前接口已经使用的 sourceSkillKey 字段，不补写未由当前契约要求的 useKind。规则只表示“运行时已经确认该主动技能命中英雄后执行已有效果”，不负责生成范围命中。

## 来源与现有组成

来源固定为规划工作树的第十八批挺进破坏者候选、客户端 16.17 原始资料、官方 16.17.1 装备资料，以及前端工作树中六件装备公式结果补录已经保存的 active_hit 效果请求和回读证据。来源文件只读取并记录散列，不修改规划工作树。

候选和来源确认：

1. item_6631_active 已有主动伤害公式 active_damage，系数为 0.8×来源总攻击力；主动说明明确包含物理伤害、目标英雄、减速和命中英雄后的自身移动速度。
2. 本批只使用当前主动命中主目标所需的效果入口。附近其他目标、范围半径、减速、自身移动速度、衰减节拍和冷却继续留在候选的后置边界。
3. 当前实库已经存在 active_hit，结果为一次性 TARGET 伤害，引用 active_damage，伤害类型键为 physics，交付方式为 SKILL，来源类型为 DIRECT，禁止暴击且没有技能侧吸血规则。
4. 当前实库已有 item_6631_active 技能主体、6 个参数、1 个公式、1 个 active_hit 效果、装备技能关系和装备及技能代表图；过程、内部状态和触发规则目前为空。

## 冻结边界

本批只新增一条触发规则，不新增或更新技能主体、装备主体、直接属性、关系、图片、参数、公式、效果、过程或内部状态。已有主动冷却参数不改写为规则冷却；不把范围、减速、自身移速、衰减或未接线运行时字段塞进请求。

只读准备必须保护：

- item_6631_active 主体、装备关系、装备代表图和技能代表图；
- 全部参数及详情、全部公式及详情、active_hit 效果及详情、过程列表、内部状态列表；
- 目标触发规则列表为空，新规则详情路径写入前返回 404；
- 全技能目录、每个技能的触发规则列表和所有现有规则详情；
- 物理伤害目录和所有现有修正区域目录，用于核对 active_hit 的引用环境；
- 第一次和第二次全量扫描的技能键、规则键集合及数量稳定。

若目标规则已经存在、active_hit 不存在或内容漂移、任何受保护对象读取失败、全量规则详情不能逐条读取，报告为 REVISE，禁止后续写入。静态来源、实库 GET 和脚本检查不能证明主动施放、命中生产、范围选择或战斗运行时接线。

主负责人独立评审通过后，只执行冻结请求中的唯一 POST；返回 201 后立即 GET 新规则详情并核对冻结字段，再确认既有非规则组成未变化。
