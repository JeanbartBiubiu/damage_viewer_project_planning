# 布兰德E与墨菲特E/R使用流程补录

布兰德E已有法力参数却缺法力效果，本批先补消耗效果，再建立250毫秒普通施法过程及主动入口。墨菲特E/R各补基础法力和普通冷却登记过程及入口，固定0的步骤只表示登记，不声明实际施法时长为零。既有伤害、实际命中和已纠正的吸血资格保持原样。

固定资料按当前根绑定核对：布兰德E采用manaValues与官方一致的全等级90，忽略旧mana数组；墨菲特R只取三个技能等级，不把数组尾部零值当有效等级。31个数值与引用点通过。7次POST及即时回读、独立74次GET通过，7个新对象和7个变化集合符合预期，其余60项响应含时间戳不变。准备74次GET，写入窗口88次GET。

墨菲特E两种施法时间字段的实际含义、R特殊施放、控制、布兰德被动联动和代表页面仍待续；未新增或验证突进、通道、命中生产、消耗冷却运行或Wasm。浏览器认证连接仍不可用，不计整技能管理完成。
