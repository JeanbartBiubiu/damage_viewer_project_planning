# 八项英雄候选复核与四项触发补录

本目录合并复核卡莎 R、安妮 E、盖伦 W、薇古丝 W、卡萨丁 Q、艾希 W、艾翁 Q 和魔腾 R 八项只读候选。八个上游目录均以 1062 个技能、104 条规则、24 条来源初始化规则为稳定基线，候选详情为 404，实际请求只有 GET。

独立语义评审接受盖伦 W、薇古丝 W、卡萨丁 Q 和艾翁 Q 四项，暂缓另外四项。安妮 E 当前无法区分自施与友军目标；卡莎 R、艾希 W、魔腾 R 缺少对应宿主事件资格、去重或阶段证据。本批只新增四条通用触发规则，不修改主体、关系、图片、参数、公式、效果、过程或内部状态。

执行顺序固定为：

1. 保存 `00-独立语义评审.json`，只让通过语义门禁的四项进入写入集合。
2. 运行 `准备合并只读.mjs`，重新取得两轮全局规则与四个目标的非规则快照，生成修订 4 冻结请求。
3. `05-Cursor终审-首版脚本.json` 记录首版脚本已通过只读终审；`06-首次写入预检失败.json` 记录写入前因校验器读取旧字段而停止，1194 次 GET、0 次业务写入。
4. 修正校验器后重新做 Cursor 只读终审，接受证据写入 `07-Cursor独立评审.json`。
5. 将评审输入散列在内存中传给 `受保护写入.mjs`，只允许一次四条 POST；每条 201 后立即 GET，任何候选已存在均停止，报告写入 `08-写入与即时回读.json`。
6. 用 `独立GET回读.mjs` 另发纯 GET，完整比较旧 104 条、新 4 条和四个目标非规则组成，报告写入 `09-独立GET回读.json`。仅允许后端对 `SKILL_HIT.eventSource.detail.useKind` 的固定空值规范化。
7. 用 `只读页面验收.mjs` 在真实 Chromium 核对四张列表图片、代表公式、效果、结果和规则，报告写入 `10-页面验收.json`；页面请求不得包含业务写方法。
