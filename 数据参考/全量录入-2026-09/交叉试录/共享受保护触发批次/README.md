# 共享受保护触发批次

`受保护触发批次-v1.mjs` 是本轮重复录入触发规则的版本固定执行器。批次目录保留自己的方案、配置和入口脚本，并把共享执行器的字节散列一起冻结；共享执行器一旦用于真实写入就不再修改，需要变更时新增版本文件。

当前版本只覆盖本轮已经实际使用的动作：执行已有效果、启动已有过程。它完整保存每条规则的事件明细，分别散列业务正文与规则更新时间；独立批准必须重取同一完整基线，写入器只接受批准的冻结批次散列和目标非规则组成散列。

固定阶段为 `freeze`、`prepare`、`review`、`write`、`readback`、`targets`、真实浏览器验收、`manifest`。接口阶段使用进程内临时令牌；只读阶段拒绝非GET，写入阶段只允许冻结规则的POST。生成文件均拒绝覆盖，已成功POST只能由恢复分支回读，不能盲目重放。
