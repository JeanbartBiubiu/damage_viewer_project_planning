## 来源与审查

复用第一批目录内的171英雄完整冻结原文及索引。官方16.17.1与客户端16.17逐级核对并校验原文摘要；本批采用的冷却从客户端索引1开始，法力从索引0开始。`录入公共参数.mjs`默认只读，显式`--apply`先对整批源摘要、技能等级和既有参数预检，再补缺项；同值跳过、不同值停止，不覆盖或删除。

独立审查纠正了只按中文“充能”筛选的两类问题：

- 兰博E的500毫秒来自两次施放间隔，客户端同时明确2发弹药、6秒恢复。该字段在写入前撤出；不能把500或6000直接录为普通冷却。生成器同时检查官方弹药量及客户端弹药字段。
- 卡萨丁W的武器充能、瑞兹Q的符文充能不属于弹药；两来源普通冷却分别明确7000、5000毫秒，已纳入本批。
- 卡萨丁R的40法力说明为零层数基础费用，连续施放的层数倍率另配。斯卡纳E保留明确基础冷却，取消及返还另核。

因此初始94项候选撤1项、补2项，最终95项。冷却或费用存储成功不表示消耗过程、层数修正或完整技能完成。
