# 装备效果候选资料

本目录覆盖官方 16.17.1 固定资料中，已冻结的 181 件普通装备候选里除 47 件纯属性装备以外的 **134 件**。未重新调整模式范围，未调用业务接口、数据库或浏览器。

| 文件 | 内容 |
| --- | --- |
| `装备效果候选.json` | 134 件逐件记录，含 353 行直接属性、各效果原文与来源定位 |
| `机制段落候选.json` | 197 个命名效果段，178 个被动、19 个主动；含技能草稿中文说明 |
| `未补字段清单.json` | 104 件存在资料缺口的装备及具体缺项；另列 20 件含零值展示的对象 |
| `逐件审阅.json` | 134 件逐项阅读后的必要资料缺口与业务边界，不是自动猜测的机制参数 |
| `录入用说明.md` | 按装备编号排列的人工录入参考，直接查看属性、效果、缺项与边界 |
| `来源与覆盖.json` | 固定来源摘要、覆盖标识及计数 |
| `生成效果候选.mjs` | 从已冻结资料与逐件审阅结果生成本目录文件，不写业务数据 |

30 件暂未发现必须补齐的明确数值缺口，可优先形成完整文案候选；仍须确认系统的事件、对象、状态及重复触发规则。其余 104 件也可先录已明确的属性或独立效果，不能把一项缺失扩展成整件都无资料。

技能候选名使用“装备名·效果名”，主动与被动按原始标签区分。原文只给了条件、作用对象或持续时间时，就只保留这些内容；没有猜测系数、射程、触发冷却或等级插值。候选说明没有被直接转换为 API 参数，不代表系统已支持或完成录入。

直接属性同时保留显示值和小数比例。例如说明 15% 攻速，在小数比例约定下是 0.15，含义为额外攻速，不是每秒攻击次数。所有原始 `stats` 中能与直接属性对应的值均已核对一致；缺失字段保留“说明有值、stats未提供”的记录。多兰之盾每 5 秒回复 4 生命对应原始字段每秒 0.8，已单独核对，不混为直接生命属性。

20 件存在零值展示，其中可能有动态公式结果，也可能是成长属性当前值；统一标为需核对，不能直接填常数 0。例如育恩塔尔荒野箭的 0% 暴击几率与永久成长机制连在一起，不应替换为固定 25%。电震涡流剑的百分号前与额外穿甲前没有数字，已单列明确资料缺失。

控制、法术护盾、幽灵、基础技能急速、终极技能急速、召唤师技能急速等概念分别保留。涉及视野、经济、兵线对象或区域的效果标有边界核对，不把风暴或环绕区域仅凭“召唤”一词误判为独立召唤物。

在本目录运行 `node 生成效果候选.mjs` 可重新生成。验证包括：冻结来源摘要一致；181 = 47 + 134；134 件都有逐件审阅且仅出现一次；197 个命名段没有空名称或空正文；353 行直接属性均可明确解析；已有数值与说明一致。这里没有执行页面、数据库或战斗验证。
