## 来源与字段核对

`整理来源.mjs` 复用了既有英雄成长补证时保存的完整客户端响应，未重新下载或改变资料版本。将 171 名范围内英雄原文无损压缩保留，共 11,258,245 字节原文、1,514,383 字节压缩文件；每个文件保存原始地址、抓取时间和原文及压缩文件摘要。解压后核对摘要，不依赖被 Git 忽略的旧临时缓存。

`技能来源索引.json` 沿实际角色根引用记录 171 名英雄的 855 个技能绑定：被动只取 `mCharacterPassiveSpell`，主动按 `spells` 槽位；没有缺失绑定。绑定可用不等于该技能已经完成数值核对或实录。角色根路径沿既有核对记录，避免 Fiddlesticks / FiddleSticks 大小写差异。

`生成公共参数候选.mjs` 只处理明确列出的 16 名英雄，核对官方静态资料 16.17.1 与客户端 16.17 的摘要和逐级数值。等级数取官方技能 `maxrank`；本批普通冷却取客户端索引 1 起、法力取索引 0 起。秒转毫秒，仅采用明确的正数；非蓝量资源不建立法力参数。充能恢复、再施放和开关类冷却单独待核对，不套用普通冷却。

独立审查发现“充能”关键词会将贾克斯 W 的下次攻击强化误判为弹药机制，已针对该技能纠正：官方 `[7,6,5,4,3]` 与根绑定客户端索引 1～5 一致，录入 `7000/6000/5000/4000/3000` 毫秒。词语筛选仅用来提示核对，不能直接判定机制不支持。
