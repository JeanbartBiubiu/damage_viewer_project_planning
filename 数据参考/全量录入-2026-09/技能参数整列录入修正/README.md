# 技能参数整列录入修正

系统-05已修正：技能等级和角色等级参数均支持整列粘贴，准确校验当前数量、空项、十进制有限数字和整数要求。支持换行、Windows换行、制表符和中英文逗号，失败时原等级草稿保持。应用只填草稿，非空文本未应用时阻止保存；查看无批量入口，切换取值方式或重开不带入旧粘贴内容。

728项单测、静态检查、类型检查、构建及3项定向生产构建页面测试通过。真实页面返回内瑟斯P的18级分段值和婕拉Q的5级伤害值，验证空项、类型与数量错误恢复、整列应用和只读界面；只应用已核现值后取消，没有重写正确数据。页面后2次GET确认完整参数含时间戳不变。

旧盖伦P参数已改为计算时传入，未为验收重新写入未证实的等级曲线。此改动改善录入操作，不填补任何来源缺口；无后端、表结构或战斗运行改动。
