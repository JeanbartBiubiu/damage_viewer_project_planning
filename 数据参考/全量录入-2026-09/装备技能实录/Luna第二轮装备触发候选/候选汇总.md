## 逐项结论

### 水银弯刀
官方说明给出移除控制类减益（浮空除外）并提供移动速度；客户端字段为移速比例 0.5、持续 2 秒、冷却 90 秒，规范化资料还记录幽灵状态。当前 API 只保存 `quicksilver_move_speed`，结果为自身 `move_speed_percent` 增加、持续 2000 毫秒，未保存解控、浮空例外或幽灵效果。

可复用的有界骨架是 `SKILL_USED`（`sourceSkillKey=item_3139_active`、`useKind=ACTIVE`）后以 `EXECUTE_EFFECT` 执行 `quicksilver_move_speed`，动作上下文可用 `CURRENT_TARGET`，效果结果目标为 `SOURCE`。这只能表达移速部分，不能安全代表完整主动，因此暂缓。

### 放血者的诅咒
官方和客户端说明为对英雄造成魔法伤害时施加 7.5% 魔抗削减，持续 6 秒，最多 4 层；规范化资料补充同一普攻或技能施放实例对每个英雄至多一层，并有 0.3 秒限制。当前参数与效果生命周期已保存 7.5%、6000 毫秒、4 层；效果结果目标为 `TARGET`，重新施加会叠加并刷新。

现有 `DAMAGE_DEALT`、`damageTypeKey=magic`、英雄目标条件和 `EXECUTE_EFFECT` 可以组成表面骨架，但当前没有施法实例标识、来源/目标维度去重或 300 毫秒门控状态。直接挂规则会把多段伤害错误算成多层，暂缓。近战/远程没有来源分支，不新增分支。

### 蜕生
官方和客户端说明要求敌方英雄在被持有者造成伤害后的 3 秒内阵亡，并在死亡位置生成新星治疗友军；规范化资料给出持有者存活、1.75 秒新星过程、100+20%法强和 60 秒冷却。当前 API 已保存 `self_healing` 公式 `100+0.2×SOURCE ability_power` 及 `self_heal` 的自身 `DIRECT_HEAL` 结果，但生命周期未启用，过程、内部状态和触发规则均为空。

一对一只评估自身治疗，纯盟友范围治疗不纳入候选；仍必须先有伤害与敌方英雄击杀参与的关联、来源存活检查、3 秒窗口、60 秒冷却和 1.75 秒时序。当前没有可确认的击杀事件键或过程，暂缓。
