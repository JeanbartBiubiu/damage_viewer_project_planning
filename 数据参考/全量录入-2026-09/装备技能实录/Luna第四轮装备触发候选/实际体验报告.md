# Luna第四轮装备触发候选体验报告

本轮只做六项装备技能及受影响目录的定点 GET 复核，没有创建技能效果、过程、内部状态或触发规则，也没有页面操作。

## 操作与耗时来源

- 读取固定来源、阶段进度、既有装备实录和后端源码说明：静态文件读取，未单独计时。
- 定点 GET：115 次，全部为 GET；其中候选组成 102 次，状态、伤害类型和伤害修正区目录 13 次。业务写入 0，非 GET 请求 0。
- 六项均返回技能主体、装备关系及组成列表；六项触发规则列表均为空。影焰已有 1 个公式，其余五项没有公式或效果。
- 本轮没有重复读取全量技能目录或全量规则基线；只查询六项对象及受影响目录。

## 体验与边界

- 页面验收：未执行。前端卡顿：未执行，未启动页面流程。
- 字段歧义：
  - “造成伤害”不能直接缩成普通攻击或技能命中；海克斯科技发电机和斥候弹弓还需要敌方英雄目标资格、冷却消费及递归排除。
  - “减速”不能用现有眩晕状态或移动速度属性代替。瑞莱的冰晶节杖和赛瑞尔达的怨恨均保留参数，但等待 `slow` 状态和准确命中/生命阈值时点。
  - 影焰同时要求魔法或真实伤害、低于40%生命值和只影响额外伤害；不能使用当前已有的铁板靴或兰顿伤害修正区冒充。
  - 振奋盔甲的25%是自身受到治疗和护盾的增幅，不是施放治疗或护盾强度；当前两类修正结构不完整。
- 错误恢复：本轮没有写入失败、超时或断线，也没有重放请求。目录查询仅记录返回状态，不把旧的写入响应当作本轮回读。
- 手工查找位置：固定原文在 `装备符文/官方原始资料/item-16.17.1-zh_CN.json`；客户端字段在 `装备效果补证/客户端原始资料/items-16.17.cdtb.bin.json.gz` 和 `lol-16.17-zh_CN.stringtable.json.gz`；已有组成回读分别位于第十三批、第十四批、Luna第五批、Luna第六批和第十八批目录。
- 是否转成 API 或脚本：六项现有参数和公式已通过既有录入脚本保存；真正触发前仍应由主负责人先完成通用状态、事件时点、冷却和修正区能力，再将稳定字段核对转为一次性 GET 预检脚本。当前不建议生成写入脚本。
