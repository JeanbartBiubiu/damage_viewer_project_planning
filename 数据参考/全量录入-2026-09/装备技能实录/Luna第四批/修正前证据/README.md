# Luna第四批装备技能实录

本目录记录第四批六件装备的冻结来源核对、录入候选、接口逐字段回读和体验边界。业务范围是 `item_3072`、`item_3031`、`item_3508`、`item_6676`、`item_3140`、`item_3157`；装备已有基础属性不在技能中重复保存，收集者的金币效果按本批范围跳过。

## 结果

- 5 个新技能已写入并挂载，5 个新增技能代表图已从对应装备代表图复用并独立回读。
- 1 件装备（无尽之刃）有冻结证据证明只有直接属性，跳过新技能创建。
- 新增技能组件：11 个参数、2 个公式、5 个效果、0 个触发规则、5 个装备技能关系、5 个代表图关系。
- 最终只读回读：348 个字段，差异 0，缺失 0。
- 配置保存和接口回读不等于战斗、Wasm 或浏览器运行验证；页面代表流程由主负责人验收。

## 使用方式

`录入装备技能.mjs` 默认只读。`--write-candidate` 只生成候选；`--apply` 才补缺写技能、参数、公式、效果和关系；`--apply-images` 独立补缺代表图。每个对象、子组件和关系都先 GET，写入后再 GET 逐字段比较；已有值不同会停止，不覆盖。

脚本内使用公开占位 `local-entry` 请求本地管理接口，材料不保存令牌、Cookie 或图片内容。

- `录入装备技能.mjs`：只读、候选和显式补缺脚本。
- `录入候选.json`：六件装备的候选与跳过记录。
- `来源与处置清单.json`：冻结来源、装备直接属性预检、技能处置与待补边界。
- `装备基础属性与图片预检.json`：六件装备基础属性和代表图的 GET 证据。
- `逐字段回读证据.json`：最终独立 GET 逐字段证据及来源哈希。
- `实际体验报告.md`：接口操作、配置边界、来源缺口和未执行验证的分开记录。
