# Luna第三批装备技能实录

本目录只记录六件装备的新技能、技能组成、装备技能挂载、装备代表图复用，以及逐字段接口回读：多兰之盾 `item_1054`、破败王者之刃 `item_3153`、海克斯饮魔刀 `item_3155`、玛莫提乌斯之噬 `item_3156`、不朽盾弓 `item_6673`、星蚀 `item_6692`。

## 来源与口径

数值和说明来自规划树冻结的 16.17 客户端压缩原文、中文绑定说明和逐件补证结果。基础装备属性已经存在，本批没有重写基础属性、共享属性、状态字典或第二批文件。小数按比例保存，时间参数统一换算为毫秒；物理伤害沿用系统现有键 `physics`，魔法伤害使用 `magic`。

纯固定数值直接作为参数或效果值保存。需要等级计算器、距离分支、受击后的生命阈值时序、攻击计数去重或战斗状态结束判断的内容，只保存已确证的独立组成，并在处置清单和体验报告中标明未接线边界。

## 脚本用法

`录入装备技能.mjs` 默认只读。`--write-candidate` 只生成本批候选；`--apply` 才补缺写入技能及组成、挂载；`--apply-images` 与 `--apply` 一起使用时，复用对应装备代表图为新技能补图。脚本每个对象按技能、参数、公式、效果、规则、挂载、代表图顺序逐项 GET，已有值逐字段相同才跳过，不覆盖不同值；写入后立即独立 GET 回读。

中途因主负责人要求等待后端短暂重启，恢复后脚本先逐项 GET 确认停点对象，再按顺序补缺；没有盲目重放已经成功的请求。
