# Luna第五批装备技能录入说明

本目录记录第五批六件装备：反曲之弓、萃取、死刑宣告、湮灭宝珠、灭世者的死亡之帽、瑞莱的冰晶节杖。来源版本为16.17客户端与16.17.1官方中文资料。录入脚本默认只读，使用“--apply”才写业务数据，使用“--apply-images”才补技能代表图；本次使用公开占位“local-entry”，材料未保存真实凭据。

## 已保存结果

接口顺序写入后，六个技能、9个参数、3个确证效果、3条触发规则、6条装备挂载和6个技能代表图均已独立回读。死亡之帽总法术强度提升使用“attribute_percent_bonus”乘区保存0.3比例，直接属性130点法术强度没有重复计入。公式数量为0，因为固定数值和现有乘区可以直接表达。

基础属性预检覆盖6件装备、7个字段，全部与接口一致。最终生成器回读统计为 276 个字段、差异 0 个、缺失 0 个；另一个独立回读脚本完成 39 项检查，字段差异 0 个，失败检查 0 项，图片键检查通过 6/6。

## 各装备处置

- 反曲之弓：保存攻击附带15点物理伤害、普通攻击命中触发；15%攻击速度沿用装备直接属性。技能触发攻击特效是否也进入同一事件仍待运行链核对。
- 萃取：保存每次攻击回复3点生命值、普通攻击命中触发；7点攻击力沿用直接属性。小兵击杀金币、100次阈值和额外350金币按范围跳过，不计待补机制。
- 死刑宣告：保存40%重伤比例和3秒参数。候选结果明确使用“HEALING_MODIFIER”的“受到治疗、减少、任意治疗”语义，但现有比例加算会把两份40%叠成80%，需先补只取最强的组合语义，不能只新增治疗目录。全部物理伤害同时限定敌方英雄的条件及生命回复覆盖另缺依据；未保存效果或宽泛触发。
- 湮灭宝珠：与死刑宣告相同，魔法伤害来源已在说明和来源证据中区分；效果与触发待取强组合及准确英雄目标条件补齐；待配目标已由自身纠正为当前目标。
- 灭世者的死亡之帽：保存0.3总法术强度提升参数、属性百分比变化效果和“SOURCE_INITIALIZED”初始化触发。该初始化事件明细严格为空；配置回读已完成，未执行运行时计算。
- 瑞莱的冰晶节杖：保存30%减速和1秒参数。单加减速状态名不能绑定30%强度，状态操作结果当前禁止数值规则；控制类别、强度及组合语义仍缺结构，伤害型技能范围另核。不能用眩晕或属性变化代替。

## 接口体验与问题

直接属性、技能、参数、效果、触发规则、挂载和图片均可通过管理接口按对象逐步读回。首次提交死亡之帽属性效果时，接口返回400，指出没有效果生命周期时不能带结果生命周期行为；脚本随后改为无期限显式生命周期并成功保存，最终回读零差异。该修正已保留在录入脚本中。

页面体验本批未由本代理执行，浏览器代表验收由主负责人接手。接口配置和回读不等于运行时伤害、治疗、重伤或减速验证。

## 待配与来源缺口

重伤和减速的参数、来源文案及算术样例已保存；尚未保存的效果分别受跨来源只取最强、控制强度绑定或目标筛选能力不足影响，具体原因见“来源与处置清单.json”的“pendingRules”“pendingEffects”。本批没有改共享状态字典、治疗乘区或目标条件结构，也没有将未完成配置称为运行时验证。
