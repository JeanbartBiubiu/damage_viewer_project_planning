# Damage Viewer Web

`web/` 是 Damage Viewer 的前端工作台。它负责当前阶段 0～9 的管理页面、图片缓存，以及底层 TinyGo V2 Wasm 运行时资源。

它在整条链路里的位置是：

1. 读取后端游戏列表和当前管理接口。
2. 提供属性、角色、装备、符文、技能分类、伤害类型、技能、状态、游戏配置和图片管理页。
3. 在浏览器侧处理上传图片，并缓存、同步公开图片资源。

## 当前主要页面

- `src/App.tsx`：应用外壳、路由、API 基址和本地状态；根地址与未知 Hash 落到 `#/attributes`
- `src/pages/admin/attributes/`：属性管理（`#/attributes`）
- `src/pages/admin/characters/`：角色管理（`#/characters`）；关联技能行可直接「录入技能」，进入选中技能的参数、公式、效果、过程和触发编辑入口；「返回角色技能」重新打开同一角色的关联弹窗，并保留角色列表筛选。
- `src/pages/admin/equipment/`：装备管理（`#/equipment`）；“关联技能”可直接录入选中技能，显示所属装备，返回同一关联窗口并保留筛选。未保存的挂载草稿需确认放弃，连接或游戏变化清除旧技能上下文。
- `src/pages/admin/runes/`：符文管理（`#/runes`），提供“符文列表”“分组与槽位”两个视图；列表最左显示代表图，可直接上传、选择已有图，符文可挂载技能。
  - 符文列表的“关联技能”可直接「录入技能」，页内共用技能管理页并显示所属符文；「返回符文技能」重新打开同一符文关联弹窗，并保留关键词草稿、类别、查询、页码和每页数量。分组与槽位不提供技能关联入口。连接、游戏或令牌变化会清除旧符文技能上下文，迟到响应不能恢复。未保存的挂载草稿和技能草稿仍走既有离开确认，取消保留当前编辑。
  - 两个视图均使用本地分页，默认25条，可选50/100条。查询、重置和切换连接回到第一页，保存与刷新保留有效页码。
  - 分组编辑完整有序槽位及每槽候选，通过上移/下移调整顺序；空布局、空槽位允许保存，同一属性碎片可以跨行复用。类别不符、缺失引用及保存错误保留草稿，写入后独立回读完整布局；回读失败时重新读取，不重复创建。
- `src/pages/admin/skill-categories/`：技能分类管理（`#/skill-categories`）
- `src/pages/admin/damage-types/`：伤害类型管理（`#/damage-types`）
- `src/pages/admin/skills/`：技能管理（`#/skills`，含参数、公式、效果与结果及效果生命周期、过程与内部状态、条件与触发）
  - 技能列表及角色/装备/符文聚焦共用「行为总览」：只读汇总已保存的使用、消耗与冷却、命中、效果、结束配置，并列出未归类规则、未挂接效果和五组未覆盖的过程（含没有启动动作的被动/消耗过程）。普通资源扣减不会被标成施放消耗。参数、公式和内部状态只作辅助引用。总览不执行动态公式，也不表示机制或战斗已验证。
  - 角色录入检查的问题和引用必须带结构化定位；「定位问题」「定位引用处」按稳定键打开原编辑器字段。缺键、重复键、类型变化、公式快照不符或未知控件会停在正确对象入口并提示无法精确定位，不会用旧下标猜测另一行，也不会自动创建对象。引用集合默认前三项，可展开全部；来源对象与目标显示名称和稳定键，子结果/选项保留各自名称，目录缺失、加载失败及停用分别提示。名称详情最多四个请求并行，切换检查或连接后旧响应不回流。

  - 查看或编辑技能主体、效果、过程和规则时，详情返回前只显示加载提示；读取失败保留重试入口，不展示可被响应覆盖的默认表单。技能主体每次打开都读取当前详情，启停也先读最新主体再仅改变状态，避免旧列表覆盖已更正字段。结果引用目录未返回时显示加载提示，完成后再判断是否缺少引用。规则来源技能在目录加载中或失败时分别显示对应状态，成功返回后才标记缺失；重试保留当前键与草稿。
  - 效果编辑器结果表的关键引用摘要并列显示名称与稳定标识；参数、公式、属性、状态、目标效果、技能和分类在目录加载中、加载失败、成功但缺失时分别标明，停用目录显示停用。摘要同时给出作用对象与明确单位：冷却减少/增加/设置剩余为毫秒，按比例减少剩余冷却为比例，重置为可用无数值；生命周期延长剩余时长为毫秒，层数与次数使用对应标签；仅普通移动减速的施加标注减速比例，修正类按既有标签标比例，未知属性或伤害单位不猜测。固定 0 显示 0，未配置不补 0。技能范围超过三项默认前三项和总数，可展开查看全量；展开只改变展示，不产生草稿或保存请求。不在顶层效果列表重复这些摘要。
  - 新建参数及切换取值方式后，固定值和等级数值均留空；未填不能保存，明确填写的0仍合法，已有0原样回显。等级参数支持整列粘贴，按当前等级从低到高填写，使用换行、制表符或逗号分隔；应用前检查完整数量、有限十进制数值及整数要求，错误时保留原等级值。固定填充和等差递增需先明确填写工具数值，均可填0。应用只更新草稿，仍需保存；未应用的非空文本会阻止保存，切换取值方式或重新打开会清空粘贴草稿。
  - 扩大技能最高等级前确认新增等级范围；保存后提示已有等级参数由服务端补0，需按来源逐项核对新增值。该提醒不代表新增数值已核实，也不改变已有参数值或后端等级联动规则。
  - 列表使用本地分页，默认每页 25 条，可选 50/100 条；翻页不重新请求技能列表，只加载当前页缩略图。查询、重置和切换连接回到第一页，编辑保存保留页码，删除末页最后一项后回退至有效页；从角色进入的单技能录入不显示分页。
  - 冷却变化与技能急速修正共用“技能范围”（全部技能 / 指定技能 / 指定技能分类）；请求与回显字段为 `detail.affectedSkillScope`
  - 冷却变化支持“按比例减少剩余冷却”，70%填写0.7。毫秒与比例操作之间切换会清除原数值，范围和目标保持；可静态取得的有效比例越界时保留草稿并提示。共享含义见规划真源《系统精简实施说明》的“剩余冷却比例减少增量”。
  - 生命周期操作支持“延长剩余时长”，有效增加量按非负整数毫秒填写；层数与时长切换清空原数值。目标期限和统一到期模式由后端最终核对，错误定位到目标并保留草稿。共享含义见规划真源《系统精简实施说明》的“生命周期剩余时长延长增量”。
  - 效果结果共十九种，含普攻计时重置、收到护盾修正、技能急速修正、斩杀、命中联动应用和攻击联动应用；条件与触发含应用命中联动、触发攻击联动
  - 普攻计时重置使用空明细且不填写数值，只能即时或在已有生命周期的离散时点执行；不会直接发起攻击。切换种类会清除原数值、乘区和法术护盾粒度，作用对象仍按来源资料选择。
  - 收到护盾修正作用于结果选中的护盾承受者，必须使用父效果生命周期和持续时点；数值按小数比例填写，25%写为0.25。护盾乘区只支持比例加算、护盾结果阶段；切换结果种类会清除旧乘区及无关明细。
- `src/pages/admin/modifier-zones/`：乘区管理（`#/modifier-zones`），维护属性、伤害、治疗和护盾范围；治疗乘区可选用比例加算或比例减少取强。护盾修正只影响本次收到的普通护盾量，页面保存不代表战斗结算已实现。
- `src/pages/admin/statuses/`：状态管理（`#/statuses`）；状态种类含眩晕、普通移动减速、禁锢、沉默、魅惑与击飞，创建后只读展示。禁锢、沉默、魅惑和击飞使用已有无强度状态操作；有期限实例由技能效果生命周期维护，具体期限与刷新方式按来源选择。
- `src/pages/admin/game-settings/`：游戏配置（`#/game-settings`）；等级读取、保存和确认操作绑定当前连接与游戏，失效响应不覆盖当前数据，读取失败需重试后才能保存。等级和图片草稿合并参与离开保护；刷新等级、切换游戏或连接前确认未保存修改。扩大范围的确认和成功提示列出新增等级，说明服务端补0需要按来源核对。
  - “通用吸血规则”统一维护各类吸血的来源比例属性、计算基数、默认效率及适用集合。同集合内部任一匹配，伤害产生方式、来源性质和技能分类之间同时匹配；完整集合保存，未配置种类不启用。只选择当前游戏的十进制属性与分类，新增规则不预填资格或效率。加载、保存及刷新确认绑定当前连接和游戏，失败保留草稿；吸血、等级、图片共同参与离开保护。
  - 伤害结果的吸血资格区分“未核定”和“已核定”。新伤害默认未核定，可保存但不可运行；已核定且例外为空表示继承游戏规则，详情显示实际适用情况和来源比例属性。特殊来源按资料核定，必要例外只表达明确禁止或覆盖资格、基数与效率；禁止会清除数值引用，覆盖要求本游戏已有同类规则。旧的逐伤害吸血规则字段直接拒绝，未核定不会自动改为继承。
- `src/pages/admin/images/`：图片管理、浏览器侧图片处理与缓存工具（`#/images`）
  - 图片列表使用本地分页，默认每页25条，可选50/100条；翻页只切换当前缓存结果，不请求后端管理列表。查询、重置和切换游戏回到第一页；编辑保存、刷新及同步保留有效页码，清理缓存或结果缩减后回退至有效页。

## 常用验证

开发中先运行受影响的类型或测试检查；以下完整检查在功能收尾执行。阶段提交前再执行非 Wasm 端到端测试。已有结果对应最终代码时，不因代理交接重复执行。

```powershell
cd web
npm run lint
npm run typecheck
npm run test
npm run build
```

本迭代默认页面回归为**非 Wasm**。可复用清单见 [../文档记录/测试记录/web/非Wasm最小回归清单.md](../文档记录/测试记录/web/非Wasm最小回归清单.md)。当前管理页只维护桌面布局，不覆盖移动端。

技能效果、过程、内部状态和触发规则的数值统一提供「固定数值」「技能参数」「技能公式」三种取值来源。参数和公式限当前技能，固定 0 与未配置分别保存；纯固定值不依赖公式目录。时间允许符合范围的小数，次数与层数保持整数要求，直接参数与公式内的动态输入一起核对绑定。

内部状态和效果结果切到“技能公式”后，即使还未选择公式，目录加载失败也会显示重试入口。结果窗口可以直接重试父效果的公式目录，保留两层草稿；重试不会自动保存。2026-09-09 已在隔离浏览器复现原失败并验证两种窗口恢复，587项单测、类型检查、静态检查和构建通过。

阶段 7.5 在技能行提供「条件与触发」入口，不新增导航或路由。当前配置范围为 22 种固定事件；只保存规则聚合，不执行事件/公式，也不含运行时或 Wasm。效果结果共十九种，含普攻计时重置、收到护盾修正、技能急速修正、斩杀、命中联动应用和攻击联动应用。

「来源对象初始化完成」事件（`SOURCE_INITIALIZED`）用于基础属性、挂载技能/装备与初始内部状态准备完毕后一次施加被动。详情为严格空对象，不提供事件数值；当前目标与事件来源均是该来源对象自身，不是战斗对手。表单提供时机与对象说明，切换事件时清理原命中专属配置；后端契约见其 README 的同名说明，不代表前端已经执行初始化或被动计算。

生命周期检查直接读取当前技能效果的实例，支持存在、不存在和层数比较；主体随效果已有范围显示，层数比较复用三种取值且禁止动态输入。已保存条件不能更换种类，删除后新增条件会避开原标识。

「事件对方类别」用于技能命中、普攻命中、来源对象完成击杀、伤害待结算、来源对象造成伤害和来源对象受到伤害，支持多选英雄、史诗野怪、小兵、非史诗野怪和建筑。技能命中和普攻命中固定判断本次实际命中对象，击杀固定判断本次被击杀对象，来源对象造成伤害固定判断本次伤害承受对象，伤害待结算和来源对象受到伤害固定判断本次伤害来源对象；每种事件不增加主体选择，明细仍只含 `{categories}`。切换到其他事件需确认清除该条件。类别条件不作为循环保护，也不代替尚未实现的命中、击杀或伤害事件生产。

「显式目标为来源对象」只用于技能使用事件，明细固定为空对象。它检查回退前的显式目标确实是技能拥有者；没有显式目标时不匹配，不能把无目标施法回退到来源对象当成自施。切换到其他事件会提示并清除该条件，同时移除因此变空的条件组。当前只维护管理配置，不生产技能使用事件，也不执行目标身份判断。

「来源施放资源消耗」供已选择来源技能的技能命中，以及当前技能主动或消耗过程的完成、失败时点绑定。开始时点和取消请求不提供成本。属性来自当前游戏目录，目标限动作可达的计算时输入十进制参数；过程目录和属性目录未成功加载时不能确认绑定，失败保留草稿。完成与失败之间切换保留合法绑定，已有绑定不能更换来源种类，需删除后用新标识新增。当前提供管理录入，不生产运行时施放消耗快照。

施放阶段与消耗、冷却时点遵循规划真源《管理页面与共性机制迭代计划》第4项。技能使用事件必须明确选择首次、再次或蓄力释放；旧记录缺阶段显示待核定，修改前须核定。推进当前过程只选择本技能对应的再次施放或蓄力步骤，沿用已有实例，不填写目标对象或动态输入。失败原因筛选统一用于过程挂接、内部状态操作、普通冷却及过程事件，空值表示不限原因，切离失败时点会清除原因。冷却变化支持设置剩余冷却，按有限非负毫秒填写，允许小数，0表示立即可用；负上界和有效数值溢出不能保存。上述管理表达不代表过程执行或战斗运行已完成。

## 常见问题

### 1. 页面能打开，但接口请求失败
