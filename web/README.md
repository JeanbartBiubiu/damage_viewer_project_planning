强化消费后的自动资格链通过完整过程可选 `empoweredPredecessorUseRef`（直接资格前项使用）核对真实因果，最多沿原16项配置回溯，不靠同毫秒或有限日志猜顺序。只有能证明在该刀命中之后启动的后项首步占用，才能与已成立的该刀区分；其它占用仍阻止攻击。普通资格链原输出省略该字段。正式单工作线程专项36场／170次运行、27项因果篡改拒绝及100次同会话重复均通过，原始证据与复现命令见 `output/first-hero-2026-10-17/priority-empowered-worker/验收记录.md`，不代替完整盖伦Q或整英雄证明。

“计算模拟”菜单新增独立的“混合战斗分析”页，地址为`#/simulation/combat-analysis`，可在该页选择双方、装备／构筑及实际技能来源，配置并执行自动循环。背景普攻默认开启，可关闭观察纯主动。原`#/simulation/basic-attack`保留单次／连续普攻及固定时刻技能计划，其自动循环入口导航到新页。两个页面共用`SimulationScenarioPanel.tsx`中的场景装配与任务管理，各自持有输入和结果；切页后旧任务与响应不能进入新页。

混合页使用独立的`CombatScenarioSetup.tsx`：选择双方角色与等级后，自动列出真实绑定技能，只需调整启用和等级，不再选择普攻或逐个添加主动。唯一普攻自动带入；缺失或歧义时允许关闭普攻运行纯主动，不猜选主体。主动按完整配置的首次主动入口识别，被动不生成施放规则。首次等级为真实最高等级，0、清空、关闭和自定义低等级保留；关闭不删除连招草稿，换角色清理原角色规则。双方桌面并排、窄屏上下排列，构筑与其它来源、施放高级设置及配置版本分别折叠。全部主动关闭时走现有连续普攻路径，自动专属记录设置隐藏；原普攻页的布局、手动主体和固定计划流程保持。

准备计算后不再要求逐项勾选施法成本或确认技能配置。页面依照游戏中明确配置的普通费用属性、真实主动来源和过程开始挂接自动识别可忽略成本，识别结果保存在计算档案中；同一技能同一普通资源有多项开始消费时拒绝猜选，弹药、计数和其它必要消费继续严格校验。当前协议没有独立的费用用途字段，单项费用的自动识别以这些现有约束为边界。配置版本只读折叠展示。执行前仍重读完整快照；配置有变化时重新预检并保留输入，本次不运行，补全新增输入后可直接重新开始。

混合页还读取后端的完整对象计算可用目录：只有当前正式Wasm、适配器、数据和原优先范围全部匹配的完整核验对象才可选。未完成英雄、装备仍可搜索，显示禁选原因；目录失败可重试，不能回退成全部可选。准备和运行前重新读取目录，失效时保留原选择、技能等级与规则草稿并阻止计算。原范围内明确排除且实际绑定的技能自动关闭并锁定，显示原因；不关闭任何必需技能来获得整英雄通过。原普攻页和管理页不加此完整对象门禁。

自动规则最多16项真实已绑定、已开启且已学的攻击方技能，支持上下移动就绪优先顺序、多项关联冷却，以及每项至多一个前置、一个后继的释放资格链。自动模式接入单步骤即时、有限延时或强化下一次普通攻击的首次过程，无需逐次填写施放毫秒；其它复杂控制继续使用原页的固定时刻计划。

新页结果展示双方生命、累计伤害及累计／窗口伤害率、完整来源／类型贡献、自动／普攻／伤害／直接治疗事实及真实使用详情。曲线直接消费Wasm采样；汇总模式仍可单独请求曲线。全场累计不随筛选变化，有限明细不反算总额；资格两端、无使用关联及治疗原数组位置分别解释。自动冻结档案展示版本为2，白名单视图与完整原结果一并下载，Wasm运行协议及产物保持。

自动规则直接生成首次阶段的真实场景闭包，由 `automaticSkillRequest.ts` 独立装配，不造手动动作。来源关闭、等级清空、删除被引用规则或关系失效时保留草稿并报告字段路径；作者摘要变化时重新读取及预检，本次停止后可直接再次执行，规则、目标或模式变化使旧结果过期。结果独立核对每项规则与真实过程的开始、终结、最后等待，以及资格授予／消费守恒；明细预算0、截断和只返回汇总保持完整累计。被动内部冷却通过现有状态用途字段显式运输，技能自身／实际目标作用域保持。

机制与字段的唯一共享定义见规划真源[主动技能自动调度与连招约束详细设计](../文档记录/详细设计/项目/主动技能自动调度与连招约束详细设计.md)。独立构造的正式工作线程专项入口为 `node node_modules/@playwright/test/cli.js test --config tests/fixtures/simulationAutomaticSkills.config.ts --reporter=line`，复用运行中的5173服务，可用 `SIMULATION_WEB_BASE` 指定地址；2、3、4、16项链及背景普攻分别核对重复运行、记录预算、汇总、错误恢复和释放重编。专项构造不替代真实英雄作者数据与页面验收。

真实目录还直接经过生产准入函数，精确接纳当前正式证明集合，其余对象带原因禁选；这项函数验证与浏览器可操作性分开记录。当前正式资源包含安妮、盖伦在约定单向1V1范围内的完整必要来源及原19件纯属性装备。实际页面专项分别验证未就绪英雄保持禁选，以及通过英雄可直接选择、调整技能等级、准备并运行到结果与会话释放。不伪造HTTP，也不关闭必需兄弟技能绕过门禁。当前证据由`SIMULATION_LIVE_OUTPUT_DIR`另存于`output/combat-analysis/scene-initial-final-live-*`；未启用真实服务导致的跳过不计作验收。

  - 查看或编辑技能主体、效果、过程和规则时，详情返回前只显示加载提示；读取失败保留重试入口，不展示可被响应覆盖的默认表单。技能主体每次打开都读取当前详情，启停也先读最新主体再仅改变状态，避免旧列表覆盖已更正字段。结果引用目录未返回时显示加载提示，完成后再判断是否缺少引用。规则来源技能在目录加载中或失败时分别显示对应状态，成功返回后才标记缺失；重试保留当前键与草稿。
  - 效果编辑器结果表的关键引用摘要并列显示名称与稳定标识；参数、公式、属性、状态、目标效果、技能和分类在目录加载中、加载失败、成功但缺失时分别标明，停用目录显示停用。摘要同时给出作用对象与明确单位：冷却减少/增加/设置剩余为毫秒，按比例减少剩余冷却为比例，重置为可用无数值；生命周期延长剩余时长为毫秒，层数与次数使用对应标签；仅普通移动减速的施加标注减速比例，修正类按既有标签标比例，未知属性或伤害单位不猜测。固定 0 显示 0，未配置不补 0。技能范围超过三项默认前三项和总数，可展开查看全量；展开只改变展示，不产生草稿或保存请求。不在顶层效果列表重复这些摘要。

## 常见问题

### 1. 页面能打开，但接口请求失败

- 确认后端服务是否已启动。
- 检查页面内 API 基址与 `VITE_API_BASE_URL`。
- 若浏览器缓存了旧地址，清理本地存储后重试。

### 2. 根地址没有进入属性管理

- 空 Hash 与无法识别的旧 Hash 都会落到 `#/attributes`。
- 确认前端构建已包含当前路由，而不是仍打开旧总览页。
