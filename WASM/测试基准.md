## 默认口径

### 固定输入口径

- 本文档中的人物属性，进入 Wasm 前都视为已经编译完成的固定初始值。
- Wasm 不再根据“人物等级”重新推导基础属性成长。
- 本文档中的“成长攻击速度”在测试基准里等同于“额外攻击速度”，不表示等级成长语义。
- 总攻击速度 = 基本攻击速度 + 额外攻击速度 * 攻击速度系数。

### 事件与排序口径

- 若未单独指定优先级，则按引擎默认排序处理。
- 同一时刻多个事件同时可执行时，按引擎默认 `(tMs, priority, seq)` 顺序处理。
- `t=0` 时，双方所有技能默认都处于可释放状态。
- 未显式写前摇、后摇、引导时间的技能，默认视为无前摇、无后摇、无引导。
- 未显式写资源消耗的技能，默认资源消耗为 `0`。
- 本阶段只关心法力值资源；普通攻击和被动默认不消耗法力值。
- 技能释放前先校验法力值是否足够；法力值不足时，该技能本次施法失败。
- 因法力值不足而失败的施法，不扣法力、不进入冷却、不产生伤害/护盾/DoT/攻击特效/减 CD 等后续效果。
- 自动决策时，若高优先级技能因法力值不足不可释放，则继续尝试下一个优先级技能；若本时刻没有任何可释放动作，则等待下一事件。

## 装备
### 我方装备
1. 吸血刀
	装备属性: 攻击力30 攻击速度0.3 生命偷取0.1(普通攻击造成的实际伤害的0.1倍可用来回复生命值)
	装备效果: 可以触发攻击特效，造成敌方额外当前生命值8%的物理伤害

2. 魔法刀
	装备属性: 法术强度 100 攻击速度0.5 技能极速20
	装备效果：可以触发攻击特效，额外造成20+当前法术强度*0.15的魔法伤害

3. 面具
	装备属性: 法术强度 50 生命值400
	装备效果：造成主动技能魔法伤害时，敌方3s内每秒额外受到2%最大生命值的魔法伤害
4. 黑切
	装备属性: 攻击力45 生命值250 技能极速15 护甲穿透10
	装备效果: 造成物理伤害时，减少敌方5%最大护甲，最大可以叠加6层减少30%，同一攻击事件内多个物理伤害分量可以叠加多层；所有层数共享一个持续时间，新的叠层会刷新总持续时间到5s

5. 多兰之刃
	装备属性: 攻击力10 生命值100

## 技能
### 我方技能
1. 普通攻击(普通攻击是特殊的一种技能
	冷却计算公式:1/(攻击速度+(成长攻击速度系数*成长攻击速度))
	法力消耗: 0
	造成效果: 对敌方造成面板最大攻击力物理伤害
	是否可进行暴击判定:可以

2. 技能：秘术射击
	冷却: 10s * (100/(100+技能极速))
	法力消耗: 25
	造成效果: 对目标造成100 + 1.0*当前攻击力 + 0.2*当前法术强度的物理伤害，同时可以附带攻击特效，所有技能的冷却减少1s

3. 技能: 奥术跃迁
	冷却: 15s * (100/(100+技能极速))
	法力消耗: 40
	造成效果: 对目标造成200+ 0.8 * 当前法术强度的魔法伤害

4. 技能: 数3
	法力消耗: 0
	每次攻击会对目标打上标记，标记达到3后对目标造成额外1%的最大生命值真实伤害

### 敌方技能
1. 生成护盾
	法力消耗: 0
	每隔8s，生成50+最大生命值*1%的普通护盾；`t=0`时可立即释放；若已有护盾存在，则与新护盾不累加，取“当前剩余护盾值”和“新生成护盾值”中的较大值，并按该值刷新护盾

2. 眩晕
	冷却时间7s*(100/(100+技能极速))
	法力消耗: 0
	对敌方造成0.5s眩晕；眩晕期间目标无法普通攻击和释放技能；若当前存在可被打断的动作，则立即打断

### 我方技能释放优先级
奥术跃迁>秘术射击>普通攻击

### 敌方动作规则

- 敌方没有普通攻击技能，因此整个测试过程中不会进行普通攻击。
- 敌方只会释放文档中列出的技能：`生成护盾`、`眩晕`。
- 敌方技能若未单独指定优先级，则按引擎默认排序处理。

### type = 1003

## hp削减类型
魔法伤害、物理伤害、真实伤害。

## 治疗
生命偷取效果:普通攻击类型的伤害，可以额外获得实际伤害值*生命偷取*(1+治疗强度)的生命回复。

- 普通攻击本体伤害可以触发生命偷取。
- 普通攻击附带的攻击特效伤害也可以触发生命偷取。
- 秘术射击的技能本体伤害不触发生命偷取。
- 秘术射击附带的攻击特效伤害可以触发生命偷取。

## 护盾
普通护盾，可以额外豁免折后伤害。

## 公式
注意，乘区不体现在公式里，要额外进行计算处理
### 物理伤害
实际值=输入值*(100/(100+敌方当前护甲-我方护甲穿透))
### 魔法伤害
实际值=输入值*(100/(100+敌方当前魔抗-我方法术穿透))
### 真实伤害
实际值=输入值

## 最小验收记录项

- 最终结果至少要能确认 `stopReason = enemyDead`。
- 首次普通攻击事件需要记录：
  - 普攻本体原始伤害
  - 攻击特效分项伤害
  - 折后总伤害
  - 生命偷取回复值
- 首次秘术射击事件需要记录：
  - 技能本体原始伤害与折后伤害
  - 附带攻击特效的分项伤害
  - 成功释放前后的法力值变化
  - 技能冷却减少1s后的结果
- 首次奥术跃迁事件需要记录：
  - 技能本体原始伤害与折后伤害
  - 成功释放前后的法力值变化
  - 是否成功触发面具
  - 面具3次DoT每次的原始值和折后值
- 护盾相关至少要记录：
  - `t=0`首次护盾生成值
  - 首次受击后护盾剩余值
  - 再次生成护盾时是否按取大值刷新
- 黑切相关至少要记录：
  - 每次叠层后的层数
  - 当前护甲值
  - 5s未继续叠层后是否正确清空
- 眩晕相关至少要记录：
  - 首次眩晕生效时间
  - 首次眩晕结束时间
  - 眩晕期间我方动作是否被阻断
- 资源门禁相关至少要记录：
  - 首次因法力不足而被阻止的技能 ID
  - 被阻止时的当前法力值与技能耗蓝
  - 该次阻止后未扣法力、未进入冷却、未产生伤害或触发效果
