## 6. 建议排查顺序

### 6.1 改接口时

1. [接口定义.md](server/game_manage/接口定义.md) 或 user_manage 契约。
2. `combatDataClient` / `apiClient` 是否对齐。
3. 对应 Controller / `service/combatdata`。

### 6.2 改页面时

1. `App.tsx`、`navigation.ts`。
2. `pages/admin/combat-data/**` 或目标页面。
3. 回契约确认路径与字段。

### 6.3 改发布链路时

1. `VersionPublishPage` / `usePublishFlow`
2. 接口定义发布节
3. `VersionAdminController` → `GameDataService` → `CombatDataPublishService`

### 6.4 改 Wasm 宿主时

1. `WasmValidationGenericPage` → `combatDataAssembler` → `genericEngineClient` → `tinygoV2Bridge`
2. 确认 ABI 仅为 compile / run / release_session

## 7. 维护约定

1. 新增页面时，补充本索引中的“页面到接口”映射。
2. 新增接口时，先更新对应 `接口定义.md`，再补本索引。
3. 本文件只做定位信息，不承载接口字段级真源定义。
4. 不要把已删除的 Bundle/Catalog/hero·item·skill 专用路由写回「当前」映射。
