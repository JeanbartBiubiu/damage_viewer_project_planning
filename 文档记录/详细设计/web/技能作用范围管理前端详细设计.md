## 4. 接口类型

在 `web/src/types/skillEffect.ts` 新增公共类型：

```ts
export type SkillEffectAffectedSkillScopeMode =
  | 'ALL'
  | 'SKILLS'
  | 'CATEGORIES'

export interface SkillEffectAffectedSkillScope {
  mode: SkillEffectAffectedSkillScopeMode
  skillKeys: string[]
  skillCategoryKeys: string[]
}
```

修改：

1. 冷却变化明细删除 `affectedSkillKeys`，改为必填 `affectedSkillScope`。
2. 结果种类加入 `SKILL_HASTE_MODIFIER`。
3. 新增技能急速明细类型，固定包含增加/减少操作和公共技能范围。
4. 结果固定联合显式包含新结果，不用宽类型或索引签名兜底。
5. 前端不兼容读取、提交或双写旧 `affectedSkillKeys`。
6. `web/src/services/skillEffectClient.ts` 的结果种类集合与协议断言同步验证公共范围严格形状和技能急速明细；协议失败必须指出实际嵌套路径。

## 5. 表单草稿和转换

### 5.1 公共范围草稿

在 `effectForm.ts` 建立唯一范围草稿结构：

```ts
interface AffectedSkillScopeDraft {
  mode: 'ALL' | 'SKILLS' | 'CATEGORIES'
  skillKeys: string[]
  skillCategoryKeys: string[]
}
```

默认值为 `ALL` 且两个数组为空。

### 5.2 归一化

1. 切换为 `ALL` 时清空两个数组。
2. 切换为 `SKILLS` 时清空分类数组。
3. 切换为 `CATEGORIES` 时清空技能数组。
4. 不静默替用户去重；重复值由前端校验阻止，后端仍是最终校验边界。
5. API 回读缺少公共范围时视为损坏数据，不猜测旧字段或默认目标。
6. 已停用或页面目录中缺失的旧引用保留标识并显示不可用状态，不能在打开、切换或再次保存前被静默删掉。

### 5.3 结果转换

1. 冷却变化继续沿用既有操作和值规则组合，只替换范围字段。
2. 技能急速修正必须生成数值规则、持续生命周期和施加时快照读取。
3. 技能急速草稿不生成乘区、法术护盾范围或立即前序输出选项。
4. 编辑其他结果时不得残留范围字段。
5. `requiresValueRule`、`isPersistentNumericResult` 与 `isPersistentOnlyResultType` 显式加入技能急速修正；固定生成 `PERSISTENT + APPLICATION_SNAPSHOT + SHARED + KEEP`，不加入按当前时点读取名单。

## 6. 公共技能范围控件

新增 `SkillEffectAffectedSkillScopeFields.tsx`，只负责公共范围输入，不拥有结果操作、公式或生命周期：

1. 标题统一为“技能范围”。
2. 范围单选为“全部技能 / 指定技能 / 指定技能分类”。
3. `ALL` 不显示目标选择。
4. `SKILLS` 显示现有启用技能多选。
5. `CATEGORIES` 显示启用分类多选和“新增技能分类”入口。
6. 多选按目录顺序显示，不自动推导角色技能或装备技能。
7. 同一技能属于多个已选分类不在前端展开或去重；页面只保存分类引用。
8. 控件接收字段错误和停用引用展示所需目录，不自行发请求或保存。

冷却变化与技能急速修正必须调用同一控件，不能复制两份范围表单。

## 7. 结果弹窗

`SkillEffectResultEditorModal.tsx`：

1. 结果种类增加“技能急速修正”。
2. 冷却变化和技能急速修正显示公共技能范围控件。
3. 技能急速修正显示增加/减少、数值公式、固定倍率、固定最小值、固定最大值和持续生命周期相关字段。
4. 生命周期时点固定为“持续生效”，数值读取固定为“施加时快照”；固定值可展示为只读或隐藏，不允许选择非法组合。
5. 技能急速修正不显示乘区和法术护盾阻挡范围。
6. 结果类型切换时清除旧类型不再可见的草稿字段。
7. 保存失败时保留结果、范围、公式和生命周期草稿。
8. 保存成功继续关闭当前结果弹窗并回到父效果弹窗，父弹窗显示未提交结果。

## 8. 内嵌新增技能分类

1. 仅在范围为“指定技能分类”时显示入口。
2. 复用现有技能分类新增弹窗和接口，不新增简化版分类表单。
3. 新增成功后刷新分类目录并自动将新分类加入当前多选。
4. 新增失败只留在分类弹窗，不清空父结果草稿。
5. 取消分类弹窗返回父结果，不改变已选分类。
6. 新增后仍按目录顺序规范化显示。

## 9. 摘要和查看

`SkillEffectEditorModal.tsx` 的结果摘要增加：

1. 全部技能：显示“全部技能”。
2. 指定技能：显示已选技能名称；目录缺失时保留稳定标识。
3. 指定分类：显示分类名称；目录缺失或停用时给出明确状态。
4. 技能急速修正显示“增加/减少 + 公式摘要 + 技能范围”。
5. 冷却变化保持原操作和数值摘要，再追加公共范围摘要。

摘要不展开分类命中的技能，不显示数据库名、接口字段或阶段说明。

## 10. 校验与错误映射

前端在发送前校验：

1. `ALL` 两个数组都为空。
2. `SKILLS` 至少一个技能且分类数组为空。
3. `CATEGORIES` 至少一个分类且技能数组为空。
4. 两个数组均无空值和重复值。
5. 技能急速有增加/减少操作、数值公式和合法持续生命周期。
6. 冷却变化继续执行既有操作和值规则校验。
7. 移除现有冷却变化对 `affectedSkillKeys.length === 0` 的无条件报错；仅 `SKILLS / CATEGORIES` 要求各自目标非空，`ALL` 必须允许两个数组为空。

后端字段问题映射到：

```text
results[n].detail.affectedSkillScope.mode
results[n].detail.affectedSkillScope.skillKeys[n]
results[n].detail.affectedSkillScope.skillCategoryKeys[n]
results[n].lifecycleBehavior.moment
```

无法精确落到控件的错误显示在结果弹窗顶部，不关闭弹窗。

## 11. 目录加载

1. 打开结果弹窗时沿用现有技能目录，不新增逐项请求。
2. 仅冷却变化或技能急速修正需要加载范围目录。
3. 仅进入分类模式或回读存在分类引用时加载技能分类目录；如果现有页面已统一缓存目录，则复用缓存，不重复拉取。
4. 内嵌新增成功后只刷新技能分类目录。
5. 目录请求失败时禁止保存依赖该目录的范围，但保留其他草稿。
