## 4. 类型与客户端契约

### 4.1 效果类型

`skillEffect.ts` 在十三种结果上增加：

1. `EXECUTE` 及 `{ attributeKey }` 强类型 detail。
2. `HIT_LINK_APPLICATION` 及明确空 detail。
3. `ATTACK_LINK_APPLICATION` 及明确空 detail。

结果联合总数精确为十六种。三种结果都使用既有 `valueRule`，继续携带阶段 7.6.3 公共 `spellShieldBlockScope`，但不携带 `modifierZoneKey`、不使用 `MOMENT_EVALUATION`；请求和响应不能改为宽可选接口。前十三种结果的乘区字段与生命周期读取联合保持不变。

### 4.2 触发规则类型

1. 事件联合增加 `HIT_LINK_APPLIED / ATTACK_LINK_APPLIED` 和 `{ sourceSkillKey: string | null }` detail，总数精确为二十一种。
2. 两种事件声明 `EVENT_SOURCE` 不可用、事件值为空。
3. 事件值联合和 `PRIOR_ACTION_RESULT.outputKind` 保持阶段 7.6.3 集合，不提前加入联动值或击杀输出。

### 4.3 客户端响应检查

开发环境最小协议检查增加：

1. 三种结果 detail、数值规则、离散生命周期行为和阻挡范围基本形状。
2. 两种联动事件 detail 和 null/字符串来源技能。
3. 未知后段输出或在联动事件中返回事件值时抛明确协议错误。

客户端不得静默补默认、删除字段或把空 detail 当任意对象。

## 5. 效果草稿与映射

`effectForm.ts` 增加：

1. 三种结果的完整草稿、固定默认 detail 和既有数值规则初始化。
2. `fromDetail` 无损保留属性、公式、固定倍率/上下限、阻挡范围和生命周期时点。
3. `toCreateRequest / toUpdateRequest` 只提交当前结果合法字段；切换结果种类时清除旧种类 detail。
4. 三种结果禁止持续生效；从持续结果切换时列出生命周期字段清理并要求确认，取消则保持原草稿。
5. `isSpellShieldBlockScopeVisible` 的封闭结果种类白名单显式加入三种新结果；合格 `target = TARGET` 离散结果复用阶段 7.6.3 阻挡范围流程，但候选项只含 `SKILL / EFFECT / RESULT`，不含“只阻挡当前伤害实例”。非目标对象、持续时点或回读到 `DAMAGE_INSTANCE` 时按现有确认/协议错误流程拒绝，不静默改写。
6. 保存成功后使用后端完整详情重建草稿，不推测次数、击杀或联动状态。
7. `fromDetail`、草稿复制、脏状态比较、种类清理和两个请求转换入口继续无损保留其他结果的 `modifierZoneKey`、停用旧引用显示和 `MOMENT_EVALUATION`；切换到三种新结果时才清理当前结果旧乘区字段。

## 6. 斩杀结果编辑

1. 结果种类显示中文“斩杀”。
2. 专属字段为“生命属性”和既有数值规则，公式标签为“斩杀阈值公式”。
3. 固定说明：“目标当前生命属性小于等于阈值时形成斩杀结果；它不是额外伤害。”
4. 属性目录只显示同游戏可选数值属性；页面不按标识或中文名猜测生命属性。
5. 不显示伤害类型、伤害数值、金币奖励、实际击杀状态或 `KILLED` 输出。
6. 禁止持续生效；其他离散/周期时点沿用阶段 7.4 现有字段。

## 7. 命中联动与攻击联动结果编辑

1. 结果种类显示中文“命中联动应用”“攻击联动应用”。

## 17. 开发获批后的真实浏览器验收

只在后端本阶段真实迁移、接口、重启回读和事务回滚验收通过后执行：

1. 用真实效果、公式、属性、过程和规则完成共享契约艾希 Q、鬼索和收集者骨架案例。

3. 后端重启后再次打开，核对三种结果、来源技能、延迟过程挂接和范围完整。
4. 尝试非法持续时点、联动事件值、技能删除和无保护循环，确认字段错误定位、草稿保留和原数据不变。
5. 确认页面没有阶段 7.6.5 输出/事件值、实际运行、计算预览、发布或 Wasm 请求。

## 18. 前端停止条件

出现以下任一情况停止编码并回到共享契约：

1. 阶段 7.6.3 最终类型、过程挂接、法术护盾范围、乘区目录与动态读取、技能目录或候选图错误结构与本文前提不一致。
2. 需要增加丰富输出、联动事件值、自由联动目标或实际攻击运行才能完成本阶段表单。
3. 需要建立第二套效果/规则编辑器、主导航或独立路由。
4. 页面必须手写 JSON、自由表达式或数据库复合键才能保存。
5. 需要在前端复制完整规则图或执行斩杀、联动、攻击、事件、预览或 Wasm。
6. 后端真实接口或浏览器验收不可用且无法定点确认原因。
