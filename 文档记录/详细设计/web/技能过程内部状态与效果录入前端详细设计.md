## 3. 类型与客户端

### 3.1 内部状态强类型

`web/src/types/skillInternalState.ts` 定义：

1. `SkillInternalStateSummary`、`SkillInternalState`
2. `SkillInternalStateType`、`SkillInternalStateScope`
3. 五种内部状态 `detail` 类型
4. 以 `stateType` 为判别字段的详情联合类型
5. `SkillInternalStateModeOption`
6. `CreateSkillInternalStateRequest`、`UpdateSkillInternalStateRequest`

联合类型必须保证：

1. 计数和弹药只能访问数值与恢复字段。
2. 模式只能访问模式选项。
3. 准备标记只能访问初始启用值。
4. 内部冷却只能访问时长公式。
5. 更新请求不包含 `stateKey`。

### 3.2 过程强类型

`web/src/types/skillProcess.ts` 定义：

1. `SkillProcessSummary`、`SkillProcess`
2. `SkillProcessActivationType`、`SkillProcessStepType`
3. 八种步骤明细和以 `stepType` 为判别字段的步骤联合类型
4. 过程级时点和步骤级时点组成的 `SkillProcessMoment` 联合类型
5. `SkillProcessCooldown`、`SkillProcessEffectBinding`
6. 以操作值区分数值、模式、准备标记和内部冷却形状的 `SkillProcessStateOperation` 联合类型
7. `CreateSkillProcessRequest`、`UpdateSkillProcessRequest`

`SkillProcessMoment` 必须让过程级时点只能携带 `stepKey: null`，步骤级时点只能携带非空步骤键。不得用 `Record<string, unknown>`、任意配置对象或旧 combat-data 过程类型代替判别联合。

### 3.3 客户端

`skillInternalStateClient.ts` 提供：

1. `listSkillInternalStates`
2. `getSkillInternalState`
3. `createSkillInternalState`
4. `updateSkillInternalState`
5. `deleteSkillInternalState`

`skillProcessClient.ts` 提供：

1. `listSkillProcesses`
2. `getSkillProcess`
3. `createSkillProcess`
4. `updateSkillProcess`
5. `deleteSkillProcess`

所有游戏、技能、状态和过程路径片段使用 `encodePathSegment`，所有请求使用现有 `requestJson` 和 Admin Token。客户端不执行或归一化公式和过程，只传递共享契约中的强类型聚合。

## 6. 过程与内部状态主弹窗

标题固定为“过程与内部状态 - {技能名称}”。页签顺序为“技能过程”“内部状态”。

### 6.1 技能过程列表

列表列为：

1. 过程名称
2. 稳定标识
3. 启动方式
4. 步骤数量
5. 效果挂接数量
6. 内部状态操作数量
7. 排序
8. 更新时间
9. 操作

顶部提供“新增过程”和“刷新”；行操作提供“查看”“编辑”“删除”。空列表显示“暂无技能过程”。

### 6.2 内部状态列表

列表列为：

1. 内部状态名称
2. 稳定标识
3. 状态种类
4. 保存范围
5. 排序
6. 更新时间
7. 操作

顶部提供“新增内部状态”和“刷新”；行操作提供“查看”“编辑”“删除”。空列表显示“暂无内部状态”。

### 6.3 请求和切换行为

1. 两个页签分别维护递增请求序号，旧请求不能覆盖切换技能、切换页签或刷新后的结果。
2. 一个页签加载失败不清空另一个页签，也不阻止查看另一个页签已有数据。
3. 删除使用组件库默认确认弹窗；成功后关闭确认并刷新当前列表，失败保留确认和错误。
4. 删除内部状态收到 `409.SKILL_INTERNAL_STATE_IN_USE` 时直接显示业务提示，不解析数据库原文；删除过程成功时只清理当前过程，不会触发效果使用中错误。

## 7. 内部状态编辑器

### 7.1 公共字段

展示：内部状态标识、名称、状态种类、保存范围、排序和说明。

1. 创建时种类和范围可选；编辑已有记录时标识、种类和范围只读。
2. 状态种类显示中文：计数、弹药、模式、准备标记、内部冷却。
3. 保存范围显示“技能自身 / 按当前目标分别保存”；只有计数允许选择后者。
4. 切换新建种类时清空上一种类明细和不再适用的范围。

### 7.2 类型专属字段

1. 计数：初始值公式、上限公式。
2. 弹药：初始值公式、上限公式、恢复间隔公式、恢复方式。
3. 模式：至少两行选项，每行维护选项标识、名称、排序和是否初始；必须且只能选一个初始项。
4. 准备标记：初始是否启用。
5. 内部冷却：时长公式，标签注明“结果按毫秒解释”。

模式选项在父级草稿内新增、编辑和删除。编辑已有模式时选项标识只读；删除服务端返回仍被引用错误时保留完整草稿和对应行错误。

### 7.3 公式目录

1. 计数、弹药和内部冷却按需加载同一技能公式。
2. 公式目录加载失败只阻止依赖公式的状态种类，不影响模式或准备标记的新增、查看和编辑。
3. 查看已保存记录时，目录中找不到公式仍用稳定标识兜底显示；编辑保存被禁用并展示目录不完整错误。
4. 页面不嵌入公式编辑器、不显示公式结果，也不硬编码 0、最大层数、弹药数或冷却时长。

## 8. 技能过程编辑器

### 8.1 基本资料与聚合草稿

过程编辑器展示过程标识、名称、启动方式、排序和说明，并分区维护：

1. 普通冷却
2. 过程步骤
3. 效果挂接
4. 内部状态操作

新建过程从一个立即步骤草稿开始；配置有效普通冷却、效果挂接或内部状态操作至少一项后才能提交。编辑先读取完整详情；详情未加载成功前不能保存。

启动方式显示主动、被动和消耗，不显示外部触发事件。编辑已有过程时过程标识只读，启动方式可以修改。

### 8.2 普通冷却

普通冷却区提供“无普通冷却 / 配置普通冷却”。启用后维护：

1. 冷却时长公式
2. 冷却开始时点
3. 时点需要步骤时选择当前过程草稿中的步骤

字段旁明确写“时长按毫秒解释”。普通冷却区不出现减少、增加或重置其他技能冷却选项，后者继续在“效果与结果”维护。

### 8.3 过程步骤列表

列表列为：步骤名称、稳定标识、步骤种类、关键时间或次数摘要、排序、操作。

1. 新增和编辑使用步骤子弹窗；查看模式只允许查看。
2. 步骤按 `sortOrder/stepKey` 显示，通过排序数字调整，不提供拖拽或关系图。
3. 删除步骤前检查普通冷却、效果挂接和状态操作草稿中的时点引用；存在引用时阻止删除并列出引用区域。
4. 已有步骤编辑时标识和步骤种类只读。

### 8.4 效果挂接列表

列表列为：挂接标识、效果、过程时点、排序和操作。

1. 效果选择器读取同一技能阶段 7.2 效果摘要。
2. 已有挂接编辑时挂接标识只读；需要更换稳定标识时明确删除旧挂接并新增新挂接。
3. 过程时点选择器先选中文时点；步骤型时点再选择当前草稿步骤。
4. 同一效果允许使用不同挂接标识挂到多个时点。
5. 资源扣除和失败返还不出现独立数值表单；维护者选择已经包含相应资源结果的效果。
6. 页面不根据效果名称猜测资源成本，也不拆开效果结果重新编辑。

### 8.5 内部状态操作列表

列表列为：操作名称、稳定标识、内部状态、操作、数值公式或模式选项摘要、过程时点、排序和操作。

1. 先选择内部状态，再按状态种类显示允许操作。
2. 计数和弹药的增加、减少、消耗和设置显示数值公式；重置不显示。
3. 模式选择显示该模式的选项；准备标记和内部冷却不显示额外值。
4. 过程时点使用当前草稿步骤目录。
5. 已有操作编辑时操作标识和操作种类只读。

## 9. 八种步骤编辑字段

步骤公共字段为步骤标识、名称、种类、排序和说明。专属字段如下：

1. 立即：无额外字段。
2. 延迟：延迟公式。
3. 多段：执行次数公式、可选间隔公式。
4. 周期：执行次数公式、间隔公式、首次执行时机。
5. 引导：持续时间公式、执行次数公式、首次执行时机。
6. 蓄力：最短蓄力公式、最长蓄力公式、到达最长时间是否自动释放。
7. 重施：重施窗口公式、最大重施次数公式。
8. 强化下一次普通攻击：有效窗口公式、攻击发起或攻击命中时消耗。

所有时间字段标签注明按毫秒解释；次数字段注明未来按正整数解释。页面只选择同技能公式，不执行公式、不比较两个公式结果，也不提供单位切换。

切换新建步骤种类时必须清空上一种类专属字段，不能把隐藏草稿带入请求。

## 10. 目录加载与引用保护

1. 过程编辑器缓存同一技能公式、效果摘要和内部状态摘要；模式状态需要时再读取详情获取选项。
2. 每类目录使用独立请求序号；切换技能、关闭过程弹窗或切换内部状态后，旧请求不得覆盖新目录。
3. 公式、效果和内部状态没有独立启停筛选；所属技能停用后仍能维护完整配置。
4. 某类目录加载失败只阻止新增或编辑依赖该目录的草稿区域，不影响过程列表、完整只读详情和不依赖该目录的区域。
5. 已保存引用在目录中缺失时显示稳定标识和“目录缺失”，禁止编辑保存，避免误覆盖未知引用。
6. 过程编辑期间内部状态或效果在其他弹窗被删除导致保存冲突时，保留整个过程草稿并定位服务端字段错误。
7. 页面不缓存或复制效果结果、公式表达式和模式以外的目录明细。

## 12. 弹窗与页面行为

1. 主弹窗、聚合编辑、子项编辑和删除确认都使用 Arco 默认 Modal。
2. 不覆盖弹窗边框、阴影、定位或建立新的全局宽度样式。
3. 打开子弹窗时父级草稿保持不变；子弹窗保存只更新父级草稿。
4. 过程或内部状态保存成功关闭当前编辑弹窗并刷新对应列表；失败时保留全部草稿、活动页签和字段错误。
5. 点击遮罩或按 Esc 关闭编辑弹窗时直接丢弃该聚合未保存草稿，不增加二次确认；同时通过现有 `onDirtyChange` 清理页面未保存状态。
6. 保存进行中禁用重复提交和关闭动作。强化下一次普通攻击步骤中，“消耗时点”只控制准备状态何时消耗；效果挂接的步骤执行始终显示为“普通攻击命中时执行”。
7. 页面不显示用途说明、阶段边界教学、未来功能占位、执行按钮或计算预览。

## 15. 前端停止条件

1. 阶段 7.2 客户端、类型或后端效果接口与共享契约不一致。
2. 后端过程或内部状态接口要求提交数组之外的大块配置、自由脚本或旧 combat-data 结构。
3. 内部状态或步骤无法用判别联合表达，必须退回任意对象或多个冲突可空字段。
4. 实现需要复制效果结果、公式表达式、参数等级 Map 或资源数值到过程草稿。
5. 实现需要提前加入效果与状态生命周期、条件、外部事件、动态输入供值、暴击、吸血或前序结果控件。
6. 实现需要修改导航、App 路由、全局弹窗样式、通用关系图、计算页面或 Wasm 适配器。
7. 完整前端验证或真实浏览器验收不可用，且不能定点确认原因。

出现任一项时停止并回到共享契约确认，不用隐藏字段、自由文本或旧页面兼容绕过。
