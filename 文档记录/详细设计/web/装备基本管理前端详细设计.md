# 装备基本管理前端详细设计

本文实施[装备基本管理共享契约](../项目/装备基本管理详细设计.md)，不重复定义接口字段和错误含义。

## 1. 页面

新增独立“装备管理”导航和页面。列表提供关键词查询、重置、刷新、新增、查看、编辑、装备属性和删除。

基本资料弹窗复用角色页已经确认的默认弹窗行为：遮罩可关闭，保存成功自动关闭，保存失败保留，存在未保存修改时沿用全局离开保护。

## 2. 装备属性

装备属性弹窗一次读取装备属性和属性定义。主体按行显示属性名称、标识、当前数值与操作，提供搜索、只显示已配置和添加属性。

未配置显示 `—`；设置或编辑只录入一个直接数值。属性定义中的`百分比护甲穿透`正常进入列表；页面不提供`生命值增加 10%`这类乘算规则。保存时提交稀疏 Map，成功后自动关闭弹窗。

## 3. 写入范围

1. 新增装备类型和 API 客户端。
2. 新增装备管理页面及资料、属性弹窗。
3. 在应用路由和导航中增加 `#/equipment`，不恢复旧 item 页面。
4. 更新前端单元测试和非 Wasm 浏览器验收。

6. 启动真实前后端，完成装备创建、编辑、属性保存、刷新回读和删除。
