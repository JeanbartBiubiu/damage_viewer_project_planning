## 3. 类型与客户端

### 3.1 强类型

在 `skillEffect.ts` 增加：

1. `SkillEffectLifecycle` 及请求形状。
2. 四种实例范围、三种重复层数方式、三种重复持续方式和四种到期方式。
3. 两种首次周期方式。
4. `SkillEffectResultLifecycleBehavior`。
5. 六个固定生命周期时点、两种数值读取方式、两种层数值方式、三种重复值方式和两种周期执行方式。
6. `SkillEffectLifecycleOperationDetail` 与六种生命周期操作。
7. `SkillEffectResultType` 增加 `LIFECYCLE_OPERATION`。

扩展：

1. 效果摘要增加 `lifecycleEnabled: boolean`。
2. 效果详情、创建请求和更新请求增加 `lifecycle: SkillEffectLifecycle | null`。
3. 每个结果响应和请求增加 `lifecycleBehavior: SkillEffectResultLifecycleBehavior | null`。
4. 结果联合类型对 `LIFECYCLE_OPERATION` 使用专属 `detail`，不能用可选字段拼成宽接口。

### 3.2 客户端

`skillEffectClient` 保持阶段 7.2 五个路径和方法：

1. 列表解析 `lifecycleEnabled`。
2. 详情、创建和更新透传 `lifecycle` 及结果 `lifecycleBehavior`。
3. 不增加生命周期子资源方法，不改 Admin Token、成功响应或错误外壳。
4. 客户端测试覆盖新联合类型、null 生命周期和 URL 编码，不复制表单业务校验。

## 4. 草稿模型

`effectForm.ts` 增加：

1. `SkillEffectLifecycleDraft`，字段与共享契约一致，选择框空值使用空字符串或 null，不使用未定义混合状态。
2. `SkillEffectResultLifecycleBehaviorDraft`。
3. 生命周期操作结果草稿字段 `targetEffectKey` 和 `lifecycleOperation`。
4. 对应字段错误结构。

必须扩展：

1. 响应转草稿。
2. 空白效果和空白结果草稿。
3. 新建结果切换种类时的专属字段重置。
4. 克隆结果请求和效果提交请求。
5. 生命周期及结果行为的同步校验和请求构建。

已有结果的 `resultType` 仍不可修改。新结果在种类切换时只保留公共字段，清空旧种类明细、数值规则专属状态和不合法的生命周期行为字段。

## 5. 效果管理弹窗

`SkillEffectManagementModal`：

1. 列表继续按后端顺序展示，不新增分页和关键词。
2. 在结果数量旁显示“有生命周期”或“无生命周期”，信息来源只使用 `lifecycleEnabled`。
3. 生命周期操作目标目录复用当前技能效果摘要；只把 `lifecycleEnabled = true` 且不是当前编辑效果的记录作为正常选项。
4. 当前草稿引用的目标不在目录时保留“未知目标”只读项，不静默清空；最终提交由后端返回稳定错误。
5. 删除被生命周期操作引用的效果时展示后端 `409.SKILL_EFFECT_LIFECYCLE_IN_USE` 中文提示，不在前端猜测引用来源。

## 6. 效果编辑弹窗

### 6.1 生命周期入口

在效果资料和结果列表之间增加“生命周期”区域：

1. 开关关闭表示 `lifecycle = null`。
2. 开关打开后显示持续时间公式、最大层数公式、每次施加层数公式、实例范围、重复层数、重复持续、到期方式。
3. 存在周期结果时再显示周期间隔公式和首次周期；没有周期结果时不允许残留这两个字段。
4. 公式选择只列当前技能公式，显示名称并以稳定标识作为提交值。
5. 打开详情时生命周期已经存在，则“实例范围”只读禁用；新开启生命周期时可以选择。需要修改实例范围时，先关闭生命周期并成功保存，再重新打开建立。

从开启改为关闭时：

1. 如果生命周期或任一结果行为已有草稿，使用 Arco 默认确认弹窗说明会清空这些配置。
2. 用户取消则保持开关和草稿不变。
3. 用户确认后清空 `lifecycle` 和全部结果 `lifecycleBehavior`，不自动删除结果。

### 6.2 组合联动

1. 持续时间公式为空时，到期方式固定为“仅显式移除”，重复持续方式清空。
2. 选择独立计时时，到期方式同步为独立；选择独立到期时，重复持续方式同步为独立。
3. 其他冲突组合不自动猜测业务含义，只显示字段错误并阻止确认。
4. 开启生命周期后，如果旧结果没有行为，结果列表标记“待配置”，效果保存按钮不可用。
5. 生命周期被其他效果引用而无法关闭时，后端冲突保留当前完整草稿。
6. 清空持续时间后，如果已有结果选择“自然结束”，不自动改写结果时点；保留草稿、标记对应结果错误并阻止保存，直到用户明确修改结果。
7. 页面无法仅凭当前效果详情得知其他效果是否用 `REFRESH` 引用它；清空持续时间后的目标 PUT 如果返回 `409.SKILL_EFFECT_LIFECYCLE_IN_USE` / `REFRESH_OPERATION_IN_USE`，持续时间字段和完整草稿保持不变并显示占用提示。

### 6.3 结果列表

开启生命周期时，结果行除种类和作用对象外展示：

1. 生命周期时点。
2. 数值读取方式。
3. 持续数值的层数值方式。
4. 周期结果的执行次数方式。

结果排序仍通过现有 `sortOrder` 和稳定标识保存，不增加拖拽关系图。

## 7. 结果编辑弹窗

### 7.1 生命周期时点

父效果开启生命周期时显示固定时点：

1. 施加时。
2. 持续生效。
3. 达到满层。
4. 每次周期。
5. 自然结束。
6. 提前移除。

形状限制：

1. “持续生效”只对普通护盾、属性变化和状态施加开放。
2. 状态移除、其他基础结果和生命周期操作不显示“持续生效”。
3. 没有自然持续时间时不显示“自然结束”。
4. 选择“每次周期”后，父效果周期字段成为必填。

### 7.2 数值读取

1. 当前结果有数值规则时显示“施加时留存”与“到当前时点重新读取”。
2. 施加时和持续生效固定为“施加时留存”。
3. 满层、周期、自然结束和提前移除允许两种选择。
4. 状态操作和冷却重置不显示该字段，草稿必须为 null。
5. 页面只解释保存语义，不展示实际公式值或快照。

### 7.3 持续数值

普通护盾或属性变化选择“持续生效”后显示：

1. “整个实例共享数值”或“每层分别贡献数值”。
2. 共享数值时显示重复施加的“保留、覆盖、相加”。
3. 每层贡献时隐藏并清空重复值方式。
4. 属性覆盖 `SET` 只允许共享数值，并隐藏“相加”。

状态施加选择“持续生效”时不显示数值合并字段；状态层数使用父效果生命周期规则。

### 7.4 周期执行

选择“每次周期”后显示：

1. 每个生命周期实例执行一次。
2. 按当前有效层分别执行。

其他时点隐藏并清空该字段。

### 7.5 生命周期操作

结果种类增加中文项“生命周期操作”：

1. 选择目标效果，只列同一技能其他有生命周期的效果。
2. 选择增加、减少、覆盖、刷新、消耗或移除。
3. 增加、减少、覆盖和消耗显示现有数值规则编辑区，公式未来按层数解释。
4. 刷新和移除隐藏并清空数值规则。
5. 效果摘要没有自然到期明细，因此“刷新”始终作为固定操作显示；选择无自然到期目标时由后端返回 `400.INVALID_SKILL_EFFECT_REFERENCE`，字段 `results[index].detail.targetEffectKey`、原因 `TARGET_EFFECT_HAS_NO_DURATION`。前端不额外拉取目标详情，也不偷偷扩展摘要。
6. 生命周期操作可以存在于无生命周期的普通效果中；只有父效果也有生命周期时才额外配置自身固定时点。

## 8. 目录加载

打开效果编辑弹窗后并发加载：

1. 当前技能公式目录。
2. 当前技能效果摘要目录。
3. 当前结果种类需要的伤害类型、属性、技能或状态目录。

规则：

1. 公式和效果目录加载状态分别维护，失败不互相覆盖。
2. 依赖目录正在加载、加载失败或当前值未知时，不能提交受影响结果。
3. 允许重试，不关闭弹窗或清空草稿。
4. 切换结果种类只加载新种类需要的目录；不重复请求已经成功的目录。
5. 生命周期目标效果使用稳定 `effectKey`，不使用名称或列表下标。

## 9. 表单校验与错误映射

### 9.1 前端同步校验

提交前至少覆盖：

1. 生命周期开关与结果行为全有或全无。
2. 持续时间、到期和重复持续组合。
3. 独立计时与独立到期成对。
4. 周期结果与周期间隔、首次周期双向完整。
5. 固定时点与结果种类合法组合。
6. 数值规则与数值读取方式一致。
7. 持续数值层数值方式与重复值方式一致。
8. 属性覆盖不使用每层贡献或相加。
9. 生命周期操作目标、操作和数值规则形状。
10. 生命周期操作不引用当前效果。

前端校验只改善录入，不替代后端和数据库约束。

### 9.2 后端字段错误

映射：

1. `lifecycle.*` → 效果弹窗生命周期区域。
2. `results[index].lifecycleBehavior.*` → 对应结果行和结果编辑弹窗。
3. `results[index].detail.targetEffectKey`、`operation` → 生命周期操作明细。
4. `results[index].valueRule.*` → 现有数值规则区域。
5. `lifecycle.instanceScope` + `IMMUTABLE` → 已禁用的实例范围控件及生命周期区域提示。
6. `results[index].detail.targetEffectKey` + `TARGET_EFFECT_HAS_NO_DURATION` → 生命周期操作目标控件。
7. `lifecycle.durationFormulaKey` + `REFRESH_OPERATION_IN_USE` → 目标效果的持续时间控件及生命周期区域；不能清空草稿或改写引用方。

如果后端数组下标无法对应当前草稿，显示通用错误并保留所有草稿，不把错误映射到错误结果。
