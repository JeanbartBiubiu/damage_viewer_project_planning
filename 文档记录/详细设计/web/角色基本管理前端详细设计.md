## 1. 路由与页面

新增 `#/characters` 和导航“角色管理”。从导航和 App 静态路由中移除“实体创建”“实体 Provider 挂载”；旧源码保留，旧 hash 按现有未知路由回总览。

新增独立 `#/game-settings` 和导航“游戏配置”，等级范围在该页读取和保存，不放入角色管理页面。

角色页提供列表、关键词、新增、查看、编辑、删除和“等级属性”。页面不出现“实体”、Provider 或教学式说明。

基本资料和删除使用 Arco 默认 Modal，不新增弹窗 CSS。角色标识创建后不可修改；删除失败在确认弹窗内展示并保留弹窗。

## 2. 等级属性编辑

打开等级属性时读取等级配置、角色 Map 和全部属性定义。主体使用横向矩阵：行是属性，列是 `Lv1..LvN`，左侧显示名称、标识和“固定 / 每级增量 / 未配置”，右侧提供“编辑 / 设置”。禁止使用等级折叠结构。

顶部提供属性搜索、“只显示已配置”和“添加属性”。未配置属性各等级显示 `—`；只显示已配置关闭时仍可直接点“设置”。底部显示已配置和未配置数量。失败保留草稿，等级 Map 草稿接入现有页面离开保护。

“编辑 / 设置 / 添加属性”打开单属性弹窗，选择固定或每级递增，填写最低等级数值和可选增量，按共享契约公式生成整行；“取消配置”从全部等级移除该属性。最终转换为外层等级完整、内层属性稀疏的 `levelValues` 保存。
