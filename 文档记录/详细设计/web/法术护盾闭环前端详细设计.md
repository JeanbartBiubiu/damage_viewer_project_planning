## 1. 当前页面事实与前置依赖

1. 阶段 7.6.2 应已在现有效果弹窗形成十二种结果，并在条件与触发弹窗形成十八种事件。
2. `skillEffect.ts`、`effectForm.ts` 和结果编辑器应继续是结果联合、草稿、资格校验和字段定位的唯一实现；冷却变化 detail 已使用 `affectedSkillKeys: string[]`。
3. 阶段 7.5 的触发规则类型、表单、动作编辑和目录加载应继续是规则唯一实现；编码前按前段已验收真实接口核对实际文件与组件名。
4. 当前项目不适配移动端；只维护桌面弹窗和 Desktop Chrome 非 Wasm 流程。
5. 页面只结构化保存、校验和回读，不执行法术护盾匹配、阻挡、消耗、事件、公式、预览或 Wasm。

## 2. 前端职责与非目标

前端负责：

1. 增加法术护盾结果编辑和生命周期同步校验。
2. 在每个结果草稿中显式维护可空阻挡范围，并按统一资格矩阵显示或清空。
3. 增加“法术护盾成功阻挡”事件和合格护盾效果目录。
4. 维护阻挡事件后的有序动作，不增加隐藏消耗或事件专用动作。
5. 展示目标效果资格、入站占用和循环错误，保存失败保留完整草稿。

本阶段不得：

1. 显示实际护盾状态、阻挡结果、消耗次数、治疗值或运行按钮。
2. 开放 `BLOCKED` 前序输出或伤害事件值。
3. 增加斩杀、命中/攻击联动界面。
4. 新增主导航、路由、独立法术护盾页面、移动端布局或计算预览。

## 4. 类型与客户端契约

### 4.1 效果类型

`skillEffect.ts` 增加：

1. `SPELL_SHIELD` 结果及明确空 detail 类型，结果联合总数为十三种。
2. 结果公共字段 `spellShieldBlockScope: SpellShieldBlockScope | null`。
3. `SpellShieldBlockScope` 只含共享契约四种固定值。
4. 请求和响应的每个结果都必须出现该字段；开发协议检查拒绝缺失字段、未知值或后端只对部分结果返回字段。

请求/响应继续使用封闭判别联合，不能改为宽可选接口或 Map。

### 4.2 触发规则类型

1. 事件联合增加 `SPELL_SHIELD_BLOCKED` 和 `{ shieldEffectKey }` 强类型 detail，总数为十九种。
2. 该事件的能力声明 `EVENT_SOURCE` 可用且事件值为空。
3. 事件值联合和 `PRIOR_ACTION_RESULT.outputKind` 保持阶段 7.6.2 集合，不加入 `BLOCKED`。

### 4.3 客户端响应检查

开发环境最小协议检查增加：

1. 法术护盾结果空 detail、空数值规则和生命周期行为基本形状。
2. 所有结果的 `spellShieldBlockScope` 字段存在且为 null/合法值。
3. 阻挡事件 detail 完整，未知后段结果、事件或输出明确报协议错误。

客户端不得静默补 null、删除未知字段或把失资格效果当作空目录。

## 5. 效果草稿与映射

`effectForm.ts` 增加：

1. 所有结果草稿的 `spellShieldBlockScope`，`fromDetail` 无损保留 null/合法值；冷却变化分支同时复制并保留完整 `affectedSkillKeys`。
2. `toCreateRequest / toUpdateRequest` 对每个结果显式提交该字段。
3. 法术护盾结果草稿固定无数值规则、空 detail，并复用阶段 7.4 生命周期默认初始化入口。
4. 切换结果种类、target 或生命周期时点后统一调用一个资格函数；不合格时列出原因并清空范围。
5. 若清空会改变已有非空值，要求用户确认；取消则恢复变更前草稿，不能留下 target 已变但范围未清的非法半状态。
6. 直接治疗和普通护盾无条件清空，不因其他字段变化恢复旧范围。
7. 保存成功后用后端完整详情重建草稿，不本地拼接范围或护盾资格。

资格矩阵和中文标签由 `effectForm.ts` 的单一固定表拥有，组件只消费结果，不复制另一套判断。

## 6. 法术护盾结果编辑

1. 结果种类增加中文“法术护盾”。
2. 专属区只显示说明：“持续期间提供法术护盾能力；成功阻挡后的移除和后续动作在条件与触发中维护。”
3. 不显示数值规则、吸收数值、次数或结果级阻挡范围。
4. 要求父效果已开启生命周期且当前结果为持续生效；不满足时按阶段 7.6.2 同样的确认流程复用阶段 7.4 默认初始化。
5. `valueReadMode / stackValueMode / reapplicationValueMode` 隐藏并清空。
6. 生命周期持续时间、层数、到期方式仍在父效果生命周期区域维护，不在结果内复制。

## 7. 结果阻挡范围编辑

结果编辑顺序为：基本资料 → 种类专属字段 → 数值规则（需要时）→ 法术护盾阻挡范围（合格时）→ 生命周期行为。

合格结果显示中文下拉：

1. 不参与法术护盾阻挡。
2. 阻挡整个技能。
3. 阻挡所属效果。
4. 只阻挡当前伤害实例（仅伤害显示）。
5. 只阻挡当前结果。

不合格组合：

1. `target = SOURCE` 或持续生效结果显示只读说明并提交 null。
2. 直接治疗、普通护盾固定显示“本结果不参与法术护盾阻挡”，即使 target/时点看似合格也不显示下拉。
3. 阶段 7.6.2 四种持续结果和法术护盾自身提交 null。
4. 非伤害结果不显示“只阻挡当前伤害实例”。

页面不预览阻挡后的技能、效果或伤害实例，也不尝试解释运行时优先级。

## 8. 结果列表与摘要

1. 法术护盾结果摘要显示“持续法术护盾”。
2. 其他结果范围非空时，在现有单个摘要列追加“阻挡技能/效果/伤害实例/当前结果”。
3. null 显示“—”，直接治疗和普通护盾不显示误导性可阻挡状态。
4. 列表不展示实际是否阻挡、剩余次数或当前护盾状态。

## 9. 法术护盾阻挡事件编辑

1. 事件选择器增加中文“法术护盾成功阻挡”。
2. 显示必填“法术护盾效果”目录，只列出当前技能中有生命周期且含合格法术护盾持续结果的已保存效果。
3. 判断资格必须使用完整效果详情，不能只看列表摘要或效果名称。
4. 详情在当前规则弹窗会话按 `effectKey` 缓存；关闭弹窗释放，不写全局或本地持久化。
5. 目录未加载或失败时保留 `shieldEffectKey` 草稿、禁止保存并提供重试，不退化为自由文本。
6. 已停用或因并发修改失资格的旧引用显示明确只读状态；不允许重新选择，后端仍作最终校验。

## 10. 事件能力与有序动作

1. 当前目标说明为“法术护盾承受对象（技能拥有者自身）”。
2. `EVENT_SOURCE` 在条件、动作目标和每目标冷却中可选，中文说明为“被阻挡结果的来源对象”。
3. 事件值选择器显示“该事件没有可用事件值”；切换到该事件若已有事件值条件/绑定，列出并确认清理，取消则保持原事件。
4. 护盾消耗通过现有执行效果动作选择含生命周期移除操作的效果；治疗、增益继续使用普通执行效果动作；延迟行为继续启动过程。
5. 不增加“消耗护盾”“阻挡后治疗”快捷字段或事件专用动作。
6. 动作重排继续使用现有稳定标识和排序，不在前端执行动作。

## 11. 资格变化、占用与循环错误

1. 用户修改效果导致被规则引用的护盾效果失资格时，后端 409 定位实际生命周期/结果字段；页面保留效果草稿并列出受影响规则。
2. 删除整个效果的占用错误继续显示规则引用；仍有另一合格护盾结果时不应在前端自行阻止保存。
3. 新增或扩大阻挡范围形成无保护循环时，后端 400 循环错误显示在触发保护区和对应范围字段，保留草稿。
4. 页面不复制完整规则图；只做确定的资格矩阵和当前表单内明显非法组合。
5. 本阶段不因阻挡范围变化清理前序输出，因为 `BLOCKED` 尚未开放。

## 12. 前端同步校验与错误定位

提交前至少校验：

1. 法术护盾结果空 detail、无数值规则和完整生命周期组合。
2. 每个结果范围字段存在，非空值符合结果类型、target 和时点资格。
3. 直接治疗、普通护盾及所有持续特殊结果范围为 null。
4. 阻挡事件目标效果目录已成功加载且当前草稿仍合格。
5. 阻挡事件没有事件值条件或绑定。

后端字段路径映射增加：

1. `results[i].spellShieldBlockScope` → 当前结果阻挡范围区。
2. `results[i].lifecycleBehavior.*` → 法术护盾生命周期区。
3. `eventSource.detail.shieldEffectKey` → 法术护盾效果选择器。
4. 无法定位的入站引用/循环详情 → 当前弹窗顶部与触发保护区。

未知字段问题显示服务端中文消息和详情，不把英文原因码作为主要用户文案。

## 13. 弹窗与并发行为

1. 沿用当前桌面宽弹窗和结果子弹窗，不新建页面或移动端布局。
2. 保存期间禁用重复提交、删除子项和关闭。
3. 保存成功后重新请求详情和列表，不做乐观拼接。
4. 打开规则弹窗期间效果被其他会话修改时，保存前重新以最新详情校验资格；后端 409/400 后保留草稿并允许重载目录。
5. 404 表示效果或规则已删除时刷新列表并保留草稿供查看，不覆盖不存在记录。

## 17. 前端停止条件

出现以下任一情况停止编码并回到共享契约：

1. 阶段 7.6.2 最终类型、生命周期、规则表单、效果详情或候选图错误结构与本文前提不一致。
2. 需要增加后续结果、事件、事件值或丰富输出才能完成本阶段表单。
3. 法术护盾消耗、治疗或延迟必须用隐藏快捷行为才能表达。
4. 直接治疗或普通护盾无法在页面上固定为不可阻挡。
5. 需要建立第二套效果/规则编辑器、主导航或独立路由。
6. 页面必须手写 JSON、自由表达式或数据库复合键才能保存。
