## 4. 最终事件值能力

阶段 7.6.2 的 `DAMAGE_PENDING` 四项保持不变。本阶段追加七个固定标识，并扩展事件能力：

| `eventType` | 最终允许事件值 |
| --- | --- |
| `DAMAGE_PENDING` | `RAW_DAMAGE / POST_DEFENSE_DAMAGE / HEALTH_BEFORE / PROJECTED_HEALTH_AFTER`。 |
| `DAMAGE_DEALT` | `RAW_DAMAGE / POST_DEFENSE_DAMAGE / SHIELD_ABSORBED / ACTUAL_HP_LOSS / BLOCKED / IMMUNE / KILLED`。 |
| `DAMAGE_TAKEN` | 与 `DAMAGE_DEALT` 相同。 |
| `HIT_LINK_APPLIED` | `LINK_INDEX / LINK_COUNT`。 |
| `ATTACK_LINK_APPLIED` | `LINK_INDEX / LINK_COUNT`。 |
| `SPELL_SHIELD_BLOCKED` | 无。 |

本阶段新增标识与类型：

| `eventValueKey` | 值类型 | 说明 |
| --- | --- | --- |
| `SHIELD_ABSORBED` | `DECIMAL` | 本次伤害被普通护盾吸收的数值。 |
| `ACTUAL_HP_LOSS` | `DECIMAL` | 本次伤害实际扣除生命的数值。 |
| `BLOCKED` | `INTEGER` | 是否被法术护盾阻挡，固定 0/1。 |
| `IMMUNE` | `INTEGER` | 是否被伤害免疫，固定 0/1。 |
| `KILLED` | `INTEGER` | 是否形成击杀，固定 0/1。 |
| `LINK_INDEX` | `INTEGER` | 本次联动序号，从 1 开始。 |
| `LINK_COUNT` | `INTEGER` | 本轮联动总次数，从 1 开始。 |

规则：

1. `RAW_DAMAGE / POST_DEFENSE_DAMAGE` 已在阶段 7.6.2 加入固定集合，本阶段只把它们开放给两种结算后伤害事件。
2. 所有事件值同时适用于 `EVENT_VALUE_COMPARE` 条件和 `EVENT_VALUE` 动态输入来源。
3. 值只能在能力表指定事件中使用；固定集合存在不等于任意事件可选。
4. `SPELL_SHIELD_BLOCKED` 仍没有事件值；是否阻挡通过事件身份本身表达。
5. 本阶段只保存值身份和类型，不生成、求值、钳制或舍入。

## 6. 十种固定输出

| `outputKind` | 值类型 | 合法来源结果 |
| --- | --- | --- |
| `CONFIGURED_VALUE` | `DECIMAL` | 任意具有 `valueRule` 的即时结果。 |
| `RAW_DAMAGE` | `DECIMAL` | `DAMAGE`。 |
| `POST_DEFENSE_DAMAGE` | `DECIMAL` | `DAMAGE`。 |
| `SHIELD_ABSORBED` | `DECIMAL` | `DAMAGE`。 |
| `ACTUAL_HP_LOSS` | `DECIMAL` | `DAMAGE`。 |
| `ACTUAL_HEALING` | `DECIMAL` | `DIRECT_HEAL`；或至少拥有一条吸血规则的 `DAMAGE`。 |
| `BLOCKED` | `INTEGER` 0/1 | `spellShieldBlockScope` 非空的合格离散结果。 |
| `IMMUNE` | `INTEGER` 0/1 | `DAMAGE`。 |
| `STATUS_APPLIED` | `INTEGER` 0/1 | `STATUS_OPERATION` 且操作为施加。 |
| `KILLED` | `INTEGER` 0/1 | `DAMAGE / EXECUTE`。 |

补充规则：

1. `DAMAGE + ACTUAL_HEALING` 表示该伤害结果全部吸血规则最终形成的实际治疗合计，不表示某一条吸血规则；需要区分时拆分伤害结果。
2. `BLOCKED` 要求来源结果在候选效果中仍有非空合法阻挡范围；直接治疗和普通护盾永远不能成为该输出来源。
3. `STATUS_APPLIED` 不适用于移除状态。
4. 数值输出未来未实际产生时固定提供 0；布尔输出固定提供 0/1。本阶段不保存这些值。
5. 不增加自由输出名、吸血规则键、伤害实例键或运行值列。
6. 多目标 `COOLDOWN_CHANGE` 只按结果稳定标识参与来源矩阵；仅当整条结果具有共享数值规则时提供一个 `CONFIGURED_VALUE`，不按 `affectedSkillKeys` 拆分或重复；`RESET` 不提供该输出。
7. `CONFIGURED_VALUE` 只表示来源结果自身保存的 `valueRule`，不表示同乘区加算值、乘区因子、属性修正后值或最终伤害/治疗修正值；本阶段不新增乘区输出种类。

## 7. 来源动作、结果与即时性

前序结果绑定同时满足：

1. 来源动作必须是同一规则中排序更早的 `EXECUTE_EFFECT`。
2. 排序以规则已冻结的 `sortOrder + actionKey` 稳定顺序判断；同一动作和后续动作都不允许。
3. `sourceResultKey` 必须属于来源动作目标效果；来源效果由后端推导，不信任客户端另传。
4. 来源效果没有生命周期，或来源结果在该生命周期中的时点为 `APPLICATION`，才允许作为同一轮动作序列来源。
5. `PERSISTENT / FULL_STACKS / PERIODIC / NATURAL_END / EARLY_REMOVE` 结果都不允许。
6. 不允许跨规则、跨技能、跨动作链、隐式同效果结果依赖或后向引用。
7. 因此使用 `MOMENT_EVALUATION` 的持续属性、伤害或治疗修正不能成为同轮前序动作结果来源；乘区选择和动态读取不改变即时性判定。
8. 来源动作或结果被重排、删除或改形状时，规则 PUT 必须重新验证完整绑定集合。

## 8. 值类型与运行输入绑定

1. `DECIMAL` 输出只能绑定小数参数。
2. `INTEGER` 输出可绑定整数或小数参数；绑定到小数时按未来精确数值转换语义处理，本阶段不执行转换。
3. 每个动作可达公式的每个 `RUNTIME_INPUT` 参数仍必须恰好一个绑定；缺失、多余、重复和类型不兼容都返回 `400.INVALID_RUNTIME_INPUT_BINDING`。
4. 事件筛选、条件右值、每目标冷却和过程次数保护公式仍不得引用运行输入。
5. 需要根据一个执行结果决定是否执行另一组动作时，使用固定事件建立另一条规则；不在动作数组中增加执行到一半的条件。

## 9. 效果形状变化的入站保护

效果 PUT 必须以候选快照复查所有直接或过程间接引用规则及丰富前序结果绑定：

1. 删除被引用结果继续返回 `409.SKILL_EFFECT_IN_USE / TRIGGER_RULE_RESULT_IN_USE`。
2. 把即时结果改为不可即时、把状态施加改为移除、删除最后一条吸血规则、清空阻挡范围或其他变化令既有 `outputKind` 不再可用时，返回 `409.SKILL_EFFECT_IN_USE / TRIGGER_RULE_SHAPE_IN_USE`。
3. 改变可达公式参数集合继续返回 `409.SKILL_EFFECT_IN_USE / TRIGGER_RULE_RUNTIME_INPUT_IN_USE`。
4. 字段定位本次实际变化字段；受影响详情按 `ruleKey/actionKey/bindingKey/outputKind` 稳定排序。
5. 处理顺序固定为先修改或删除依赖规则，再更新效果，最后按新形状恢复规则；不增加跨聚合批量接口。
6. 候选效果另行形成无保护循环时，返回循环错误并保持原聚合。

## 10. 最终可达公式与候选生产图

可达公式最终回归表必须包含：

1. 所有数值结果的 `valueRule.formulaKey`。
2. 伤害暴击倍率和全部吸血效率公式。
3. 阶段 7.6.2 的伤害修正、治疗修正、生命下限公式。
4. 阶段 7.6.4 的斩杀、命中联动和攻击联动公式。
5. 直接执行效果和通过阶段 7.3 过程挂接到达效果的两条入口。

候选生产图最终回归表必须包含：

1. 阶段 7.5 全部既有生产边和保护边。
2. 伤害到伤前/造成/受到伤害事件的本地与跨技能边界。
3. 非空阻挡范围到法术护盾阻挡事件。
4. 命中/攻击联动结果到对应事件。
5. 斩杀到击杀/死亡事件。
6. 普通护盾耗尽到生命周期提前移除的总契约边。

本阶段只验证管理配置和候选图，不执行任何边或宣称跨技能挂载未知时的全局无环。

## 12. 稳定错误

| HTTP | `code` | 本阶段场景 |
| ---: | --- | --- |
| 400 | `400.INVALID_BODY` | 新事件值或输出种类无法绑定。 |
| 400 | `400.INVALID_SKILL_TRIGGER_RULE_REFERENCE` | 来源动作、效果或结果不存在或不属于当前规则/技能。 |
| 400 | `400.INVALID_RUNTIME_INPUT_BINDING` | 输出与来源结果不匹配、来源不即时、顺序非法、值类型不兼容或绑定不完整。 |
| 400 | `400.TRIGGER_RULE_CYCLE_UNGUARDED` | 最终生产边形成无保护环。 |
| 409 | `409.SKILL_EFFECT_IN_USE` | 效果修改会令既有丰富输出、结果形状或可达参数绑定失效。 |

字段路径使用实际下标，例如 `conditions[i].detail.eventValueKey`、`actions[i].runtimeInputBindings[j].detail.outputKind`、`actions[i].runtimeInputBindings[j].detail.sourceResultKey` 和效果请求中的实际变化字段。

无效原因固定复用或增加 `INVALID_EVENT_VALUE_FOR_EVENT / OUTPUT_KIND_NOT_AVAILABLE / SOURCE_ACTION_NOT_EARLIER / SOURCE_RESULT_NOT_IMMEDIATE / RUNTIME_INPUT_TYPE_MISMATCH / TRIGGER_RULE_SHAPE_IN_USE`。未知数据库约束不得伪装为业务 400。

## 13. 页面外部行为

3. 十种输出使用中文标签，布尔输出标注“以 0/1 供值”。
4. 来源动作重排、结果改形状或输出失效时，列出受影响绑定并确认清理。
5. 效果保存遭入站 409 时保留草稿、定位变化字段并列出依赖规则。
6. 页面不让用户填写 JSON、自由输出名、复合键、运行值或公式文本。

7. 所有证据通过后更新阶段 7.6.5 三个任务；只有阶段 7.6.1～7.6.5 均完成时，才可更新阶段 7.6 三个总设计任务。

## 15. 综合验收案例

### 15.1 艾希 Q

五次伤害实例、五次吸血机会、一次命中联动和一次攻击联动保持独立；两种联动事件可读取序号/总次数，关闭、刷新和重启后结构完整。

### 15.2 伊泽瑞尔 Q

伤害、暴击、三类吸血和结果级阻挡范围完整；后续动作可读取实际扣血、实际治疗或已阻挡。选择 Q、W、E、R 的冷却减少仍是一个结果和一个基础配置值候选，并保持法术护盾阻挡范围为 null。

### 15.3 希维尔 E

法术护盾阻挡事件、护盾移除、延迟过程、治疗和增益动作顺序完整；事件本身没有事件值，也不能把触发该事件的外部被阻挡结果伪装成当前规则的前序动作结果。

### 15.4 荆棘之甲

受到直接普通攻击筛选、反伤目标和保护完整；伤害事件可读取实际扣血/免疫等最终值，无保护反伤仍被拒绝。

### 15.5 鬼索的狂暴之刃

满层规则启动延迟过程并执行命中联动应用；联动事件可读取本次序号和总次数，不把当前伤害简单乘二。

### 15.6 斯特拉克的挑战护手

`DAMAGE_PENDING + PROJECTED_HEALTH_AFTER` 条件、普通护盾、线性衰减和冷却保护完整；伤前事件仍不能读取实际扣血或击杀。

### 15.7 收集者

伤害后条件执行斩杀，后续更晚动作可把 `KILLED` 以 0/1 绑定到小数或整数运行输入；不执行金币奖励或实际死亡结算。

## 16. 综合反例

以下请求必须失败且原聚合不变：

1. 前序结果引用同动作、后续动作、跨规则、跨技能或不属于来源效果的结果。
2. 引用持续、满层、周期、自然结束或提前移除结果。
3. 没有吸血规则的伤害选择 `ACTUAL_HEALING`。
4. 阻挡范围为空、直接治疗或普通护盾选择 `BLOCKED`。
5. 状态移除选择 `STATUS_APPLIED`。
6. 非伤害/斩杀结果选择 `KILLED`。
7. 小数输出绑定整数参数。
8. `DAMAGE_PENDING` 读取护盾吸收、实际扣血或击杀。
9. 法术护盾阻挡事件选择任何事件值。
10. 联动事件在本阶段最终集合之外选择自由序号字段。
11. 效果 PUT 清空最后一条吸血、清空阻挡范围或破坏即时性，却仍有相应既有绑定。
12. 实现用一个通用结果表、自由字符串或运行缓存替代固定矩阵。

## 18. 停止条件

出现以下任一情况停止并回到方案确认：

1. 阶段 7.6.4 最终结果、事件、绑定表、效果形状或候选图与本文前提不一致。
2. 丰富输出必须保存运行值、结果缓存、自由输出或跨规则引用才能实现。
3. 需要改变阶段 7.6 总契约的输出矩阵、事件能力或直接治疗/普通护盾不可阻挡决定。
4. 需要 JSONB、数组、脚本、自由字符串或通用多态关系。
5. 需要执行公式、伤害、护盾、吸血、阻挡、斩杀、联动、事件、预览或 Wasm 才能完成管理校验。
6. 七个案例的真实数据库、接口、重启回读或浏览器验收不可用且无法定点确认原因。
