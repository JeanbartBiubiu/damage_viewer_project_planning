## 1. 目标与成功标准

阶段 7.6.4 只完成以下结构骨架：

1. 增加斩杀、命中联动应用和攻击联动应用三种固定离散结果。
2. 增加“应用命中联动”和“触发攻击联动”两种固定事件。
3. 把三种新结果公式纳入动作可达公式检查。
4. 把斩杀可能产生击杀/死亡事件、两种联动结果产生对应联动事件的关系纳入阶段 7.5 同一候选规则图。

本阶段完成后的过渡状态固定为：

1. 结果种类从十三种增加到最终十六种。
2. 事件种类从十九种增加到最终二十一种。
3. 阶段 7.6.3 的 `spellShieldBlockScope` 继续存在，三种新离散目标结果可按资格使用，但禁止 `DAMAGE_INSTANCE`。
4. `PRIOR_ACTION_RESULT.outputKind` 仍只允许 `CONFIGURED_VALUE`；斩杀的 `KILLED` 输出尚不开放。
5. 两种联动事件暂时没有事件值；`LINK_INDEX / LINK_COUNT` 留到阶段 7.6.5。
6. 本阶段只保存结构、引用、候选边和完整回读，不执行斩杀、联动或攻击。

## 3. 范围与非目标

本阶段包含：

1. `EXECUTE / HIT_LINK_APPLICATION / ATTACK_LINK_APPLICATION` 三种结果。
2. `HIT_LINK_APPLIED / ATTACK_LINK_APPLIED` 两种事件和可空来源技能筛选。
3. 三种结果的离散生命周期、数值规则和法术护盾范围组合。
4. 三种结果公式的可达参数和效果更新占用检查。
5. 击杀、死亡和两种联动事件的候选生产边。
6. 来源技能真实引用与技能删除保护。
7. 对应后端、前端自动检查和获批后的真实验收。

本阶段明确不包含：

1. 斩杀判定、生命扣除、死亡处理、金币奖励或击杀奖励。
2. 命中联动/攻击联动的目标集合、实际应用、次数循环或普通攻击执行。
3. `KILLED` 前序输出、`LINK_INDEX / LINK_COUNT` 事件值或其他丰富输出。
4. 多目标、弹射、传播、投射物、位移、攻击计时、最终结算、计算预览或 Wasm。
5. 自由联动类型、自由事件、脚本、JSONB、数组外键或通用多态关系。

## 4. 斩杀结果

`resultType = EXECUTE` 必须有数值规则，detail 精确为：

```json
{ "attributeKey": "hp" }
```

规则：

1. `attributeKey` 必须引用同一游戏启用数值属性；不按标识或中文名猜测生命属性。
2. 数值规则未来给出绝对斩杀阈值；本阶段不执行公式或静态判断阈值范围。
3. 未来语义固定为目标当前属性值小于等于阈值时形成击杀结果；它不是一条超大真实伤害。
4. 禁止 `moment = PERSISTENT`；其他离散时点继续遵守阶段 7.4 的数值读取和周期字段规则。
5. `stackValueMode / reapplicationValueMode` 必须为 null。
6. `target = TARGET` 且时点不是持续生效时，可使用阶段 7.6.3 的 `SKILL / EFFECT / RESULT` 阻挡范围；`DAMAGE_INSTANCE` 禁止。

## 5. 命中联动与攻击联动结果

两种结果都必须有数值规则、detail 固定为空对象：

```json
{
  "resultType": "HIT_LINK_APPLICATION",
  "valueRule": {
    "formulaKey": "hit_link_count",
    "fixedMultiplier": 1,
    "fixedMinValue": null,
    "fixedMaxValue": null
  },
  "detail": {}
}
```

`ATTACK_LINK_APPLICATION` 同形。

规则：

1. 数值未来按非负整数解释，表示本次应用命中联动或触发攻击联动的次数；本阶段不执行公式、不取整也不增加自由次数字段。
2. 两种结果都是离散结果，禁止 `PERSISTENT`；`stackValueMode / reapplicationValueMode` 必须为 null。
3. 其他离散时点沿用阶段 7.4 的数值读取和周期执行字段。
4. 需要延迟再次应用命中联动时，把结果挂到阶段 7.3 延迟过程步骤，不在结果中保存延迟毫秒。
5. 结果本身不引用来源技能、目标技能、攻击模板或另一个结果。
6. `target = TARGET` 且时点不是持续生效时，可使用 `SKILL / EFFECT / RESULT` 阻挡范围；`DAMAGE_INSTANCE` 禁止。

## 6. 次数责任边界

1. 伤害实例次数继续由阶段 7.3 多段、周期、引导等步骤和效果挂接形成。
2. 每个伤害实例的吸血机会继续由阶段 7.6.1 伤害吸血规则形成。
3. 命中联动次数只由 `HIT_LINK_APPLICATION.valueRule` 给出。
4. 攻击联动次数只由 `ATTACK_LINK_APPLICATION.valueRule` 给出。
5. “五次伤害、五次生命偷取、一次命中联动、一次攻击联动”必须保存为五次伤害实例和两个独立联动结果，不能把伤害乘五后配布尔开关。
6. 本阶段不保存一次运行中已执行到第几次；序号和值留到阶段 7.6.5 事件能力。

## 7. 两种联动事件

事件形状分别为：

```json
{
  "eventType": "HIT_LINK_APPLIED",
  "detail": { "sourceSkillKey": null }
}
```

```json
{
  "eventType": "ATTACK_LINK_APPLIED",
  "detail": { "sourceSkillKey": "ezreal_q" }
}
```

规则：

1. `sourceSkillKey` 可空；null 表示任意技能产生，非空引用同一游戏技能，允许引用当前技能自身。
2. 当前目标固定为本次联动目标。
3. `EVENT_SOURCE` 不可用；两种事件不凭空定义另一对象身份。
4. 本阶段两种事件没有事件值，条件和动态输入不得选择 `LINK_INDEX / LINK_COUNT` 或其他值。
5. 事件只保存来源筛选，不保存本次次数、来源结果、攻击标识或运行值。

## 8. 动作可达公式与效果更新

阶段 7.5～7.6.3 的封闭收集表增加三种结果的 `valueRule.formulaKey`：

1. `EXECUTE_EFFECT` 和 `START_PROCESS` 通过直接效果挂接到达时都收集。
2. 公式中的 `RUNTIME_INPUT` 参数继续要求恰好一个绑定。
3. 规则 POST/PUT 的缺失、多余、重复或类型不兼容绑定返回 `400.INVALID_RUNTIME_INPUT_BINDING`。
4. 效果 PUT 改变三种公式并导致直接/过程间接引用规则的可达参数集合变化时，返回 `409.SKILL_EFFECT_IN_USE / TRIGGER_RULE_RUNTIME_INPUT_IN_USE`。
5. 字段定位实际 `results[i].valueRule.formulaKey`，受影响详情按 `ruleKey/actionKey/parameterKey` 稳定排序。
6. `PRIOR_ACTION_RESULT.outputKind` 本阶段仍只有 `CONFIGURED_VALUE`。

## 9. 候选生产表

在前段封闭表上增加：

| 来源 | 可能产生的固定事件 |
| --- | --- |
| `EXECUTE` | `KILL` 和目标 `ENTITY_DIED`。 |
| `HIT_LINK_APPLICATION` | `HIT_LINK_APPLIED`。 |
| `ATTACK_LINK_APPLICATION` | `ATTACK_LINK_APPLIED`。 |

规则：

1. 新建/修改三种结果、事件筛选或引用动作时使用同一候选快照重新检查当前技能规则图。
2. 联动事件按非空 `sourceSkillKey` 过滤可能匹配边；null 表示不缩小来源技能。
3. 斩杀只增加击杀/死亡候选边，不实际标记死亡，也不产生伤害事件。
4. 三种结果带非空法术护盾范围时，继续叠加阶段 7.6.3 的阻挡事件候选边。
5. 跨技能挂载未知时不建立无法证明的本地边，也不宣称全局无环。
6. 保护边和残余有向环算法继续复用阶段 7.5，不建立联动专用循环系统。

## 10. 修改与引用保护

1. 删除被其他技能的两种联动事件 `sourceSkillKey` 引用的技能返回既有 `409.SKILL_IN_USE`；删除技能自身时先删除自身规则，自引用不会阻止整技能删除。
2. 删除/修改被规则动作引用的效果、结果或过程继续使用阶段 7.5 稳定 409。
3. 三种公式变化导致规则可达参数集合变化时使用 `TRIGGER_RULE_RUNTIME_INPUT_IN_USE`；不允许预先多绑参数。
4. 新增/修改结果或事件形成无保护环时返回循环错误，原效果或规则聚合保持不变。
5. 阶段 7.6.5 之前，移除斩杀或联动结果不会涉及丰富前序输出引用；对应输出依赖只在下一阶段建立。

## 11. HTTP 与聚合边界

1. 效果五个接口把结果联合扩展到最终十六种；一次 POST/PUT 维护完整结果、数值规则、斩杀明细和既有阻挡范围。
2. 触发规则五个接口把事件联合扩展到最终二十一种；一次 POST/PUT 维护事件、条件、动作、绑定和保护。
3. 不增加斩杀、联动、次数或事件子接口。
4. 已有结果类型继续不可原地修改；三种新结果必须使用新标识创建。
5. 列表摘要只显示阈值属性、联动种类、次数公式存在性和可空来源技能，不显示运行次数或击杀状态。

## 12. 稳定错误

| HTTP | `code` | 本阶段场景 |
| ---: | --- | --- |
| 400 | `400.INVALID_BODY` | 新结果、事件或来源技能联合无法绑定，或携带其他种类字段。 |
| 400 | `400.VALIDATION_FAILED` | 新结果数值规则、离散时点、生命周期或阻挡范围组合错误。 |
| 400 | `400.INVALID_SKILL_EFFECT_REFERENCE` | 斩杀属性或三种结果公式引用无效。 |
| 400 | `400.INVALID_SKILL_TRIGGER_RULE_REFERENCE` | 联动事件来源技能不存在或跨游戏。 |
| 400 | `400.INVALID_RUNTIME_INPUT_BINDING` | 三种新公式参数绑定不完整。 |
| 400 | `400.TRIGGER_RULE_CYCLE_UNGUARDED` | 新生产边形成无保护环。 |
| 409 | `409.SKILL_EFFECT_IN_USE` | 效果公式或结果形状变化破坏既有规则。 |
| 409 | `409.SKILL_IN_USE` | 删除仍被联动事件来源筛选引用的技能。 |

字段路径使用实际下标，例如 `results[0].detail.attributeKey`、`results[1].valueRule.formulaKey`、`results[2].spellShieldBlockScope` 和 `eventSource.detail.sourceSkillKey`。

无效原因复用 `UNKNOWN_ATTRIBUTE / SPECIAL_RESULT_FORBIDS_PERSISTENT / INVALID_SPELL_SHIELD_SCOPE / TRIGGER_RULE_RUNTIME_INPUT_IN_USE`；未知数据库约束不得伪装为业务 400。

## 15. 跨端验收

### 15.1 艾希 Q 类多段与联动

1. 阶段 7.3 过程保存五次伤害实例。
2. 同一效果或相应时点另存一次命中联动应用和一次攻击联动应用。
3. 保存、关闭、刷新和后端重启后，仍能区分五次伤害/吸血与两个独立联动结果，不执行实际联动。

### 15.2 鬼索类延迟联动

1. 既有内部状态和满层规则启动包含 0.15 秒延迟步骤的过程。
2. 延迟步骤挂接一次命中联动应用结果，不把当前伤害简单乘二。
3. 新建命中联动事件，可空来源技能完整回读；事件没有序号或总次数值。

### 15.3 收集者类斩杀骨架

1. `DAMAGE_DEALT` 规则的既有条件读取目标生命阈值，有序动作执行 `EXECUTE`。
2. 斩杀结果保存明确属性和阈值公式，禁止持续生效。
3. 页面和接口不提供 `KILLED` 前序输出，不执行死亡或金币奖励。

### 15.4 迁移、引用与反例

1. 新库和兼容迁移形成两张本阶段表、最终十六种结果、二十一种事件和结果类型列宽。
2. 删除被来源技能筛选引用的技能返回稳定冲突。
3. 给三种新结果配置持续生效或 `DAMAGE_INSTANCE`、给联动事件提交事件值，均失败且原聚合不变。
4. 重复迁移安全；部分结构、未知列宽或函数漂移整体停止。
