## 4. 数据库结构

本阶段只增加两张表，新库父表从 83 张增加到 85 张。`modifier_zones` 是已验收前置表，不属于本阶段新增表。

### 4.1 斩杀明细

`skill_effect_execute_details`：

1. 主键为 `game_id + skill_key + effect_key + result_key`。
2. 完整外键到 `skill_effect_results` 并随结果级联删除。
3. `attribute_key varchar(64) NOT NULL`，以 `game_id + attribute_key` 完整外键到同游戏属性并使用 `RESTRICT`。
4. 以被引用属性复合键开头建立反向索引。
5. 只允许父结果为 `EXECUTE`，且父结果必须有数值规则。

### 4.2 联动事件明细

`skill_trigger_rule_link_events`：

1. 主键为 `game_id + skill_key + rule_key`。
2. 完整外键到触发规则并随规则级联删除。
3. `source_skill_key varchar(64)` 可空。
4. 非空时以 `game_id + source_skill_key` 完整外键到同游戏技能并使用 `RESTRICT`。
5. 只允许父事件为 `HIT_LINK_APPLIED / ATTACK_LINK_APPLIED`。
6. 以被引用技能复合键开头建立反向索引。

`HIT_LINK_APPLICATION / ATTACK_LINK_APPLICATION` 的 detail 固定为空对象，不创建没有业务列的空结果表。

4. 必须复用同一分析器，不在效果服务复制结果遍历。

### 7.3 候选生产图

1. `EventFilter` 与 `ProducedEvent` 增加可空 `sourceSkillKey`；`loadGraph` / `eventFilter` 从 `skill_trigger_rule_link_events` 读取两种联动事件筛选。
2. 两种联动结果分别产生对应联动事件，生产事件的 `sourceSkillKey` 为当前技能；匹配条件为事件类型相同且筛选为 null 或等于当前技能。筛选非空且指向其他技能时不建无法证明的本地边，禁止按无条件宽匹配处理。
3. `EXECUTE` 增加宽匹配 `KILL` 候选边；`ENTITY_DIED` 使用 `subjectOf(result.target)`，不得改成无 subject 的宽匹配。
4. 三种结果带阻挡范围时继续由现有 `spellShieldBlockScope != null` 通用分支叠加 `SPELL_SHIELD_BLOCKED`，不增加重复分支。
5. `matches` 显式处理两种联动事件；默认不匹配行为保持不变。循环错误的 `producedEvent` 在来源技能参与过滤时返回 `sourceSkillKey`。
6. 保护边和残余有向环检查继续复用阶段 7.5；跨技能挂载未知时不建无法证明的本地边。

## 8. 引用与删除保护

1. `SkillService` 删除技能时继续调用 `SkillTriggerRuleService.assertSourceSkillNotReferenced`。扩展既有 `countSourceSkillReferences`，以同一查询合并 `skill_trigger_rule_skill_events` 与 `skill_trigger_rule_link_events`，两部分都排除待删技能自身聚合；任一外部引用返回既有 `409.SKILL_IN_USE`，自引用不阻止整技能删除。冷却目标关系入站检查保持原样。
2. 公式删除若已统一检查 `skill_effect_result_values`，三种结果自动受保护；若现有实现按结果类型枚举，只补三种值并保持 `409.SKILL_FORMULA_IN_USE`。
3. 当前属性没有独立删除能力时不新增接口；新增/改选斩杀属性仍检查存在、启用和同游戏。
4. 三种公式变化改变既有规则可达参数集合时返回 `409.SKILL_EFFECT_IN_USE / TRIGGER_RULE_RUNTIME_INPUT_IN_USE`。
5. 结果/事件变化形成无保护环时返回 400 循环错误并保持原聚合。
6. 数据库外键和延迟检查只作并发防线，未知约束保留服务端错误。

## 12. 后端停止条件

出现以下任一情况停止编码并回到共享契约：

1. 阶段 7.6.3 最终结果、事件、阻挡范围、乘区引用与动态读取、来源技能引用或候选图与本文前提不一致。
2. 需要增加阶段 7.6.5 输出、事件值或通用结果表才能完成本阶段。
3. 联动结果必须保存目标技能、运行次数、攻击模板或自由关系。
4. 效果或规则无法在一次聚合事务中维护，必须暴露半成品子接口。
5. 必须保存 JSONB、数组、自由字符串或通用多态关系。
6. 需要执行公式、斩杀、联动、攻击、事件、结算或 Wasm 才能完成结构校验。
7. 真实数据库、接口或重启回读验收不可用且无法定点确认原因。

本设计已冻结并经项目负责人授权；后端、数据库和服务操作只能落在本文写入范围内，出现停止条件时立即停止。
