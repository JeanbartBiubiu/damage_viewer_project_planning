## 8. 丰富前序结果解析

### 8.1 来源动作和效果推导

1. 按 `sortOrder + actionKey` 建立当前规则稳定动作顺序。
2. `sourceActionKey` 必须命中排序更早的 `EXECUTE_EFFECT`；同动作、后续动作或其他动作类型拒绝。
3. 从该动作强类型明细推导 `sourceEffectKey`，客户端同名字段即使出现也按非法 body 拒绝。
4. 锁定并读取来源效果完整聚合，`sourceResultKey` 必须属于该效果。
5. Mapper 写入继续保存推导的 `source_effect_key`，维持动作和结果两条真实复合外键。

### 8.2 即时性

1. 无生命周期效果的结果允许。
2. 有生命周期效果只允许 `moment = APPLICATION` 的结果。
3. `PERSISTENT / FULL_STACKS / PERIODIC / NATURAL_END / EARLY_REMOVE` 拒绝。
4. 周期执行模式、自然到期或生命周期操作不能绕过即时性。

### 8.3 输出可用性

建立一个由结果完整详情计算的固定解析器：

1. 数值规则决定 `CONFIGURED_VALUE`；一个具有 `valueRule` 的多目标冷却变化结果只产生一个该输出，不按 `affectedSkillKeys` 或目标关系行展开，`RESET` 不产生该输出。
2. 伤害结果决定四种伤害数值、`IMMUNE / KILLED`，并按吸血规则决定 `ACTUAL_HEALING`。
3. 直接治疗决定 `ACTUAL_HEALING`。
4. 非空合法阻挡范围决定 `BLOCKED`。
5. 状态操作为 `APPLY` 决定 `STATUS_APPLIED`。
6. 斩杀决定 `KILLED`。

该解析器必须同时供规则 POST/PUT 和效果 PUT 入站复查使用；前端只消费既有完整效果详情并按共享契约实现同一固定表，不新增输出能力接口。后端效果服务不得复制第二套矩阵。

### 8.4 值类型与绑定完整性

1. 小数输出只能绑定小数参数；整数输出可绑定整数或小数参数。
2. 结果输出绑定与其他来源绑定一起参与“每个可达参数恰好一个来源”检查。
3. 缺失、多余、重复、错误类型、错误来源动作或不可用输出一次收集字段问题并稳定排序。

## 9. 效果入站引用保护

效果 PUT 在写库前：

1. 通过现有前序结果绑定真实外键/索引查询所有引用当前效果/结果的规则。
2. 用候选效果重新计算每个来源结果的即时性和输出可用集合。
3. 删除被引用结果返回 `TRIGGER_RULE_RESULT_IN_USE`。
4. 令现有输出不可用或结果不再即时返回 `TRIGGER_RULE_SHAPE_IN_USE`。
5. 改变可达参数集合返回 `TRIGGER_RULE_RUNTIME_INPUT_IN_USE`。
6. 同一请求多个冲突按既有优先级和字段路径稳定返回，事务不落地。
7. 受影响详情至少携带 `ruleKey / actionKey / bindingKey / outputKind`，不得只返回计数。

删除最后一条吸血规则、清空阻挡范围、把状态施加改为移除、改变生命周期时点和移除斩杀/伤害结果必须有定点测试。

## 14. 开发获批后的真实数据库与接口验收

1. 确认准确 PostgreSQL 目标、备份及阶段 7.5、7.6.1～7.6.4 已验收状态。
2. 执行本阶段独立迁移和对应最终 schema/触发器，核对三处检查及前四段累计结构未漂移。
3. 通过真实效果、过程和规则接口完成共享契约七个综合案例及关键反例。
4. 关闭客户端并重启后端，再次 GET 验证所有事件值、输出种类、动作顺序和引用完整回读。
5. 验证效果入站 409、规则 400、事务回滚、候选循环和迁移重复执行。
6. 记录真实数据库、接口和重启回读证据后，前端才能进入最终浏览器综合验收。

## 15. 后端停止条件

出现以下任一情况停止编码并回到共享契约：

1. 阶段 7.6.4 最终表、检查、绑定、分析器或候选图与本文前提不一致。
2. 需要新表、列、运行缓存、自由输出或跨规则引用才能实现。
3. 输出矩阵无法从结果完整详情确定，必须执行结果才能完成管理校验。
4. 效果或规则无法在一次聚合事务中维护，必须暴露半成品子接口。
5. 必须保存 JSONB、数组、自由字符串或通用多态关系。
6. 需要执行公式、伤害、护盾、吸血、阻挡、斩杀、联动、事件、结算或 Wasm 才能完成结构校验。
7. 七个案例的真实数据库、接口或重启回读验收不可用且无法定点确认原因。

在 Cursor 只读评审、项目负责人确认及全部前段完整验收之前，本设计不授权任何后端、SQL、数据库或服务操作。
