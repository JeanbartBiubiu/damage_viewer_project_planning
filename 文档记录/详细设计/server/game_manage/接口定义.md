构筑管理使用 `/api/admin/games/{gameId}/build-systems` 下的系统、分组、可选项及完整定义快照，以及 `/build-option-skill-relations` 的查询、挂载、调序和解绑；代表图片继续使用现有图片子资源。旧符文专用接口已经移除。具体字段只在上表的构筑系统契约中定义。

后端返回作者配置和所选对象的一致性快照；前端负责转换为计算请求，Wasm负责执行。后端不保存完整模拟场景，也不运行战斗计算。
