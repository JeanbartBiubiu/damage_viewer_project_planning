## 1. 使用口径

本文是人工验收入口，只回答“下一步要进游戏采什么、填哪里、什么状态才可以升级 golden”。

不在本文存放截图、视频或 OCR 大文件；这里只登记 `evidenceRef`。截图、OCR JSON、视频时间点可以落在本地证据目录或后续报告产物目录，只要 `evidenceRef` 能追溯即可。

状态规则：

1. 人工未填写 `baselineValue` 前，字段状态只能是 `missing_evidence` 或 `todo`。
2. OCR 结果必须经过人工确认后才允许标记为 `source=ocr_confirmed`。
3. `low_confidence` 和未解释 `diff` 不能升级 golden。
4. 开发侧自测字段可以登记为 `source=derived_fixture`，但不能替代真实游戏侧 baseline。

## 8. 填写后的处理规则

1. 如果 `baselineValue` 已填且置信度高，再按 tolerance 判定 `match` 或 `diff`。
2. 如果 OCR 和人工读数不一致，字段先标 `low_confidence`，不要升级 golden。
3. 如果游戏侧不可见，字段只能保留 `derived_fixture` 或拆出额外证据链。
4. 如果 `versionCode`、游戏客户端版本、wasm sha256 任一缺失，case 不能升级 golden。
