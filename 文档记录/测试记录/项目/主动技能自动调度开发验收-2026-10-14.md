# 主动技能自动调度开发验收

本记录只保存已经执行的验证与范围。当前行为、共享字段及顺序的唯一来源是[主动技能自动调度与连招约束详细设计](../../详细设计/项目/主动技能自动调度与连招约束详细设计.md)。负责人在确认完成时授予、成功开始消费、开始后不归还、共同冷却和长链支持后，明确授权开始开发。

## 1. 已实现范围

原生支持1～16项实际绑定主动技能的就绪优先级、关联冷却、一次释放资格及多条独立连续链，自动模式可开启背景普攻。首期只自动执行单步骤即时或有限延时首次过程，作者须声明真实正冷却；手动固定时刻模式继续承接复杂控制、多段和引导。

共同冷却账本唯一拥有能力及内部冷却、等待登记和代号。普攻保留已走过的进度；主动、被动和普通未就绪重试共用实际拥有者的账本及共享事件堆。被动内部冷却用途显式使用已有状态用途字段，状态0／1和到期值是只读投影；到期不补旧事件。普通状态期限、弹药恢复和同次使用节流保持独立语义。

页面提供固定时刻／自动循环互斥模式、独立草稿、顺序编辑、关联冷却与前置资格、有限记录和完整资格账本。自动规则独立生成真实来源、等级及首次阶段的场景选择，没有将自动规则伪造成手动动作。后台复用现有场景闭包；本轮没有后端代码或数据库变更。

## 2. 源码调用与独立检查

| 验证对象 | 实际正式入口与所有权 |
| --- | --- |
| 能力冷却与帧写入 | `generic_gate.go`读取、`generic_execution.go`写入同一`genericCooldownLedger`；规范能力引用决定真实拥有者，费用来源语义保持 |
| 普攻 | `generic_basic_attack_wait.go`保存等待进度，共同账本保存冷却截止与等待版本；已有下一刀原位改期 |
| 自动规则 | `generic_automatic_skills.go`登记自身与关联冷却；`generic_cooldown_wake.go`在帧发布前预留容量、发布后合并候选唤醒 |
| 普通未就绪重试 | `generic_run.go`登记共同等待，`generic_cooldown_wake.go`统一通知并原位改期；成功后取消登记，不变成无限循环 |
| 被动内部冷却 | `generic_cooldown_state.go`写真实拥有者、挂载、状态键、范围与目标的共同身份；`generic_provider_state.go`及快照读取边界生成只读投影 |
| 被动能力／周期 | 子能力、普通周期及锚定周期均经过共同冷却门禁；已冷却的旧事件不重放，合法直接减少冷却的监听保留 |

独立检查发现并修复：自动来源准入仍只识别手动列表；纯主动的普通状态期限缺到期唤醒；初始空弹药的共同等待版本被旧零代号分支误判；监听子能力冷却写到执行来源而非实际拥有者；冷却跳过被误记为同次施放节流；规则引用错误缺输入索引。实际监听节流回归以合法伤害事件证明；一次额度加子能力引用仍由编译器拒绝，没有计为运行能力。

资格在实际开始／完整终结提交后更新；资格0／1、不覆盖旧授予、不累计、不补领、启动前预算失败保留、开始后失败不返还都有独立用例。明细预算0和汇总模式不会改变完整累计或真实过程。
