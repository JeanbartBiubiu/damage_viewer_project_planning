# 数据库密码与随机材料验收

本轮开发与验收通过。按用户要求调整后续版本的密码与随机材料实现，契约以[账号方案第 8 节](../../详细设计/项目/账号注册登录与权限接入技术方案.md)为准。已有发布、发布产物、`test0221` 及线上账号未升级；原有账号功能的验收保留在[初轮记录](账号注册登录与权限接入验收-2026-11-05.md)。

## 验证范围

密码生成与校验使用 PostgreSQL 的 `pgcrypto` 扩展，固定 bcrypt 成本 12。验证器种子、成对的会话／流程与防伪值、十份恢复码由数据库随机函数生成；长期加密密钥、签名私钥及内网服务凭据仍由库外工具管理。现有编号、动态码运算、二维码、加密保存及签名规则未改。

前后端按 UTF-8 字节数拒绝第 73 字节，保留合法的完整 72 字节及首尾空白，拒绝空字符与不完整 Unicode。旧密码编码不增加兼容路径；[新迁移](../../../db/user_manage/migrations/20261105_postgres_password_material.sql)遇不支持的编码停止，不转换或删除账号，[历史迁移](../../../db/user_manage/migrations/20261104_account_identity.sql)保持原样。

最终真实数据库为 PostgreSQL 18.4 独立回环实例，端口 15432，测试库 `dv_auth_verify_20261104_pg_20261105_50671bf7`。初始化并回读 30 张空游戏表、7 张账号表及扩展；没有复制真实账号或游戏数据。对旧编码的迁移拒绝在事务内验证并回滚，另对真实注册后的 bcrypt 账号执行迁移成功。

实际服务使用最终 JAR、独立回环端口 18110、受限的本机测试密钥及显式绝对配置路径；沿用模块的 Windows 本机通信临时目录参数。独立 JDBC 回读确认：一个 HTTP 测试账号使用本版 bcrypt 编码、一个正式验证器、10 枚恢复码中恰有一枚已消费、活跃会话为零；30 张游戏表仍为空。恢复流程中的等待是等待下一可用动态码时间步，不作为密码计算耗时。

前端未改变 Wasm 字节或运行协议，原有 260 项固定机制包含在本轮完整前端单测中；没有刷新整对象准入或引擎证明。
