# 账号注册登录与权限接入验收

本轮本地开发验收通过，已实现[账号方案](../../详细设计/项目/账号注册登录与权限接入技术方案.md)中的注册、强制验证器、账号恢复、开通、会话、匿名游戏读取、编辑资格及计算授权。初轮开发与验证在本机完成，未推送或部署；随后经用户明确确认，已在默认库 `test0221` 执行建表迁移，详见下方实库补充。

## 交付与运行范围

- 顶栏右上角提供登录／注册；登录需要密码及验证器动态码。注册完成后显示待开通和本人账号编号，内网开通后才能正式登录。
- 被拦截时只提示「需要登录」，关闭后保留当前输入；不打开登录表单、不跳转、不自动重放。手机端登录及提示弹窗适配 390 像素宽屏幕。
- 所有游戏资料及只读场景快照匿名开放；开通不授予编辑资格。会话恢复、退出、双标签页失效及三类账号安全变更均已接线。
- [正式建表脚本](../../../db/user_manage/schema.sql)与[已有库迁移](../../../db/user_manage/migrations/20261104_account_identity.sql)已交付；七天清理只处理从未开通账号，已开通后禁用的账号保留。
- Java 签发 Ed25519 短期票据，Wasm 在编译和每次运行入口验证；释放无需票据。构建开关缺省启用，当前前端分发明确采用早期关闭版。
- 项目子代理默认路由改为 `codex2api/gpt-6.1-sol`，沿用用户本次明确授权；没有改动全局配置或角色模型覆盖。

运行密钥位于被忽略的本机 `config/auth/`，私钥及服务凭证均未提交。数据库连接、密码、种子、恢复码、Cookie 和原始票据不进入验收记录。配置、初始化和运维入口见各模块 README。
