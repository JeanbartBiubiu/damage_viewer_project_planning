## 1. 本轮范围

本轮验证 V2 Batch B：在已通过的 Batch A `single_attacker_dps` / `target_dummy` / V2 DPS 页面基础上，接入首批 6 个英雄的普攻相关技能被动。

覆盖项：

1. 薇恩 W：三环真实伤害。
2. 提莫 E：命中魔法伤害 + 后续 DoT。
3. 韦鲁斯 W：普攻附带魔法伤害 + 枯萎层数；主动引爆不做。
4. 卡莎 P：电浆叠层与触发伤害；P/W/E/R 主动不做。
5. 图奇 P：毒液叠层 + DoT；E 引爆不做。
6. 克格莫 Q/W：Q 被动攻速；W 通过 `scenarioStates` 作为预开启 preset 参与计算。

本轮根据 1 级训练营截图和 OCR 候选值调整 DB seed，并重新发布。OCR 仍只作为候选证据，最终游戏实测数值需要人工确认。

## 5. 前端适配修正

修正文件：[tinygoV2DpsAdapter.ts](/c:/project/damage_web_dev/web/src/engine/tinygoV2DpsAdapter.ts)

修正点：页面选择 `scenarioStates` 时，自动把该 scenario 依赖的 `requiredSkillIds` 合并进 `enabledPassiveEffects`，否则图奇 Q、提莫 P、韦鲁斯 P 这类“手动指定触发态”只会出现在 selection 里，不会实际投影成 wasm 可执行的 `stat_modifier`。

复测结果证明该修正生效：选择“图奇 Q 离隐后攻速”后，active curve 的 `effectBreakdown` 包含 `twitch_q_attack_speed` / `kind=stat_modifier` / `amount=0.9506`。

## 8. 结论

开发侧结论：V2 Batch B 首批英雄被动在 DB seed、publish、前端投影和页面 smoke 上通过。

通过依据：

1. `v2_batch_b_hero_passives_004` 已发布为 `lol` current bundle。
2. 11 条 `_dps_v2` skill 可从 bundle 回读。
3. 前端能把默认技能被动和可选 scenario-state 攻速 preset 投影成 wasm 输入。
4. 页面 smoke 证明薇恩 W、图奇 P、图奇 Q 攻速 preset、提莫 P 攻速 preset、韦鲁斯 P 攻速 preset、卡莎 P 电浆均能产生可检查的输出。

保留缺口：

1. V2 DPS 页面当前仍使用固定 `target_dummy_fighter`，所以卡莎 `1000 HP / 0 双抗` 的精确 742 / 636 数值由 Wasm 回归测试和人工截图基线闭环；页面只证明 published bundle 与 wasm 输出链路可运行。
2. 提莫 P / 图奇 Q / 韦鲁斯 P 的攻速 preset 目前是满窗口手动触发态，未建模真实触发时机、持续时间结束和回退。
3. OCR 是候选证据；卡莎本轮采用用户手填 HP 节点作为人工确认值。
