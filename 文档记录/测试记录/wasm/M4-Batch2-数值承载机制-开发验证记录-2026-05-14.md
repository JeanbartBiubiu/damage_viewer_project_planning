## 4. 代码变更摘要

Wasm：

1. `wasm/tinygo_engine_v2/internal/model/types.go`
   - `StatusTemplateV2` 增加最小 tick 字段：`tickIntervalMs`、`tickCount`、`tickEffectType`、`tickFormulaId`、`tickAmount`、`tickDamageType`。
   - `ActionEffectRunResultV2` 增加 shield/heal/status 结构化证据字段。
   - `DonePayloadV2` 增加 `tickResults`，用于记录 status tick 的结构化证据。
2. `wasm/tinygo_engine_v2/internal/compile/compile.go`
   - 编译 status tick 配置，只支持 `deal_damage` 与 `heal` 两类固定 tick。
3. `wasm/tinygo_engine_v2/internal/scheduler/heap.go`
   - 增加 `EventStatusTick`。
4. `wasm/tinygo_engine_v2/internal/runtime/runtime.go`
   - `grant_shield` 输出 shield before/after/granted。
   - `deal_damage` 输出 shield before/after/absorbed。
   - `heal` 输出 raw/applied/overheal 与 HP before/after。
   - `apply_status` 输出 statusId。
   - status apply 支持固定 tick 调度，DoT/HoT tick 写入 `done.tickResults`。
5. `wasm/tinygo_engine_v2/internal/runtime/runtime_test.go`
   - 新增四个 Batch 2 独立测试。

Web：

1. `web/src/engine/tinygoV2BundleAdapter.ts`
   - TinyGo V2 input 增加 `statuses`。
   - effect 支持 `heal`、`grant_shield`、`apply_status`。
   - `schedule_tick` 编译为 status tick，而不是即时伤害。
2. `web/src/pages/WasmValidationM3Page.tsx`
   - 增加 M4.4/M4.5/M4.8/M4.9 preset。
   - evidence rows 增加 shield/heal/status/tick 字段。
   - actor outcome 增加 `shieldAmount` 行。
3. `web/src/engine/wasm/tinygo_engine_v2.wasm`
   - 已同步本轮 TinyGo runtime 构建产物。
