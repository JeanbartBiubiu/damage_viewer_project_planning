## 4. Playwright 页面 B 回归

入口：

```text
http://localhost:5173/#/wasm-validation-v2-dps-multi-hero
```

操作：

1. 进入系统总览，把 game 切换到 `lol`。
2. 确认页面 B 加载 current version `v2_batch_g_adc_level_tables_002`。
3. 使用默认三条曲线运行。
4. 编辑克格莫曲线，把 Q/W 技能等级改为 5，并把英雄等级改为 18 后运行。
5. 再把克格莫英雄等级改为 1，保持 Q/W 5 级后运行。

结果摘要：

| 场景 | 关键结果 |
| --- | --- |
| 默认三曲线 | `vayne`, `teemo`, `kogmaw` 均为 `ok` |
| 克格莫 18 级 Q5/W5 | `attackerAd=113.7`, `attackerBaseAttackSpeed=0.964583`, `attackCount=10`, `killTimeMs=3861` |
| 克格莫 18 级 Q5/W5 技能效果 | Q 操作值 `attackSpeedPercent=0.25`，W 操作值 `targetMaxHpRatio=0.06` |
| 克格莫 1 级 Q5/W5 | `attackerAd=61`, `attackerBaseAttackSpeed=0.665`, `attackCount=11`, `killTimeMs=5110` |
| 对比结论 | 技能等级改变会改变被动操作值；英雄等级改变会改变基础属性和曲线结果 |

控制台：

1. 未出现 `enabled passive effect ... missing from resolvedSnapshot.passiveEffects`。
2. 仅保留旧 session 切换前的 IT game current 404 和 favicon 404，切回 `lol` 后页面 B 能正常运行。
