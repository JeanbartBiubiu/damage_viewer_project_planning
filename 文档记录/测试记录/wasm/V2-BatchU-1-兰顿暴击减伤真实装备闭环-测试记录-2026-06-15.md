断言摘要：

| case | finalDamage |
| --- | ---: |
| 无兰顿：IE full crit | `414` |
| 兰顿：焚天 + IE 首次暴击 | `132.48` |
| 兰顿：IE normal hit | `102.8571` |
| 兰顿：IE full crit | `165.6` |
| 兰顿：智慧末刃 magic on-hit | `45` |

证明点：

1. 兰顿 target equipment 在 current bundle 中可被 adapter 接入。
2. `critOnly=true` 只影响 crit portion；normal hit 只受兰顿护甲影响。
3. 魔法 on-hit 不受兰顿暴击减伤影响。
4. 无兰顿对照 case 保留 `414` 的 IE full crit，兰顿 full crit 降到 `165.6`。

这不是重新录入 Batch C/D 已测装备；只是在需要“游戏内伤害数值”口径时补兰顿专属 baseline。
