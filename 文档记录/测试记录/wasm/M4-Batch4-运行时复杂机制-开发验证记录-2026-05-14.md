## 4. 代码变更摘要

Wasm：

1. `wasm/tinygo_engine_v2/internal/model/types.go`
   - action 增加 `channelDurationMs`，run input 增加 `modeAugments`。
   - effect 增加 `interrupt`、`increment_counter`、history/counter/mode/interrupt evidence 字段。
   - done payload 增加 `triggerResults`。
2. `wasm/tinygo_engine_v2/internal/compile/compile.go`
   - 编译 action channel duration、interrupt/counter effect、mode augment 参数。
3. `wasm/tinygo_engine_v2/internal/scheduler/heap.go`
   - 增加 `EventActionComplete` 与 execution handle。
4. `wasm/tinygo_engine_v2/internal/runtime/runtime.go`
   - 增加最小 running execution arena，用于 channel start、completion、interrupt lazy drop。
   - 接入 `counter.State`，并让公式 `counter(...)` 可读 run 内计数器。
   - `fireTriggers` 记录一层 `triggerResults`，保持递归触发不展开。
   - damage effect 支持 mode augment multiplier evidence。
5. `wasm/tinygo_engine_v2/internal/runtime/runtime_test.go`
   - 新增六个 Batch 4 独立测试。

Web：

1. `web/src/pages/WasmValidationM3Page.tsx`
   - 增加 M4.13/M4.14/M4.16/M4.17/M4.18/M4.19 preset。
   - evidence rows 增加 blocked status/rule、execution、interrupt、history、counter、mode、trigger 字段。
2. `web/src/engine/tinygoV2BundleAdapter.ts`
   - TinyGo V2 input 支持 `channelDurationMs`。
   - raw effect 支持 `damage_from_recent`、`interrupt`、`increment_counter`，并补充 mode augment 参数承载。
3. `web/src/engine/wasm/tinygo_engine_v2.wasm`
   - 已同步本轮 TinyGo runtime 构建产物。
