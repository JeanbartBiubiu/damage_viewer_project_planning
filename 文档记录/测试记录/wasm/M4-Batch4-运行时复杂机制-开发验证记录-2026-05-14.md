## 10. Review 修复补充 2026-05-15

本次只修复 M4 review findings，不新增 browser/preset 完成证据。

修复范围：

1. `execution_arena_full`：channel action 在 execution arena 满时不再先提交资源和冷却；blocked result 保持 `blockedReason=execution_arena_full`，无 `resourceDeltas`、无 effect、无 `readyAtMs` 变化。
2. history window：`DamageTaken` 改为记录实际 HP 损失 `appliedDamage`；shield 吸收量和 overkill 超出 HP 的部分不进入 HP damage history。
3. DoT trigger：DoT tick 作为 M4 顶层 damage event，可触发一层 `on_damage_dealt` / `on_damage_taken` evidence；trigger effect 仍以 `chainDepth=1` 执行，不递归展开。
4. trigger owner：runtime dispatch 开始尊重 `ownerRole` / `ownerId`；空 owner 保持全局触发，`source` / `target` owner 只匹配对应 actor。
5. action snapshot：`interrupt` 和 `increment_counter` 不再输出 `unknown` effect kind。

新增/扩展回归测试：
