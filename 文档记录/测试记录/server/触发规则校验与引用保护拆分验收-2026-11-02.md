## 真实服务与独立回读

使用最终应用包绑定 `127.0.0.1:18082`，沿用项目的本机通信临时目录参数；仅本次本地进程关闭管理鉴权，未修改认证配置。数据库为 `test0221`，在写入前独立核对相关实际列及隔离游戏键不存在；只创建本次专用游戏 `codex_trigger_20261102_01`，不修改现有 LoL 作者配置。

最终一轮 29 次 HTTP 请求通过，包含以下场景及每次失败后的新请求回读：

- 公共游戏读取；单独规则创建、读取与更新的实际往返。
- 非法结构返回 `400.INVALID_BODY`，规则不存在，整技能摘要不变。
- 被引用效果删除及被引用结果移除返回 `409.SKILL_EFFECT_IN_USE`，效果与摘要不变。
- 同时提交效果修改和新增引用对象，最终组合检查返回 `409.SKILL_OBJECT_REFERENCE_INVALID`，原结果恢复，临时新增对象全部回滚。
- 同一统一保存中，先提交引用规则、再提交此前不存在的效果，最终成功；另一次保存同时删除旧规则和效果、创建新规则和效果，也成功并回读一致。
- 旧摘要保存返回 `409.SKILL_CONFIGURATION_CHANGED`，没有写入；最终缺失引用保存失败后，已写入的新效果和规则均不存在，摘要不变。

HTTP 验证结束后，以另一个数据库连接读回：2 个技能、2 个效果、2 条规则、4 条引用；规则仅为 `hit`、`next_rule`，效果仅为 `heal`、`next_effect`，没有失败请求产生的对象。随后通过生产服务删除两个测试技能，再由独立连接确认技能、效果、规则和引用均为零；删除本次游戏与其自动创建的空图片分区后，游戏剩余数为零。本次应用进程已停止。
