# 第七章：当前能力与阅读导航

理解系统以后，还需要区分通用机制、页面接线、真实对象可用性以及实际部署。这个章节提供核对入口，不另存对象数量、测试通过数或任务进度。

## 怎样核对当前能力

| 能力范围 | 当前理解 | 从哪里核对完整定义 |
| --- | --- | --- |
| 作者配置管理 | 管理角色、装备、构筑、技能组成、状态、乘区、关系和图片 | [前端说明](../../../web/README.md)、[后端说明](../../../server/data_manage/README.md)及实际配置 |
| 计算场景 | 单次／连续普攻、有限技能计划及混合战斗分析 | 页面、生产适配及[录入边界](../计算范围与录入边界.md) |
| 通用机制 | 规则通过编译和运行改变数值，时间与状态依实际机制演进 | [引擎说明](../../../wasm/tinygo_engine_v2/README.md)、[机制用例说明](../../../web/tests/mechanisms/README.md) |
| 完整对象 | 可用目录匹配当前配置、依赖、范围及引擎和适配器身份 | 后端可用目录、正式范围及准入数据，入口见录入边界 |
| 账号与资格 | 注册、登录、验证器、安全操作、内网开通及受保护操作 | [账号方案](../../详细设计/项目/账号注册登录与权限接入技术方案.md)、[账号数据库说明](../../../db/user_manage/README.md) |
| 访问统计 | 匿名页面访问上报，编辑账号查询近三十天 | [统计说明](../../../db/visit_statistics/README.md) |

源码里存在一个能力，不代表所有页面或所有游戏对象都已经接入它。具体对象必须核对完整配置及所需场景；既有正式证明也要与现场内容和产物身份相符。

## 已确认简化与未实现设想

产品简化以[技能计算取舍](../../概要设计/项目/技能六模块能力组合表.md)为准，对象排除与资料缺口以原账本为准。手册中的例子用来解释结构，不补齐未知资料，也不授予某个对象支持资格。

装备／构筑比较、斩杀线、属性扫点、版本差异、最大伤害组合搜索等属于[背景说明](../../需求澄清/项目/背景说明.md)保留的方向。新分析问题仍需明确输入、比较口径和验收，不能从通用计算能力直接推断已有专用页面。

浏览器场景快照缓存及失效更新暂缓到版本管理明确后处理；有限排程和决策接口属于候选。最新引擎方向查[子系统现状](../../概要设计/项目/Wasm子系统职责与协作现状及调整方向.md)，任务是否完成只查[任务规则](../../../db/task_doc_governance/task_rules.json)。

## 验证入口按问题选择

| 要确认什么 | 对应验证入口 |
| --- | --- |
| 局部逻辑和输入边界 | 对应源码旁的单元测试，各模块规则规定受影响检查 |
| 生产适配与真实引擎是否遵守数值规则 | [固定机制回归](../../../web/tests/mechanisms/README.md)，由合成输入和独立手算期望经真实引擎验证 |
| 源码与分发引擎是否一致 | [引擎说明](../../../wasm/tinygo_engine_v2/README.md)的正式构建与[前端说明](../../../web/README.md)的构建比对入口 |
| 正式对象能否继续准入 | 真实配置摘要、依赖机制覆盖和当前产物身份，见[开发流程](../开发与独立评审流程说明.md) |
| 页面和权限接线是否正确 | 前端模块中的浏览器用例及必要真实页面验证 |
| 实库、安装或性能是否符合预期 | 对应环境的独立读回、部署检查或同口径测量；操作入口见模块说明与[部署规程](../部署操作规程.md) |

单元测试、机制回归、浏览器和真实数据库分别覆盖不同层次。验证入口长期维护，执行结果对应当时文件和环境；没有重新执行时，不把文档整理说成新一轮运行验证。

独立验收过程文档不再作为长期知识章节保留，旧过程从 Git 历史追溯。测试代码及系统使用的正式准入证明继续维护，部署步骤与实际部署状态仍要分别判断。

## 阅读或修改时的核对顺序

先定位业务问题和[相关概念](03-核心概念与关系.md)，再沿[数值因果](04-规则怎样改变数值.md)、[完整流程](05-一次计算的全过程.md)与[系统协作](06-系统各部分怎样协作.md)找到拥有者；随后读取对应规则、共享定义、源码和测试。

需要新增规则时，先区分已有行为、已确认取舍和未决设想。修改共享定义后核对生产者与消费者，修改对象配置后核对范围和准入。任务状态只维护于任务规则，手册只在概念、关系、边界或入口变化时更新。

新增功能先按[功能设计与能力组合指南](../开发指南/功能设计与能力组合指南.md)推导所需能力及契约；具体编写、用例、构建排错和文件移动方法从[开发指南](../开发指南/README.md)按当前工作选择，模块规则继续决定权限与最低验证门槛。
