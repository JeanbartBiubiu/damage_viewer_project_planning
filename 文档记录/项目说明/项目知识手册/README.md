# Damage 项目知识手册

Damage 把游戏资料、可编辑配置、场景输入和数值计算连在一起，帮助玩家解释伤害差异并复算结果。这份手册面向首次阅读项目的人，以及需要定位问题和修改影响的人工智能助手。

阅读主线是“为什么需要它 → 用户怎样使用 → 系统描述了什么 → 数值为什么变化 → 一次计算怎样完成 → 各部分怎样协作”。具体施工计划、接口字段和命令继续由对应设计、共享规范和模块说明维护。

需要查术语、计算口径或概念分歧时，进入[领域知识库](../../领域知识库/README.md)。手册提供整体阅读路线，词条集中解释已收录概念，并给出算例、常见误读及本地依据。

## 三种关系分开阅读

- **章节关系**表达阅读顺序，例如先理解效果，再理解生命周期。
- **概念关系**表达包含和关联，例如技能组织效果，装备可以授予技能。第三章提供整体关系；已收录的概念由领域词条集中解释，其他章节保留摘要与链接。
- **实现关系**表达数据由谁生产、谁消费以及在哪保存。源码入口帮助继续调查，不把目录划分当作业务概念本身。

目录构成阅读树，概念之间通过正文链接形成关系图。以后需要知识库页面、向量检索或有向无环图时，可以使用这些主题和关系；只有被明确规定无环的关系才按无环图处理，普通交叉引用允许互相指向。当前不新增图数据库、索引服务或自动同步系统。

修改概念时同步检查涉及的流程章节和实现入口。一个小节应能独立说明主题、关联对象、适用限制及依据，便于单独阅读或检索；必要上下文用明确链接补齐，不依赖“见上文”推断。章节不维护对象完成数量、逐轮测试数或第二份任务进度。

验收过程文档已移除，历史过程从 Git 追溯。持续验证入口、固定机制用例和系统使用的正式准入证明各自保留；历史文件名若保存在原始资料或证明的来源说明中，表示当时出处，不是现行阅读链接。
