# 游戏机制与工程术语

面向用户的字段、按钮、选项和可见错误使用中文。代码、接口、数据库及资料中的稳定标识保留原值；首次出现必要技术名称时解释含义。本文只统一常用说法，具体数值语义以实现和共享定义为准。

| 术语或标识 | 中文含义与边界 |
| --- | --- |
| DPS / DoT / HoT | 每秒伤害／持续伤害／持续治疗；区间汇总必须来自区间内真实结算 |
| HP / AD / AP | 生命值／攻击力／法术强度；分别说明当前、最大、基础或额外等取值口径 |
| Crit | 暴击；区分概率、倍率及期望值，期望金额不是一次随机暴击结果 |
| Basic Attack / On-hit | 普通攻击／命中附加；附加结果不能冒充新增一次普通攻击 |
| Cooldown / Stack | 冷却／层数；写清所属对象、范围、期限与上限 |
| Status / Internal State | 战斗状态／技能内部状态；与页面状态和本场输入分开 |
| Shield / Heal / Vamp | 护盾／直接治疗／吸血；分别核对吸收、实际回复及修正来源 |
| Resource / Cast Cost | 资源／施法费用；机制资源和真实生命值不因键名相同自动成为同一账本 |
| Execute / Takedown | 斩杀／参与击杀；斩杀需明确阈值口径，参与击杀包括来源明确的击杀或助攻 |
| Tick / Gate | 周期结算／条件门槛；时间与资格分别判断 |
| Provider / Ability / Operation | 供值器／能力／操作；分别承载来源行为、执行入口和数值变化意图 |
| Snapshot / Session | 快照／编译会话；配置快照、战斗末态和可复用规则不能混用 |
| Runtime Input | 运行输入；定义声明用途，本场值由场景或真实事件提供，缺失不补零 |
| Wasm / Worker | 浏览器内计算引擎所用的字节码／浏览器后台工作线程 |
| ABI / DTO | 宿主与引擎的调用协议／跨层传输的数据结构 |
| Digest / Proof | 内容摘要／核验凭据；摘要匹配用于身份核对，本身不证明机制正确 |

同一使用、命中、来源、目标和挂载有各自身份。文档中的“保存通过”“机制通过”“完整对象通过”“已安装”分别表示不同事实，报告时保留时间、范围及限制。
