# 领域知识库

本库统一项目中容易混淆的术语、概念关系和数值口径。讨论乘区、当前生命、原始伤害等问题时，先查对应词条，使用其中明确的对象、单位和时点，再查它链接的实际定义。

知识库与代码放在同一仓库，概念变更和实现变更可以同次评审。页面按主题互相链接，直接阅读或全文搜索即可使用。

## 写词条时回答什么

一份词条围绕一个可独立解释的主题，至少包含：明确含义、相邻概念的区别、需要的输入与单位、关键时点或顺序、正反算例、适用边界及本地依据。例子要说明假设；有现成固定用例时指向其真实位置，不能用例子推断全部场景支持。

同一术语只在一个词条集中解释，其他页用摘要和链接。显示名称、字段名与玩家习惯叫法不同的，明确对应关系；需要区分的口径不要继续共用模糊名称，例如区分技能基础金额和伤害记录中的原始金额。

发现歧义时先找出分歧是名称、单位、身份、读取时点、计算基数还是支持范围，再对照所属定义与用例。若源码与已确认业务契约冲突，应记录并处理实际缺陷；不能只改词条来为错误行为背书，也不能凭个人游戏理解改变项目规则。

修改概念时同步检查引用它的手册、指南、生产者、消费者及相关测试；改变业务语义仍按根规则评审。词条不记录逐轮测试数量、任务进度或会话流水，不依赖外部网站才能理解基本含义。
