# Damage Viewer

面向游戏玩家与攻略作者的数值分析工具。管理工作台维护角色、装备、构筑和技能配置；计算页面读取场景数据，由浏览器内的Wasm引擎执行并展示结果。当前处于MVP阶段。

2026-11-01清理了已实现的详细设计、旧发布链与旧模型说明、重复看板和过期阶段计划；有效计算取舍与后续接口草案继续保留。原始资料、逐对象账本、正式证明、测试代码和必要验收记录保留。外置历史证据见[归档索引](数据参考/外置归档索引.md)。
