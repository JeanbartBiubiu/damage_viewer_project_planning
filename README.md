# Damage Viewer

面向游戏玩家与攻略作者的数值分析工具。公共查看版提供资料查询、场景计算和问题反馈，私有维护版供人工智能助手准备并提交经过验证的配置变更；两种前端共用一个后端，计算由浏览器内的Wasm引擎执行。当前处于MVP阶段。

## 验证与文档维护

当前页面已有单次／连续普攻、有限技能计划和混合战斗分析。管理保存、通用机制回归、真实对象运行和完整对象准入分别判断；已存在的历史证明数量不能作为现场可用数量。

持续验证入口集中在[手册第七章](文档记录/项目说明/项目知识手册/07-当前能力与阅读导航.md)及模块说明。单元测试、固定机制回归、正式产物核对、浏览器和真实数据库分别覆盖对应层次；历史结果不代表当前版本重新验证或已经部署。

文档保留当前产品约束、概念关系、有效计划、操作与验证入口。已实现的字段、函数、实施分工和逐轮施工过程由源码、测试及Git历史承接；废弃方向直接删除。详细设计只在新任务确有独立维护需要时创建。

原始资料、逐对象账本和验收附件保存在本机。源码、可执行回归用例和后端运行所需的正式准入清单随仓库提供。新检出需要开展资料核对或录入时，按[归档索引](数据参考/外置归档索引.md)恢复对应文件。

复查已删除文档时用 `git log --all -- <原路径>` 查找，再用 `git show <提交>:<原路径>` 读取。任务状态及文档映射只维护于任务规则，映射变化后在仓库根目录执行：

```powershell
node tools/task-governance/cli.mjs check
```
