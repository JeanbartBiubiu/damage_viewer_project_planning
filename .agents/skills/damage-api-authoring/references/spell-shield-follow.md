# 同次命中结果的阻挡跟随

`DAMAGE.detail`可选`spellShieldFollowResult: {skillKey, effectKey, resultKey}`，只表达同一次真实父命中内结果之间的单向阻挡关系。省略保持原形状；显式空值、缺键和未知字段拒绝。

跟随者须为即时目标伤害、自身法盾范围为空，不能声明普攻主体或主体替换。所指结果须是同游戏、同实际角色关系的合法可判盾即时目标伤害，且不能继续跟随；自指、链和环拒绝。后端保留定义引用并保护生产者修改、删除和角色关系移除。场景关闭、零级或未计划的生产者只加载定义，不因此启用。

宿主在真实父命中完整候选形成后解析引用。所指结果本次未参与时跟随者正常；所指结果本次被挡时沿同一阻挡事实，不能另造命中或消费第二面盾。不以同一毫秒代替真实使用、命中和目标身份，也不能只给两个独立结果分别填写法盾范围来模拟。

仍走现行聚合保护保存和完整独立回读。采用前核对实际服务、宿主和正式Wasm已安装同一能力；新增字段不代表原对象已经通过运行验证。来源文本的特殊同击规则需在实际场景中检查普通分支、共同受挡、一次盾消费及后续资格。
