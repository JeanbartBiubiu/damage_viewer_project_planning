# 技能伤害验证

接收已确认的技能文本、对应技能结构与场景输入，对比预期结果和 Wasm 计算结果。文本可由 GPT 或其他大模型整理；默认规则和数值已经确认，不重复查询资料、核对来源或版本。

## 输入与场景

输入可来自[技能文本转换](../character-skill-authoring/SKILL.md)，也可直接提供技能结构、预期值或 Wasm 结果。已有内容直接使用，只补缺少的一端；不以已保存到数据库、来源元信息或正式证明作为比较前提。

没有指定场景时，按文本选择几组有区分力的输入：正常触发、改变关键等级或属性、条件不成立或边界。只覆盖本次技能涉及的行为。

| 文本涉及的行为 | 对照重点 |
| --- | --- |
| 等级、属性倍率、生命比例、层数、阈值 | 改变相关输入，比较对应金额与条件分支 |
| 多段、周期、延迟、冷却 | 逐笔金额、次数、顺序、时刻与后续资格 |
| 增益、减抗、标记、强化普攻 | 比较实际后续伤害，覆盖条件成立与不成立 |
| 控制与打断 | 比较受影响一方的行动中断、延后及恢复时点 |
| 护盾、治疗、致死或阻挡 | 比较相应吸收、生命变化及触发结果 |

缺少决定预期的必要条件或存在文本内部矛盾时，具体指出并交回调用方补齐，不自行展开资料调查。

## 计算与对照

1. 已给预期值时直接采用；只给规则或算式时，用计算器、[离线计算工具](references/calculation-tool.md)或独立脚本求值，大模型不自行完成算术。期望不能从被测公式求值器、生产结算函数或 Wasm 输出反填。
2. 对同一组场景输入取得 Wasm 结果；已有对应结果时直接比较。需要实际运行时按[运行接线](references/wasm-route.md)使用现有入口，完成编译、运行和会话释放，不额外启动资料审核或正式准入流程。
3. 逐项比较本次预期声明的金额、次数、条件、时刻及必要状态。区分技能公式金额、`rawAmount`、防御后金额与实际扣血；字段口径不明确时按需查[伤害口径](../../../文档记录/领域知识库/伤害金额、护盾与实际扣血.md)。多段技能不能只比较总额；预期不触发时明确比较事件数为0。消费与重新叠层读取真实状态，不从伤害金额反推；未实例化的状态不能用补0冒充已比较。明确记录本场忽略的费用等条件，不据此判断相应资格通过。
4. 金额使用 `abs(实际值 - 期望值) <= 1e-9 × max(1, abs(期望值))`；标识、次数、整数时刻和条件精确比较。缺字段、未执行、编译失败或影响本次比较的结果不完整，均不能判为一致。

## 输出与完成标准

输出场景输入，以及每个对照项的预期值、实际值、差异和结论。按“通过”“不一致”“未能比较”分别报告；只有本次必要对照项全部一致，才判断该技能在这些场景下符合预期。

发现差异时指出对应字段和可能的转换或计算问题，不为贴合 Wasm 改写输入规则或预期。修复、记账、整角色验收和发布由调用方任务决定，不作为本技能的附加步骤。

## 随工具能力演进

用户已授权在更合适的计算或对照工具可用后，自动更新本技能的工具选择和必要接线。切换前用相同输入验证计算正确、相同结果通过、故意差异失败；保持预期独立于被测实现。只更新这项比较能力，不扩大业务范围。
